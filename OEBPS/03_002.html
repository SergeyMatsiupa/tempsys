3.2.1    XAMPP für Windows

Windows-Nutzer erfahren in diesem Abschnitt im Detail, wie sie eine vollständige Webserver-Umgebung installieren, die zum Betrieb von Magento benötigt wird. Als Basis dafür dient das Serverpaket XAMPP. Es sei an dieser Stelle erwähnt, dass es unzählige Möglichkeiten gibt, den Apache-Webserver in Kombination mit PHP und der Datenbanksoftware unter Windows zu installieren. Ich habe mich in diesem Buch explizit für die Variante mit XAMPP entschieden, da es mit Abstand die einfachste, schnellste und fehlerfreiste Art des Setups darstellt. Auch benötigen Sie als Leser dadurch keine tieferen Kenntnisse in Sachen Systemadministration, was meiner Meinung nach ebenso einen Vorteil darstellt. Ich gehe im Übrigen von der Nutzung der aktuellsten Version von Microsoft Windows aus. Zu diesem Zeitpunkt ist das Windows 10. Sollten Sie eine ältere Version einsetzen, können Sie XAMPP dennoch nutzen und auch dieser Anleitung folgen. Der Installationsprozess wird relativ ähnlich ablaufen, auch wenn es die eine oder andere kleinere Abweichung geben kann. Das wird Sie aber sicherlich nicht von der fehlerfreien und problemlosen Installation von XAMPP abhalten.

Informationen zu XAMPP

Bei XAMPP handelt es sich um eine bereits konfigurierte und einfach zu installierende Webserver-Umgebung. Diese ist für eine Vielzahl von Betriebssystemen bzw. Betriebssystemversionen verfügbar und ermöglicht das einfache Setup von Apache, PHP und MariaDB bzw. MySQL. Weitere Informationen zu XAMPP, nützliche Tipps und Tricks, Downloads sowie eine Dokumentation finden Sie unter www.apachefriends.org.

Probleme beim Starten des Apache-Webservers in Verbindung mit Skype

Sicherlich kann es unterschiedlichste Gründe geben, warum beim Start des Apache-Webservers eine Fehlermeldung zurückgegeben wird. Konfigurationsanpassungen für Windows

Magento setzt gewisse PHP-Konfigurationsparameter und -Module voraus. Bevor Sie mit der Installation von Magento beginnen können, muss im ersten Schritt die PHP-Konfiguration angepasst werden. Würden Sie diesen Schritt überspringen, würden Sie anschließend im Installationsprozess von Magento eine entsprechende Fehlermeldung erhalten und könnten die Installation erst gar nicht starten. Magento lässt sich also nur auf Systemumgebungen installieren, bei denen die minimalen Konfigurationsparameter auch tatsächlich eingehalten werden.

Begeben Sie sich in das XAMPP Control Panel, klicken Sie bei Apache auf Konfig, und wählen Sie anschließend PHP (php.ini) aus. Jetzt öffnet sich bei Ihnen ein Editor, beispielsweise der klassische in Windows integrierte Editor. Suchen Sie zuerst die Zeile

;extension=php_intl.dll

und entfernen Sie das vorangestellte Semikolon. Wiederholen Sie diesen Vorgang bei folgender Zeile:

;extension=php_xsl.dll

Sie haben mit diesen Änderungen nichts weiter gemacht, als die PHP-Erweiterungen INTL bzw. XSL zu aktivieren, die von Magento 2 vorausgesetzt werden. Starten Sie anschließend den Apache-Webserver neu, indem Sie auf Stoppen und daraufhin auf starten klicken. Haben Sie diese Änderungen durchgeführt, sind die grundlegenden Voraussetzungen für Magento erfüllt, und das System ließe sich installieren. Gehen Sie an dieser Stelle aber bitte noch einmal in die php.ini-Datei, und passen Sie zwei Einstellungen an. Suchen Sie die Zeile

memory_limit = 128M

und ersetzen Sie die 128 durch eine 512. Anschließend suchen Sie die Zeile

max_execution_time = 30

und ersetzen die 30 durch eine 360. Durch diese Änderungen haben Sie dem PHP-Prozess etwas mehr RAM zugewiesen, was für Magento definitiv nötig ist. Auch ist der Wert der maximalen Ausführungszeit nun höher. Das kommt Ihnen speziell bei Prozessen, die etwas länger laufen, zugute. Wenn Magento beispielsweise für eine Operation mehr als 30 Sekunden benötigen würde, würden Sie bei den Standard-php.ini-Einstellungen einfach eine Fehlermeldung erhalten. Wenn Sie diesen Wert aber hochsetzen, darf eine Operation auch ein wenig länger laufen, ohne dass direkt ein Fehler erzeugt wird.

Haben Sie diese Änderungen durchgeführt, haben Sie alle notwendigen Einstellungen und Konfigurationsparameter angepasst, um Magento 2 erfolgreich installieren zu können. Gratulation! Die nächste größere Hürde auf dem Weg zum eigenen Online-Shop auf Basis von Magento 2 haben Sie hiermit genommen.

3.2.2    XAMPP für Linux-Systeme

Sie verwenden anstelle von Windows eine Linux-Distribution? Kein Problem, denn unter Linux ist XAMPP ebenfalls verfügbar. Sofern Sie Linux verwenden, haben Sie zwar im direkten Vergleich zu Windows zusätzliche und zum Teil auch sehr einfache alternative Möglichkeiten, eine Webserver-Umgebung aufzusetzen. Aufgrund der Einfachheit lege ich Ihnen an dieser Stelle jedoch den Einsatz von XAMPP ans Herz.

Mögliche Unterschiede aufgrund der Linux-Distribution

Bei Linux ist die Systemvielfalt wesentlich größer als unter Windows. Daher sind pauschale Aussagen zur Installation kompliziert, denn je nach Linux-Distribution können sich der Installationsprozess und die gegebenenfalls auftretenden Probleme stark unterscheiden. Sollten Sie Probleme bei der Installation von XAMPP unter Linux haben, kann ich Ihnen die Webseite und ganz speziell das Diskussionsforum von XAMPP empfehlen. Hier sollten Sie bei auftretenden Problemen fündig werden.

Bei der nun folgenden Installationsanleitung gehe ich von einem auf Debian basierenden System aus. Ich selbst verwende die aktuellste Version von Debian, die Sie kostenlos unter https://www.debian.org/ herunterladen können.

XAMPP unter Linux installieren

Um XAMPP unter Linux zu installieren, gehen Sie zuerst auf die Website von XAMPP, indem Sie die URL http://www.apachefriends.org in Ihrem Browser öffnen. In der oberen Navigationsleiste befindet sich der Link Downloads, auf den Sie nun klicken. Alternativ können Sie an dieser Stelle auch direkt die URL https://www.apachefriends.org/de/download.html aufrufen und gelangen direkt zur Download-Seite. Scrollen Sie ein wenig nach unten, bis Sie die Überschrift »XAMPP für Linux« finden.

Exakt wie bei der XAMPP-Version für Windows existieren auch für Linux verschiedene Versionen. Der Unterschied bei den Versionen liegt in der inkludierten PHP-Version. Wenn Sie XAMPP 5.3.7 herunterladen, wird dieses Paket mit der PHP-Version 5.3.7 ausgelöst. Bei 5.6.23 ist die entsprechende PHP-Version inkludiert, und bei XAMPP 7.0.8 erhalten Sie die aktuellste Version von PHP, nämlich 7.0.8. Da Magento 2 perfekt auf PHP 7 abgestimmt ist, bitte ich Sie an dieser Stelle, diese Version herunterzuladen. Sie müssen hierzu nur auf den Button Download (64 bit) klicken. Sie sollten exakt dieselbe Ansicht wie in Abbildung 3.7 haben, bei der sich auf der rechten Seite der erwähnte Download-Button befindet.

Öffnen Sie hierzu das Terminal, und wechseln Sie in den Root-User, indem Sie in die Konsole su eingeben. Daraufhin werden Sie nach einem Passwort gefragt, das Sie an dieser Stelle eingeben. Bei alternativen Linux-Distributionen wie z. B. Ubuntu ist es nicht nötig bzw. möglich, an dieser Stelle per su den Benutzer zu wechseln. Im Fall von Ubuntu müssten Sie beim nächsten Befehl, den Sie ein paar Zeilen weiter finden, ein sudo davorstellen. Das Prinzip und das Ziel sind in beiden Fällen identisch. Um XAMPP installieren zu können, müssen Sie sich als Administrator bzw. Benutzer mit Root-Rechten anmelden, da Sie die Installation ansonsten nicht durchführen können. Sobald Sie sich als Benutzer mit Root-Rechten angemeldet haben, führen Sie bitte folgenden Befehl aus: chmod 755 xampp-linux-*-installer.run, wobei Sie das * durch die entsprechende Version von XAMPP ersetzen müssen. Den Pfad zu dieser Datei müssen Sie an dieser Stelle ebenso selbstständig anpassen, je nachdem in welchen Ordner Sie das soeben heruntergeladene Setup-Paket heruntergeladen haben. Durch das Setzen der Berechtigungen haben Sie anschließend die Möglichkeit, XAMPP zu installieren. Geben Sie hierzu folgenden Befehl in die Konsole ein: ./xampp-linux-*-installer.run. Die XAMPP Developer Files, bestehend aus Dokumentationen und weiterführenden Informationen, können Sie zwar abwählen, ich würde Ihnen die Installation aber empfehlen. Der Speicherplatzbedarf hält sich in Grenzen, und Sie haben durch die Installation keinerlei Nachteile. Gegebenenfalls möchten Sie zukünftig auf die eine oder andere Dokumentation zurückgreifen, weswegen sich die Installation der Developer Files lohnen kann. Belassen Sie daher die Auswahl, und klicken Sie auf Next. Es bleibt Ihnen auch an dieser Stelle nur der Klick auf Next als Option übrig. Daraufhin erhalten Sie, ähnlich wie bei der Windows-Version, weiterführende Informationen zu Bitnami, wobei Sie an dieser Stelle den Haken entfernen und auf next klicken können, vorausgesetzt, Sie interessieren sich zu diesem Zeitpunkt nicht für Bitnami.

Was ist Bitnami?

Bitnami stellt für verschiedene Projekte, z. B. Wordpress oder Magento, fertig konfigurierte, leicht zu installierende Anwendungspakete zum Download bereit. Die Pakete sind teilweise kostenlos, zum Teil aber auch kostenpflichtig. Bei den kostenpflichtigen Paketen erhalten Sie unter anderem einen Support. Wenn Sie mehr über Bitnami erfahren möchten, können Sie weiterführende Informationen auf der Website https://bitnami.com einsehen.

Anschließend beginnt XAMPP mit der Installation der Pakete, wobei der Installationsprozess in der Regel nur wenige Minuten dauert. Sobald die Installation abgeschlossen ist, erhalten Sie eine Meldung, wie sie in Abbildung 3.9 zu sehen ist, und Sie können auf den Button Finish klicken.

Glückwunsch! Sie haben XAMPP für Linux erfolgreich installiert und damit die Basis für die Installation von Magento geschaffen. Nach der Installation wird XAMPP standardmäßig gestartet, und die installierten Dienste stehen Ihnen zur Verfügung. Sie haben aber natürlich die Möglichkeit, XAMPP manuell zu stoppen bzw. manuell zu starten. Hierfür sind folgende Konsolenbefehle notwendig:

XAMPP starten: /opt/lampp/lampp start

XAMPP stoppen: /opt/lampp/lampp stop

Die Befehle müssen Sie als Administrator ausführen, ansonsten erhalten Sie eine Fehlermeldung wie »You need to be root to perform this action«.

Konfigurationsanpassungen für Linux

Sollten Sie den XAMPP-Installationsteil für Windows überflogen haben, wird Ihnen sicherlich der Abschnitt hinsichtlich der Konfigurationsanpassungen aufgefallen sein. Bei der Windows-Variante von XAMPP fehlen einige PHP-Module bzw. -Extensions, die für den reibungslosen Betrieb von Magento vorausgesetzt werden. Glücklicherweise ist dies bei der Linux-Variante von XAMPP nicht der Fall. Sprich, Sie können nach der Installation von XAMPP unter Linux Magento 2 problemlos installieren, ohne weitere Eingriffe in die Konfiguration tätigen zu müssen. Dennoch empfehle ich Ihnen an dieser Stelle die Modifikation von zwei Parametern innerhalb der PHP-Konfiguration. Diese sind zwar nicht zwangsläufig notwendig, aber empfehlenswert, da sie die Performance von Magento steigern.

Öffnen Sie zuerst das Terminal, und wechseln Sie durch die Eingabe von su den Benutzer, um Root-Rechte zu erlangen. Sobald Sie dies erledigt haben, geben Sie folgenden Befehl in das Terminal ein:

vim /opt/lampp/etc/php.ini

Bitte beachten Sie, dass Sie für die Ausführung dieses Befehls das Programm Vim installiert haben müssen. Alternativ können Sie aber jeden beliebigen Editor für die Bearbeitung der php.ini-Datei verwenden, z. B. vi oder nano. Wenn Ihnen das Terminal nicht liegt, können Sie die Bearbeitung der Datei ebenfalls mithilfe eines grafischen Editors vornehmen. Wichtig ist letztendlich nur, dass Sie die Bearbeitung mit Root-Rechten durchführen, da Sie die Datei ansonsten nicht speichern können.

Sobald Sie die Datei geöffnet haben, nehmen Sie folgende Anpassungen vor. Suchen Sie die Zeile memory_limit = 128M, und ändern Sie diese in memory_limit = 512M ab. Anschließend suchen Sie die Zeile max_execution_time = 30 und ändern diese in max_execution_time = 360. Speichern Sie anschließend die Datei, und starten Sie den Webserver neu, indem Sie im Terminal die Befehle /opt/lampp/lampp start sowie /opt/lampp/lampp stop ausführen. Durch die beiden getätigten Anpassungen haben Sie zum einen das Speicherlimit erhöht, denn Magento läuft mit »nur« 128 MB etwas unrund. Zum anderen haben Sie die Scriptlaufzeit von 30 Sekunden auf sechs Minuten erhöht. Dadurch gewähren Sie Magento eine längere Ausführungszeit, was an der einen oder anderen Stelle zu einer Fehlervermeidung innerhalb des Systems führt.

Linux-Benutzer haben in der Regel ein sehr gutes Systemwissen

Verzeihen Sie mir an der einen oder anderen Stelle die inhaltliche Abkürzung bei der Installation und Konfiguration von XAMPP unter Linux. Sofern es sich bei Ihnen um einen Linux-Benutzer handelt, unterstelle ich Ihnen in diesem Buch ein gewisses Systemwissen, wodurch ich auf Installationsanweisungen und Nutzungshinweise zu beispielsweise Vim verzichte. Aufgrund der Vielfältigkeit und der unterschiedlichen Distributionen von Linux würde eine Detailerklärung den Rahmen dieses Buches sprengen. Sollten Sie vor größeren Problemen beim Setup unter Linux stehen, kann ich Ihnen alternativ die Nutzung der MageVM empfehlen, die im Verlauf dieses Kapitels im Detail beschrieben wird.

Glückwunsch, Sie haben mit dieser letzten Konfigurationsanpassung den Grundstein für die Installation von Magento 2 auf Ihrem System gelegt und sind somit ideal vorbereitet. Technische Hürden dürften Ihnen somit nicht mehr im Weg stehen.

3.2.3    MAMP für macOS-Systeme

Das Betriebssystem macOS von Apple erfreut sich mittlerweile speziell im Bereich der Webentwicklung und bei den Internetagenturen sehr großer Beliebtheit. Aus diesem Grund dürften die Chancen, dass Sie dieses Betriebssystem verwenden, gar nicht so gering sein. Leider gibt es ganz im Gegensatz zu Windows und Linux mit XAMPP unter macOS speziell in der Verbindung zu Magento einige Probleme. Würden Sie auf XAMPP setzen, müssten Sie eine Vielzahl von Konfigurationsparametern anpassen und Module nachinstallieren. Da ich Ihnen diese Arbeit an dieser Stelle ersparen möchte, empfehle ich Ihnen als macOS-Benutzer die Verwendung von MAMP. Hierbei handelt es sich, ganz wie bei XAMPP, um ein vorkonfiguriertes Setup bestehend aus Webserver und MySQL-Datenbankserver, auf dessen Basis Sie relativ einfach eine Magento-Instanz aufsetzen können.

Um MAMP für macOS zu installieren, rufen Sie im ersten Schritt die Website des XAMPP-Projekts unter https://www.mamp.info auf und klicken anschließend in der oberen Navigationsleiste auf Downloads. Anschließend erhalten Sie eine Auflistung der verschiedenen MAMP-Versionen für die Betriebssysteme Windows und macOS bzw. OS X. Neben den bisher veröffentlichten Versionen können Sie direkt die aktuelle Version von MAMP herunterladen. Zum Zeitpunkt, als ich dieses Kapitel verfasst habe, handelte es sich um die Version 3.5.2, die mit PHP 7 ausgeliefert wird. Klicken Sie jetzt auf Download, um MAMP herunterzuladen.

Insgesamt existieren zwei Varianten von MAMP. Zum einen gibt es das klassische MAMP, das vollkommen kostenfrei verwendet werden kann. In Ihrem Fall reicht die kostenfreie Version jedoch aus. Sie müssen daher nicht die Befürchtung haben, dass im späteren Verlauf gegebenenfalls Kosten entstehen. Alle Übungen dieses Buches können problemlos mit der kostenfreien Version durchgeführt werden.

Klicken Sie auf den Button Fortfahren, um die Installation fortzusetzen. In der nächsten Ansicht werden Sie darauf hingewiesen, dass MAMP zwei Verzeichnisse anlegt, eines für die kostenfreie sowie eines für die kostenpflichtige Version. An dieser Tatsache können Sie relativ wenig ändern, weswegen Sie auf Fortfahren klicken, um den nächsten Schritt der Installation zu erreichen. Akzeptieren Sie im darauffolgenden Dialog den Lizenzvertrag, indem Sie auf den Button Fortfahren klicken und den darauffolgenden Dialog ebenfalls bestätigen. Nun müssen Sie das Zielvolumen auswählen. Konfigurationsanpassungen für macOS

Bevor Sie später mit der Installation von Magento beginnen können, sollten Sie im Vorfeld noch Konfigurationsanpassungen an PHP vornehmen. Dabei handelt es sich um zwei Parameter, die ich aus Gründen der Performance anpassen würde, die aber nicht zwangsläufig angepasst werden müssen. Magento könnten Sie auch ohne diese Konfigurationsanpassungen installieren, letztendlich geht es nur darum, dass Magento noch besser und geschmeidiger ausgeführt werden kann.

Begeben Sie sich erneut in den Finder, und öffnen Sie den Reiter Programme. Gehen Sie anschließend in das Verzeichnis MAMP/bin/php/php7.0.8/conf, und öffnen Sie die Datei php.ini mit einem Texteditor Ihrer Wahl. Sollten Sie keinen speziellen Texteditor installiert haben, kann ich Ihnen die Verwendung von Textedit empfehlen. Dieser Editor wird standardmäßig mit macOS ausgeliefert und erfüllt seine Aufgabe perfekt.

Suchen Sie nun die Zeile memory_limit = 128M und ersetzen Sie 128M durch 1024M. Dadurch erhält Magento bzw. der PHP-Prozess mehr Arbeitsspeicher, was an der einen oder anderen Stelle förderlich sein wird. Daraufhin suchen Sie die Zeile max_execution_time = 30 und ersetzen die 30 durch eine 360. Sollte ein PHP-Prozess länger als 30 Sekunden laufen, wird er nun nicht mehr abgebrochen, sondern erhält einfach mehr Zeit. Auch das wird Ihnen an der einen oder anderen Stelle helfen, Probleme zu vermeiden.

Speichern Sie nach diesen beiden Änderungen die Datei, und starten Sie den Webserver über die MAMP-Anwendung neu. Anschließend greifen Ihre Konfigurationseinstellungen, die Sie soeben gesetzt haben.

Unterschiede zu XAMPP

Bitte berücksichtigen Sie, dass es, speziell wenn es um die Installation von Magento geht, zwischen MAMP und XAMPP ein paar Unterschiede gibt. Unter MAMP lautet zum einen Ihre lokale Domain nicht http://localhost, sondern http://localhost:8888, zum anderen verfügt der MySQL-Benutzer unter MAMP über ein Passwort namens root. Sieht man von diesen beiden Besonderheiten ab, auch wenn es zusätzlich noch weitere gibt, die Sie aber nicht betreffen, gibt es keine speziellen Punkte, die Sie bei der Nutzung von MAMP beachten müssten. Sollten Sie dennoch Fragen haben oder vor Problemen stehen, empfehle ich einen Besuch der offiziellen Website unter https://www.mamp.info. Neben einer Dokumentation können Sie über die Website auch Kontakt zu Gleichgesinnten aufnehmen, die bei Fragen oder Problemen zur Verfügung stehen. Diese tummeln sich primär auf der Plattform Stackoverflow, die auf der offiziellen Website von MAMP entsprechend verlinkt ist.
