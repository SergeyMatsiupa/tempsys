20.3    Anbindung von externen Lösungen an Magento auf Basis von Synesty

Der Anbieter Synesty hat eine Art Datendrehscheibe entwickelt, mit deren Hilfe Sie mehrere Systeme miteinander verbinden und Daten zwischen den Systemen austauschen können. Die Datendrehscheibe selbst verfügt über verschiedene Konnektoren, die Daten z. B. von Magento 2 aufnehmen, aber auch anderen Systemen bereitstellen kann. Mithilfe dieses Mechanismus können Sie beispielsweise Bestellungen aus Ihrem Magento-System exportieren, bei Synesty speichern und aus dem Datenspeicher bei Synesty einem ERP-System, beispielsweise Plentymarkets, bereitstellen. Der umgekehrte Weg ist auch denkbar, sprich, Sie verwalten in Plentymarkets Produkte und stellen diese mittels Synesty Ihrem Magento-System bereit. Zugegebenermaßen handelt es sich hierbei um eine recht einfache Form der Anbindung. Wenn Sie eine individuelle Schnittstelle entwickeln würden, würden Sie natürlich nicht die Daten nochmals in einem separaten Bereich zwischenparken und transferieren. Viel eher würden Sie eine direkte Anbindung zwischen den Systemen entwickeln, da dadurch die Reaktionszeiten wesentlich geringer sind und die Daten in den jeweiligen Systemen zeitnah bereitstehen. Der große Vorteil von Synesty liegt aber darin, dass Sie eben nicht mit zusätzlichen Entwicklungsaufwänden rechnen müssen, weswegen diese Lösung für gewisse Szenarien sicherlich vollkommen in Ordnung ist. Auf den folgenden Seiten möchte ich Ihnen anhand eines kleinen Beispiels zeigen, wie Sie Synesty nutzen können.

Im ersten Schritt benötigen Sie einen Account bei Synesty, den Sie vorerst kostenlos anlegen können. Auch wenn für die Nutzung von Synesty Gebühren anfallen, können Sie die Lösung im ersten Moment vollkommen kostenfrei testen. Sie kaufen also nicht die Katze im Sack, sondern können sich selbst ein Bild von der Lösung machen. Das ist definitiv ein Punkt, der für diese Lösung spricht!

Um einen Account anzulegen, öffnen Sie bitte die URL https://synesty.com, und klicken Sie auf den Button Kostenlos & unverbindlich testen, der sich in der Hauptnavigation befindet. 20.3.3    Übertragene Daten einsehen

Auf den vorherigen Seiten haben Sie gesehen, wie einfach man Magento an Synesty anbinden kann. Die Anbindung von Magento ist aber nur der erste Schritt, da Synesty die Daten, die durch den Flow definiert werden, zunächst nur zwischenspeichert. Dieser Zwischenspeicher ist später für den Export der Daten essenziell, Sie können aber innerhalb der Oberfläche auch einfach nur einen Blick in den Zwischenspeicher werfen, um zu prüfen, welche Informationen Magento bereitgestellt hat bzw. importiert wurden.

Navigieren Sie nun zum Dashboard, und klicken Sie in der Hauptnavigation auf den Punkt Datastores. Sie erhalten daraufhin eine Auflistung der verschiedenen Datastores, d. h., es kann mehrere dieser Datentöpfe im System geben, auf die Sie später zurückgreifen können. Aktuell dürfte jedoch nur einer dieser Datentöpfe vorhanden sein. Klicken Sie bitte auf Magento2-Orders, um zu den Details zu gelangen. Als Ergebnis erhalten Sie eine Auflistung (siehe Abbildung 20.8) aller im System vorhandenen Bestelldaten, die durch die Synesty-Schnittstelle von Magento importiert wurden.

Abbildung 20.8    Synesty speichert alle Informationen aus angebundenen Systemen im sogenannten »Datastore«.

Datastores sind Datentöpfe, die befüllt und angezapft werden können

Innerhalb von Synesty können Sie mehrere Datastores erstellen, die vollkommen autark voneinander agieren können. Ein Datastore stellt dabei eine logische Einheit dar, so haben Sie einen Datastore für Bestellungen, einen Datastore für Produkte etc. Zugleich haben Sie natürlich die Möglichkeit, beliebig viele Datastores anzulegen. Auch die Nutzung von Mapping-Tabellen, die speziell beim Datenimport relevant sind, ist möglich.

Wenn Sie sich die Daten innerhalb des Datastores Magento2-Orders im Detail ansehen, werden Sie feststellen, dass alle relevanten Informationen einer Bestellung importiert wurden. Hierzu zählen die Zahlungsmethode, die Rechnungs- sowie die Lieferadresse, die E‐Mail-Adresse des Kunden, die gewählte Versandmethode usw. Die Informationen, die in Magento bei einer Bestellung bereitstehen, wurden also sauber übergeben und gespeichert.

Neben der Auflistung aller im System vorhandenen Bestellungen finden Sie bei jedem Datensatz eine Detailansicht, die Sie öffnen können. Klicken Sie hierzu beim gewünschten Datensatz einfach auf den Button anzeigen, der sich in der zweiten Spalte befindet, worauf Synesty Sie zu einer neuen Ansicht weiterleitet. In dieser Ansicht sehen Sie nochmals alle importierten Felder samt importierten Werten in übersichtlicher Form aufgelistet. Auch haben Sie in dieser Ansicht die Möglichkeit, bereits importierte Werte abzuändern und zu überschreiben. Gerade zu Testzwecken kann dies eine ganz nützliche Funktion sein, da Sie nach dem Import der Daten direkt eingreifen können und nicht zwangsläufig einen neuen Import starten müssen. Neben der Möglichkeit, bestehende Daten abzuändern, können Sie zudem den gesamten Datensatz löschen und somit aus dem System entfernen. Eine Historie zeigt Ihnen an, wie sich die importierten Werte gegenüber dem letzten Import verändert haben. Somit haben Sie immer direkt im Blick, welche Werte durch einen späteren Import angefasst wurden und vor allem was der ursprüngliche Wert war. Zusammengefasst können Sie innerhalb der Detailansicht die importierten Werte prüfen bzw. abändern, haben zudem eine Art Historie zur Hand und sehen vor allem, durch welchen Flow die Werte bereitgestellt wurden.

Mit diesen wenigen Schritten, die Sie auf den letzten Seiten gesehen haben, konnten Sie Magento relativ einfach an Synesty anbinden und haben zudem alle im System vorhandenen Bestellungen an Synesty übertragen. Das ist an sich die halbe Miete, aber richtig sinnvoll ist Synesty natürlich nur dann, wenn Sie die importierten Werte einer weiteren Applikation wie einem ERP-System bereitstellen. Als Beispiel für dieses Kapitel zeige ich Ihnen die Datenübergabe zu Actindo, die auf eine recht einfache Art und Weise erfolgt. In der Praxis werden Sie die Datenübertragung, das kann ich Ihnen an dieser Stelle schon sagen, sicherlich etwas eleganter lösen. Zu Demonstrationszwecken ist die jetzt folgende Methodik aber die einfachste und verständlichste.

20.3.4    Bestelldaten transformieren und exportieren

Aktuell liegen alle Bestellungen, die Synesty aus Magento importiert hat, im Datastore. Auf Basis des Datastores können Sie nun z. B. weitere Flows erstellen, die den Datastore anzapfen, die Daten extrahieren und direkt in eine Schnittstelle übergeben. Alternativ hierzu können Sie aber auch einfach den Datastore filtern und eine CSV-Datei ausleiten, die per E‐Mail versendet oder per FTP hochgeladen wird. In meinem folgenden Beispiel gehe ich von einer halbautomatisierten Schnittstelle aus, bei der ich einer Person regelmäßig per E‐Mail Bestelldatenexporte zusenden möchte. Die Person, in diesem Fall handelt es sich um mich, nimmt dann diesen Bestelldatenexport und importiert die Bestellungen nach Erhalt in Actindo.

Begeben Sie sich jetzt bitte, sofern Sie abgemeldet sind, wieder in die Synesty-Applikation, und klicken Sie in der oberen Navigation auf den Link Projekte. Sie erhalten eine Auflistung aller in Synesty angelegten Projekte, wobei Sie das einzig vorhandene Projekt namens Magento2 - Bestellungen abrufen auswählen. Sie gelangen zur Auflistung der Flows. Da Sie jetzt einen neuen Flow erstellen müssen, der den Datenexport regelt, klicken Sie auf den Button Flow erstellen. Eine Textbox erscheint, in der Sie den Namen des Flows eingeben müssen. Sie können eine beliebige Bezeichnung wählen, ich verwende an dieser Stelle jedoch den Namen »Export der Bestellungen als CSV und Versand per E‐Mail«. Als Nächstes gelangen Sie in die Detailansicht des Flows, in der Sie die jeweiligen Schritte definieren können. Wenn Sie auf eine Vorlage setzen wie beim Beispiel des Magento-Bestelldatenimports, sind die Schritte bereits vorkonfiguriert. Aktuell verwenden Sie aber keine Vorlage, d. h., Sie müssen den Flow von Grund auf selbst bauen. Scrollen Sie jetzt ein wenig nach unten, bis Sie bei der Überschrift »Vorschläge für Ihren ersten Step:« landen. Da Sie im ersten Schritt, d. h. bevor Daten exportiert werden können, die Daten aus dem Datastore laden müssen, klicken Sie auf den Button SearchDatastore. Denn dieser Schritt ist für den Abruf der Daten aus dem Datastore verantwortlich und erlaubt zudem noch eine Filterung und Einschränkung der Daten. Wenn Sie auf SearchDatastore geklickt haben, wird automatisch der neue Schritt hinzugefügt. Fahren Sie mit der Maus über den soeben hinzugefügten Schritt und klicken Sie auf das Zahnradsymbol, woraufhin sich das Fenster »Step Konfiguration« öffnet. In diesem Fenster wählen Sie bitte bei der Option »datastoreName« den einzig vorhandenen Datastore aus, und klicken Sie auf Speichern. Anschließend können Sie das Fenster schließen. Wie erwähnt, könnten Sie auch noch Filter setzen und die Ergebnismenge einschränken, meiner Meinung nach müssen Sie dies zum jetzigen Zeitpunkt aber nicht tun. Nachdem Sie diesen Schritt hinzugefügt und konfiguriert haben, weiß Synesty nun, dass Sie die Daten aus dem Datastore abholen möchten. Sprich, die Daten stehen zur Verfügung, jetzt müssen Sie aber entscheiden, was Sie mit den Daten tun möchten. Für eine Ausleitung als CSV-Datei, was aktuell mein Plan ist, müssen Sie im nächsten Schritt auf den Button Step hinzufügen klicken. Es öffnet sich ein Fenster, in dem Sie aus einer Vielzahl von Aktionen auswählen können. Suchen Sie an dieser Stelle nach dem Eintrag SpreadsheetCSVWriter, und fügen Sie diesem Ihrem Flow hinzu. Dieser Schritt bzw. diese Aktion ermöglicht, sofern Synesty eine Quelle hat, den Export der Daten, die aus dieser Quelle stammen, im CSV-Format. Sobald der Schritt hinzugefügt wurde, fahren Sie mit der Maus über den Schritt und klicken Sie auf das Zahnradsymbol. Die Quelle, die als Grundlage dient, ist Synesty direkt klar. Hierfür wird der vorherige Schritt automatisch genutzt, d. h., eine Quelle müssen Sie an dieser Stelle nicht mehr angeben. Dafür ist es wichtig, einen Dateinamen zu hinterlegen, den Sie im Feld filename eingeben können. Wie Sie in Abbildung 20.9 sehen, haben Sie zudem die Möglichkeit, den grundlegenden Aufbau der CSV-Datei zu beeinflussen, was Sie jedoch an dieser Stelle nicht tun müssen.

Abbildung 20.9    Beim Export der Bestellungen können Sie auf den grundlegenden Aufbau der CSV-Datei einwirken.

Klicken Sie, nachdem Sie einen Dateinamen hinterlegt haben, auf speichern, und schließen Sie das Fenster. Sie haben jetzt die Ausleitung der zuvor definierten Quelle bestimmt, damit sind Sie so gut wie fertig. Wichtig ist nun noch das Handling, d. h., was Synesty mit der CSV-Datei anstellen soll. Beispielsweise können Sie die generierte CSV-Datei per FTP auf einen FTP-Server laden oder eben per E‐Mail versenden. Fügen Sie einen dritten und letzten Schritt hinzu, und wählen Sie dabei die Aktion EmailSend aus. Fahren Sie wieder mit der Maus über den hinzugefügten Schritt, und klicken Sie auf das Zahnradsymbol. Anschließend speichern Sie die Einstellungen und schließen das Fenster.

Wenn Sie meinen Schritten gefolgt sind, werden Sie jetzt insgesamt drei Schritte in Ihrem Flow vorfinden, die alle Bestelldaten aus dem Datastore abrufen, eine CSV-Datei daraus erstellen und diese CSV-Datei per E‐Mail versenden. Damit sind exakt die Anforderungen erfüllt, die ich eingangs erwähnt hatte. Prüfen Sie bitte, ob Ihr Flow nun genauso arbeitet. Als Vergleich können Sie sich an Abbildung 20.10 orientieren, die meinen Flow abbildet.

Abbildung 20.10    Der soeben erstellte Flow ruft alle Bestellungen ab, speichert diese als CSV-Datei und versendet anschließend die CSV-Datei per E‐Mail.

Sollte Ihr Flow bereit sein, aktivieren Sie diesen, und klicken Sie auf den Button Flow ausführen. Innerhalb weniger Sekunden sollten Sie per E‐Mail eine CSV-Datei erhalten, die alle Bestellungen, die im Datastore vorhanden sind, enthält. 20.3.5    Actindo-Test-Account erstellen

Bei Actindo handelt es sich um eine webbasierte ERP-Lösung, die einen recht großen Funktionsumfang besitzt. Ob die Lösung für Sie tatsächlich infrage kommt, kann ich Ihnen an dieser Stelle nicht beantworten. Denn wie die Auswahl einer E-Commerce-Lösung hängt die Auswahl einer ERP-Lösung von verschiedenen Faktoren ab.

Auf Basis von Anforderungen, einem verfügbaren Budget, rechtlichen Rahmenbedingungen und zum Teil auch auf Basis der Usability lassen sich ein oder zwei mögliche ERP-Systeme eingrenzen und lässt sich anschließend eine Auswahl treffen. Da der Auswahlprozess an dieser Stelle den Umfang sprengen würde und es mir in erster Linie um eine exemplarische Anbindung von Magento bzw. Synesty geht, empfehle ich Ihnen an dieser Stelle die Nutzung von Plentymarkets. Da keinerlei Lizenzkosten anfallen, zumindest nicht in der Testversion, die ich gleich auswähle, können Sie alle Schritte nachvollziehen, ohne zuerst eine Software lizenzieren zu müssen. Ziel ist es im Folgenden, die in Synesty durch Magento bereitgestellten Bestellungen zur ERP-Lösung Plentymarkets zu exportieren, sodass Bestellungen im ERP-System weiterverarbeitet werden können.

Um einen Actindo-Account zu erstellen, öffnen Sie bitte die offizielle Website https://www.actindo.de/, und klicken Sie im mittleren Bereich der Seite auf den Button Zur Anmeldung. Es öffnet sich daraufhin ein neues Fenster, in dem Sie sich einen Account anlegen können. Füllen Sie, um die Anmeldung zu finalisieren, einfach alle Formularfelder aus. Haben Sie dies getan, klicken Sie auf den Button Absenden. Daraufhin wird ein Testsystem erstellt, was einige Minuten dauern kann. Zeit für eine Kaffeepause!

Nach einigen Minuten erhalten Sie eine Bestätigungsmail, die einen Bestätigungslink enthält. Klicken Sie auf diesen Link, um im Anschluss per E‐Mail die Zugangsdaten zu erhalten. Melden Sie sich, sobald Sie die E‐Mail samt Zugangsdaten erhalten haben, im nächsten Schritt bitte in Actindo an, um mit der Anbindung bzw. dem Datenimport von Synesty fortzufahren. Nachdem Sie sich erfolgreich bei Actindo angemeldet haben, sollten Sie direkt im Dashboard, also der Startseite von Actindo landen. Damit haben Sie die erste Hürde genommen und erfolgreich einen Actindo-Account erstellt, der jetzt im nächsten Schritt an Synesty angebunden werden kann.

20.3.6    Bestellungen in Actindo importieren

Actindo ist ein wahnsinnig umfangreiches und komplexes System, verzeihen Sie mir daher an dieser Stelle, wenn ich Sie eher im Schnelldurchgang durch das System führe. Über Actindo selbst könnte man gut und gern allein ein Buch im selben Umfang wie das Magento-2-Handbuch verfassen.

Wenn Sie bestehende Bestellungen importieren möchten, klicken Sie im linken Menü auf den Eintrag Faktura und innerhalb von Faktura auf Extras • Import Neu. Werfen Sie zur besseren Orientierung einen Blick auf Abbildung 20.11, in der Sie beide Menüpunkte sehen.

Sobald Sie auf Import Neu geklickt haben, öffnet sich ein neues Fenster. Zuerst werden Sie gefragt, was Sie importieren möchten. Wählen Sie an dieser Stelle aus dem Dropdown-Menü den Eintrag Belege. Da an dieser Stelle keine Definition vorhanden ist, klicken Sie auf weiter, um in den nächsten Schritt zu gelangen. In der nächsten Ansicht müssen Sie einen Datentyp wählen. Da Synesty die Bestellungen im CSV-Format exportiert hat, wählen Sie bitte den Eintrag CSV aus. Bei der Datei, hierbei handelt es sich um das nächste Feld, können Sie die Datei auswählen, die Ihnen per E‐Mail von Synesty bereitgestellt wurde. Klicken Sie, nachdem Sie die Datei ausgewählt haben, auf weiter. Nun wird es spannend, denn Sie müssen Actindo den Aufbau der CSV-Datei mitteilen.

Abbildung 20.11    In Actindo finden Sie die Import-Funktion im Menüpunkt Faktura.

Abbildung 20.12    Nachdem Sie die Struktur angepasst haben, erscheinen in der Vorschau direkt die Datensätze.

Wählen Sie beim Feldtrennzeichen das Semikolon aus, daraufhin wird Actindo als Vorschau die in der CSV-Datei enthaltenen Daten bereits korrekt darstellen, wie Sie in Abbildung 20.12 sehen. Je nachdem wie Sie Ihre CSV-Datei aufbauen, müssen Sie an dieser Stelle noch Anpassungen vornehmen. Am wichtigsten sind letztendlich das Trennzeichen und die Frage, ob die Werte umschlossen sind. Der Zeichensatz spielt beispielsweise eher bei Sonderzeichen eine Rolle, d. h., hier müssen Sie sich erst darum kümmern, wenn Sonderzeichen nicht korrekt importiert werden. Sofern bei Ihnen die Vorschau, genau wie bei mir in Abbildung 20.12, in Ordnung aussieht, klicken Sie bitte auf weiter.

Mit jetzigem Stand weiß Actindo, wie Ihre CSV-Datei aufgebaut ist und in welchen Zeichensatz die Daten eingelesen werden können. Da die Feldbezeichnungen in Actindo jedoch nicht identisch mit denen in Magento sind, erfolgt im nächsten Schritt ein Mapping. Sprich, Sie müssen Actindo mitteilen, welchem Feld in Actindo die Spalten, die in der CSV-Datei enthalten sind, entsprechen. Glücklicherweise ist die Auswahl recht einfach: Sie können per Drag & Drop die Felder, die von Actindo vorgegeben werden, auf die in der CSV-Datei enthaltenen Spalten ziehen. Ziehen Sie beispielsweise die Belegnummer auf die Spalte B, das Belegdatum auf die Spalte FE, den Vornamen auf die Spalte AJ etc. Bitte beachten Sie, dass bei Ihnen die Spalten verschoben sein können. Daher müssen Sie schauen, ob die Feldzuordnung bei Ihnen genauso funktioniert oder ob Sie andere Spaltenbezeichnungen als ich haben.

Nachdem Sie die Feldzuordnungen vorgenommen haben, was beim ersten Mal zugegebenermaßen etwas mühselig ist, klicken Sie auf weiter. Actindo zeigt Ihnen daraufhin in einer Art Übersicht die Werte samt Zuordnung an, und sofern das für Sie in Ordnung ist, können Sie mit einem Klick auf weiter in den nächsten Schritt springen. Actindo versucht nun, die Daten zu importieren, und wird Ihnen zudem zurückmelden, falls ein Fehler vorhanden ist. Ist mit Ihrer CSV-Datei bzw. dem Import so weit alles in Ordnung, erhalten Sie ein grünes Licht wie in Abbildung 20.13.

Abbildung 20.13    Jeder Datensatz, der importiert werden soll, wird entweder durch ein rotes oder grünes Licht gekennzeichnet,

Bei jedem Datensatz mit einem grünen Licht wissen Sie sofort, dass dieser importiert werden konnte. Wird hingegen eine rote Ampel dargestellt, sollten Sie mit der Maus über diese rote Ampel fahren. Daraufhin erhalten Sie eine detaillierte Fehlermeldung und wissen sofort, warum der Datensatz nicht importiert werden kann, sodass Sie dementsprechend nachjustieren können. Ansonsten sind Sie an dieser Stelle mit dem Import fertig und können nun das Fenster schließen.

In Actindo selbst müssen Sie jetzt noch prüfen, ob die Daten tatsächlich erfolgreich übernommen wurden. Klicken Sie hierfür auf Faktura • Verkauf • Übersicht. Innerhalb dieser Maske werden alle Aufträge, die im Actindo-System eingegangen sind, aufgelistet. An dieser Stelle muss nun genau wie bei mir ein neuer Datensatz auftauchen. Dieser Datensatz sollte exakt die Informationen enthalten, die beim Export aus Synesty bereitgestellt wurden. Klicken Sie mit der rechten Maustaste auf den Datensatz, und wechseln Sie in den Tab Liefer-Adresse. Werfen Sie jetzt bitte einen Blick auf Abbildung 20.14, denn wie Sie sehen, ist exakt die Lieferadresse aus der Magento-Bestellung, die diese Bestellnummer trägt, enthalten.

Abbildung 20.14    Nach dem Datenimport stehen beim Auftrag alle durch den Import bereitgestellten Daten zur Verfügung.

Schauen Sie sich in diesem Zuge gern alle Informationen an, die in diesem Auftrag enthalten sind, und vergleichen Sie die Daten mit denen der Magento-Bestellung. Sollten Sie bei der Feldzuordnung keine Fehler gemacht haben, so müssen an sich alle Daten korrekt übermittelt und importiert worden sein.

Herzlichen Glückwunsch, Sie haben erfolgreich Daten aus Magento exportiert und in Actindo importiert und dabei die Datendrehscheibe Synesty verwendet! Wenn Sie eine Anbindung auf Basis von CSV-Dateien vornehmen, können Sie praktisch jedes beliebige System anbinden, das den Import von CSV-Dateien unterstützt! Ansonsten haben Sie mit Synesty zudem die Möglichkeit, via REST API jedes beliebige System anzubinden, das eine REST-Schnittstelle zur Verfügung stellt.

20.3.7    Sonstige Funktionen von Synesty

Auch wenn ich Ihnen die Lösung von Synesty aufgrund des Umfangs nicht im Detail erklären kann – bei Bedarf können Sie sich direkt von Synesty eine Einführung geben lassen –, möchte ich an dieser Stelle ein paar ausgewählte Funktionen und Möglichkeiten erwähnen, die bislang keine Erwähnung gefunden haben.

Dashboard

Ähnlich wie bei Magento steht auch in Synesty ein Dashboard zur Verfügung, das Ihnen viele Informationen auf recht schnelle und einfache Art zugänglich macht. So erhalten Sie in der Box Aktuelles & Forum Informationen, die direkt das Produkt Synesty betreffen. Da sich Schnittstellen ändern und dadurch Nebeneffekte entstehen können, lohnt sich ein regelmäßiger Blick in diesen Bereich. Gegebenenfalls wurde etwas in Magento, Plentymarkets oder einer weiteren Lösung, die Sie angebunden haben, angepasst. Gegebenenfalls wurde auch ein Fehler entdeckt, der für Sie eine Rolle spielt. Zudem können Sie aus dem Dashboard heraus direkt Flows erstellen und erhalten im Dashboard eine Übersicht über die laufenden Aktivitäten. Hier sehen Sie sofort, wenn es beim Datenaustausch hakt (siehe Abbildung 20.15).

Abbildung 20.15    Im Dashboard sehen Sie sofort, ob es Probleme beim Datenaustausch gibt.

Neben den Aktivitäten befindet sich zudem ein Chart samt Statistik, der Sie ebenfalls über die Funktionsfähigkeit Ihrer Schnittstellen informiert. Die Anforderung an ein Dashboard, d. h. die übersichtliche Bereitstellung der relevantesten Informationen, wird von Synesty daher sehr gut erfüllt.

Meine Verbindungen

Den Punkt Meine Verbindungen hatte ich auf den vorherigen Seiten zwar bereits erwähnt, ich möchte ihn an dieser Stelle jedoch nochmals herausstellen, da es sich um einen der wichtigeren Bereiche in Synesty handelt. Wenn Sie auf Mein Konto • Meine Verbindungen klicken, gelangen Sie zur Übersicht aller anzubindenden Systeme. An dieser Stelle verwalten Sie zudem die Verbindungsdaten, d. h., sollte sich der Benutzer oder das Passwort Ihres Magento-Benutzers ändern, müssen Sie diese Änderungen hier einpflegen. Sie haben in diesem Menüpunkt somit die Möglichkeit, alle vorhandenen Verbindungen zu verwalten und neue hinzuzufügen.

Support

Während meiner Testphase bin ich mehrmals in die Situation gekommen, den Support von Synesty kontaktieren zu müssen. Bevor es jedoch so weit kommt, können Sie im Menüpunkt Support auf eine umfangreiche Knowledge-Base zurückgreifen. Aktuell sind mehr als 250 Fragen und Antworten in der Knowledge-Base hinterlegt, die Wahrscheinlichkeit, dass ein Nutzer ein ähnliches Problem wie Sie hat und dieses bereits gelöst wurde, ist daher recht groß. Sollten Sie jedoch keine weiterführenden Informationen erhalten, können Sie selbstverständlich den Support direkt kontaktieren, der erfahrungsgemäß sehr schnell und kompetent weiterhilft.
