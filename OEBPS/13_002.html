13.2    Bestellbedingungen verwalten

Sollten Sie in der Vergangenheit in einem Online-Shop eingekauft haben, und als Leser dieses Buches gehe ich davon aus, dass Sie zur E-Commerce-affinen Zielgruppe gehören, ist Ihnen vermutlich die Anforderung im letzten Schritt des Einkaufsprozesses bekannt. Bevor Sie eine Bestellung absenden können, müssen Sie den allgemeinen Geschäftsbedingungen und der Widerrufsbelehrung zustimmen. Tun Sie das nicht, können Sie den Einkauf nicht abschließen und die Bestellung platzieren. Genau dieses Verhalten müssen Sie in Ihrem Online-Shop ebenfalls nachbilden, außer Sie adressieren ausschließlich Geschäftskunden. Zum Glück ist dies mit Magento im Standard gar kein Problem, denn eine entsprechende Funktion steht bereits zur Verfügung. Diese Funktionalität möchte ich an dieser Stelle im Detail beleuchten, da Sie mit ihrer Hilfe alle möglichen Bestellbedingungen abbilden können, ungeachtet des rechtlich relevanten Widerrufsrechts bzw. der allgemeinen Geschäftsbedingungen.

Abbildung 13.7    Bestellbedingungen können einen Titel und Inhalt erhalten und müssen im Checkout-Prozess bestätigt werden.

Melden Sie sich mit Ihren persönlichen Zugangsdaten im Magento-Backend an, und klicken Sie auf Shops • Einstellungen • Allgemeine Geschäftsbedingungen (AGB). Lassen Sie sich an dieser Stelle nicht von dem Übersetzungsfehler »Allgemeine Geschäftsbedingungen (AGB)« irritieren, denn Sie werden an dieser Stelle nicht die AGB editieren, sondern die Agreements. Bedingungen bzw. Bestellbedingungen wäre an dieser Stelle die etwas sauberere Übersetzung gewesen, aber gegebenenfalls wird dies mit einer neuen Version des Sprachpakets korrigiert. Wenn Sie den Link Allgemeine Geschäftsbedingungen (AGB) aufgerufen haben, werden Sie zwei Einträge vorfinden. Diese wurden bereits von MageSetup angelegt, gehören also nicht zum Magento-Standard, aber sehr wohl zum Standard von MageSetup. Bei den Einträgen handelt es sich um die AGB bzw. die Widerrufsbelehrung. Klicken Sie, um zu den Details zu gelangen, auf den ersten Eintrag namens AGB. Daraufhin gelangen Sie zur Detailansicht, die Sie in Abbildung 13.7 sehen.

Im ersten Schritt müssen Sie einen Namen für die Bedingung hinterlegen. Dieser Name wird jedoch weder im Frontend noch im Backend ausgegeben, daher können Sie an dieser Stelle eine beliebige Bezeichnung verwenden. MageSetup nutzt beispielsweise den Namen AGB, was vollkommen in Ordnung ist. Mittels des Status definieren Sie, ob die Bedingung aktiviert oder deaktiviert ist. Wenn Sie eine Bedingung deaktivieren, wird diese nicht im Checkout-Prozess dargestellt. Wie Sie gleich noch sehen werden, können Sie einen Inhalt für die Bedingung hinterlegen. Dabei könnten Sie theoretisch auch auf einen Text, der HTML-Formatierungen enthält, zurückgreifen. Ob Sie aber tatsächlich HTML-Elemente ausgeben möchten, definieren Sie im nächsten Feld namens Inhalt anzeigen als. Im Standard wird die Option HTML gewählt, d. h., Sie können tatsächlich auf HTML-Elemente zurückgreifen. Alternativ haben Sie die Option, Text zu wählen. In diesem Fall würden die HTML-Tags ignoriert werden. Belassen Sie jedoch die Auswahl ruhig bei der Option HTML. Das nächste Feld trägt den Namen Angewandt, an sich ist diese Übersetzung wieder etwas irreführend. Gemeint ist mit dieser Option, ob die Option bereits vorausgewählt ist oder ob der Nutzer diese Option erst noch manuell auswählen muss. Daraus leiten sich die möglichen Optionen Manuell bzw. Automatisch ab. Speziell bei AGB und der Widerrufsbelehrung dürfen Sie diese dem Nutzer nicht vorausgewählt präsentieren, der Nutzer muss die Checkbox explizit selbst anhaken. Sie können jedoch beispielsweise eine dritte Bestellbedingung hinzufügen, die den Namen trägt »Ich möchte eine kostenlose Überraschung erhalten«. In diesem Fall dürften Sie die Option bereits angehakt präsentieren, da diese keinen Einfluss auf rechtliche Rahmenbedingungen hat. Belassen Sie daher diese Option bitte auf Manuell. Wenn Sie mehrere Sprachen bzw. Store Views anbieten, können Sie diese im Punkt Store View auswählen. Dadurch lässt sich diese Bedingung nur für bestimmte Sprachen aktiveren bzw. bei bestimmten Sprachen deaktivieren. Interessant wird es jetzt im nächsten Punkt. Mit dem Feld Checkbox-Text definieren Sie, welcher Inhalt direkt neben der Checkbox innerhalb des Checkout-Prozesses ausgegeben wird. Im Fall der AGB wurde durch MageSetup der Text »Ich habe die Allgemeinen Geschäftsbedingungen gelesen und stimme diesen ausdrücklich zu.« hinterlegt. Genau dieser Text, Sie werden das im Verlauf der nächsten Seiten noch sehen, wird direkt neben der Checkbox ausgegeben. Neben der reinen Bezeichnung für die Checkbox müssen Sie zudem noch den eigentlichen Inhalt hinterlegen. Um eine Redundanz zu vermeiden, wird an dieser Stelle auf den Block, der die AGB enthält, verwiesen. Theoretisch könnten Sie an dieser Stelle auch den Text direkt hinterlegen, wie Sie am Beispiel der AGB aber bereits gesehen haben, ergibt eine zentrale Datenpflege mithilfe eines Blocks Sinn, da Sie Änderungen und Anpassungen zukünftig nur an einer zentralen Stelle pflegen müssen. Um auf einen Block zu verweisen, können Sie das folgende Code-Snippet verwenden, das MageSetup initial hinterlegt:

{{block class="Magento\Cms\Block\Block" block_id="bsiness_terms"}}

Listing 13.4    Mithilfe dieses Code-Snippets wird der Block mit der ID »business_terms« geladen.

Abschließend haben Sie im Feld Inhaltshöhe (CSS) noch die Möglichkeit, die Höhe des Inhaltsbereichs, sprich der Box, anzupassen. In der Regel können Sie dieses Feld jedoch leerlassen und müssen für eine optimale Darstellung keinen Wert hinterlegen.

Aufgrund der Vorarbeit von MageSetup müssen Sie an dieser Stelle keine Änderungen vornehmen und können die Ansicht verlassen. Wenn Sie in der Übersicht nun die Widerrufsbelehrung auswählen, sehen Sie ein absolut identisches Muster. Der einzige Unterschied besteht in der Referenz auf den Block, denn an dieser Stelle werden nicht die AGB geladen, sondern die Widerrufsbelehrung.

Wechseln Sie jetzt bitte in das Frontend, und legen Sie sich ein Produkt in den Warenkorb. Betreten Sie anschließend den Checkout-Prozess, und klicken Sie sich bis zum letzten Schritt, wie in Abbildung 13.8 zu sehen, durch.

Direkt über dem Button namens Bestellung aufgeben sehen Sie nun die Bestellbedingungen, die Sie anhaken müssen um die Bestellung aufzugeben. Wie Sie sehen, werden die beiden Checkbox-Texte ausgegeben, sofern Sie auf einen der beiden verlinkten Checkbox-Texte klicken, öffnet sich ein neues Overlay, das den eigentlichen Inhalt enthält. Der Nutzer wird an dieser kritischen Stelle also nicht zu einer externen Seite geführt oder von einem Popup abgelenkt, sondern kann den Inhalt innerhalb des Overlays einsehen.

Wenn Sie möchten, können Sie an dieser Stelle beliebig viele Bestellbedingungen hinzufügen. Rechtlich notwendig sind, außer es gelten in Ihrer Branche abweichende Regelungen, jedoch nur die beiden Einträge zu den allgemeinen Geschäftsbedingungen und der Widerrufsbelehrung. In jedem Fall, ob Sie neue Bedingungen hinzufügen oder bestehende Bedingungen abändern, haben Sie innerhalb des Magento-Backends eine einfache und simple Verwaltungsmöglichkeit und sind somit nicht auf Modifikationen oder Erweiterungen angewiesen, sondern können die Änderungen und Anpassungen selbstständig einpflegen.
