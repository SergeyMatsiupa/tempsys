15.6    Berichte erstellen und verwalten

Lernen Sie jetzt das Herzstück von Magento BI kennen, die Berichte. Von Haus aus sind bereits einige Berichte vorhanden, die Sie später in den Dashboards nutzen können. Wenn Sie die bestehenden Berichte einsehen wollen, klicken Sie bitte auf Manage Data • Reports. Daraufhin erhalten Sie eine Auflistung aller im System vorhandenen Berichte, die Sie an dieser Stelle löschen, aber nicht bearbeiten können. Insgesamt wird Magento BI mit 83 Berichten ausgeliefert, d. h., auch ohne die Entwicklung individueller Berichte stehen Ihnen eine Vielzahl von Reports bereit, die Sie direkt ohne Umwege nutzen können.

Um neue Berichte zu erstellen, klicken Sie in der Hauptnavigation auf den Link Report Builder. Sie gelangen daraufhin zu einem Auswahlmenü, in dem Sie sich zwischen dem Visual Report Builder und dem SQL Report Builder entscheiden müssen. Bei Letzterem können Sie Berichte direkt auf Basis von SQL-Statements erstellen. Dadurch haben Sie eine enorme Flexibilität und können zudem recht schnell Berichte erstellen. Der Nachteil an dieser Variante ist jedoch, dass Sie sich sehr gut mit SQL auskennen müssen. Da die Nutzer in der Regel aber eher rudimentäre Kenntnisse in Sachen SQL haben, stellt der Visual Report Builder die bessere Option dar. Denn dieser ermöglicht die grafische Entwicklung von Berichten ganz ohne Kenntnisse in Sachen SQL. Klicken Sie daher, um in den nächsten Schritt zu gelangen, beim Visual Report Builder auf den Button Create Report.

Magento BI lädt daraufhin eine leere Oberfläche, wobei Sie auf der linken Seite die Möglichkeit haben, mittels eines Buttons bzw. Dropdown-Menüs eine Metrik auszuwählen. Wählen Sie nun bitte den Eintrag »Avg order value« aus. Nachdem Sie auf den Eintrag geklickt haben, erscheint an der vormals leeren Stelle auf der rechten Seite ein Chart, das wie in Abbildung 15.10 aussehen muss.

Magento BI teilt die aktuell geöffnete Ansicht in zwei Bereiche. Auf der linken Seite haben Sie die Metriken und Formeln, auf der rechten Seite das daraus resultierende Ergebnis. Sie haben nun auch die Möglichkeit, weitere Metriken und Formeln hinzuzufügen. Klicken Sie bitte erneut auf den Button bzw. das Dropdown-Menü Add Metric, und fügen Sie die Metrik Orders hinzu. Diese Metrik zeigt Ihnen die Anzahl der Bestellungen in einem bestimmten Zeitraum an. In Summe haben Sie aktuell daher zwei Metriken und daraus resultierend auf der rechten Seite zwei visuell dargestellte Daten in Abhängigkeit von der Zeit. Sie sehen die Anzahl der Bestellungen pro Monat sowie den durchschnittlichen Bestellumsatz pro Monat. Im Juni gab es in meinem Online-Shop acht Bestellungen, der durchschnittliche Bestellumsatz lag bei 81,92 €, und im Juli lag dieser bei 74 €, wobei nur eine Bestellung generiert wurde.

Abbildung 15.10    Nachdem Sie eine Metrik zum Bericht hinzugefügt haben, erscheinen die Werte im rechten Bereich der Bildschirmhälfte.

Zusätzlich zu den von Ihnen bzw. Magento BI definierten Metriken können Sie nun auch auf die von Google Analytics bereitgestellten Informationen zurückgreifen. Klicken Sie hierfür auf den Button bzw. das Dropdown-Menü Add Metric, und wählen Sie im Punkt Google die Kennzahl Page Views aus. Zugegebenermaßen ergibt die von mir getroffene Auswahl an dieser Stelle nicht viel Sinn, da in Google Analytics noch keine Daten enthalten sind. Ich möchte Ihnen an dieser Stelle aber auch nur demonstrieren, wie Sie vorgehen müssten, wenn Sie tatsächlich auf ein mit Daten gefülltes Google-Analytics-Konto zugreifen könnten. Nachdem Sie die Änderungen durchgeführt haben, müssten Sie auf der linken Seite drei Einträge vorfinden, so wie Sie diese auch in Abbildung 15.11 sehen.

Zusätzlich haben Sie nun bei den Metriken noch die Möglichkeit, diese einzugrenzen und Filter anzuwenden. Fahren Sie hierzu mit der Maus über die Metrik, woraufhin kleine Icons eingeblendet werden. Diese Icons ermöglichen Ihnen das Löschen der Metrik – natürlich nur an dieser Stelle aus dem Report und nicht grundsätzlich –, das Kopieren, das Eingrenzen durch Filter, die Anpassung der Perspektive und das Setzen von Zeiteinstellungen.

Abbildung 15.11    Pro Bericht lassen sich beliebig viele Metriken hinzufügen.

Wenn Sie auf das Icon »Filters« klicken, erscheint im rechten Bereich des Bildschirms ein weiteres Menü, in dem Sie Filter hinzufügen können. Die Logik an dieser Stelle ist recht simpel, Sie können auf Spalten der Datenbank zurückgreifen und mittels des Operators einen Filter erstellen. Vom Grundgedanken her gehen Sie exakt wie bei den Filtern innerhalb eines Filter Sets vor. Bei der Perspektive können Sie zudem den »Blick auf die Daten« einstellen, d. h. ob Sie gegebenenfalls eine zurückliegende Periode betrachten möchten, ob Sie kommutierte Werte bevorzugen etc. Bei den Einstellungen bezüglich der Zeit können Sie zudem eine Zeitspanne auswählen. Sehen Sie an dieser Stelle von einer Filterung, dem Wechsel der Perspektive und von einer zeitlichen Limitierung ab, und belassen Sie die Auswahl im Standard.

Neben der Möglichkeit, bestehende Metriken hinzuzufügen, können Sie zudem mit Formeln arbeiten. Wenn Sie nochmals einen Blick auf Abbildung 15.11 werfen, werden Sie neben dem grünen Button Add Metric einen grauen Button Add Formula sehen. Klicken Sie jetzt bitte auf Add Formula. Nachdem Sie auf den Button geklickt haben, werden im rechten Bereich ein Eingabefeld und die möglichen Inhalte angezeigt. Werfen Sie hierzu einen Blick auf Abbildung 15.12.

Abbildung 15.12    Neben Metriken können Sie zusätzlich auf Formeln zurückgreifen.

Auf der rechten Seite sehen Sie die möglichen Inhalte, gekennzeichnet durch A, B und C. Hierbei handelt es sich um die Ergebnisse, die aus den hinzugefügten Metriken bereitgestellt werden. Hätten Sie fünf Metriken hinzugefügt, hätten Sie also noch die möglichen Inhalte D und E. Auf der linken Seite, direkt unter der Überschrift Enter your Formula können Sie nun eine beliebige Berechnung auf Basis der zur Verfügung stehenden Inhalte durchführen. Beispielsweise können Sie mit folgender Formel den Gesamtumsatz pro Monat berechnen: A * B. Wenn Sie A * B in das Feld, das Sie in Abbildung 15.12 sehen, eintragen, nimmt Magento die Anzahl der Bestellungen und multipliziert diese mit dem durchschnittlichen Bestellumsatz. Als Endergebnis entsteht der Gesamtumsatz. Natürlich können Sie an dieser Stelle nicht nur Multiplikationen durchführen, sondern haben auch die Möglichkeit, komplexe Formeln zu hinterlegen. Sobald Sie eine Formel erstellt haben, klicken Sie bitte auf Apply Changes. Daraufhin wird die Formel in der linken Bildschirmhälfte wie eine Metrik behandelt, und Sie sehen die visualisierten Daten in der rechten Bildschirmhälfte.

Gegebenenfalls fragen Sie sich, warum Sie überhaupt Formeln benötigen. Grundsätzlich besteht immer die Situation, dass gewisse Werte nicht in der Datenbank vorliegen und errechnet werden müssen. Im Fall des Gesamtumsatzes ist dies zwar nicht der Fall, aber beispielsweise wissen Sie, dass Sie immer eine Retourenquote von 10 % haben. Auf dieser Basis könnten Sie Umsätze um 10 % verringern, ohne die realen Zahlen tatsächlich speichern zu müssen. Auch könnten Sie auf Basis der Webanalyse-Daten aus Google Analytics die entgangene Bestellsumme durch stehengelassene Warenkörbe auf Basis einer Formel hochrechnen. Die Möglichkeiten sind vielseitig, und Sie werden, wenn Sie denn auf Magento BI setzen, die Formeln häufiger verwenden, als Ihnen am Anfang bewusst ist.

Nachdem ich Ihnen primär den linken Bereich dieser Ansicht gezeigt habe, möchte ich nun noch auf die rechte Bildschirmhälfte eingehen. Ganz oben in der Ansicht steht, das sollte bei Ihnen auch der Fall sein, die Bezeichnung Untitled Report, die Sie per Klick auf diese Stelle ändern können. Geben Sie hier dem Bericht einfach den Namen »Test«, sodass Sie ihn später recht einfach identifizieren können. Direkt unter dem Namen des Berichts erscheint direkt die Visualisierung, die Sie in Abbildung 15.13 sehen.

Abbildung 15.13    Bei der Visualisierung stehen verschiedene Optionen zur Verfügung, wie Sie direkt unter dem Date-Picker sehen können.

Grundsätzlich können Sie die Visualisierung des Charts anpassen. In diesem Fall ergeben zugegebenermaßen die Linien am meisten Sinn, Sie können jedoch auch auf ein Torten- bzw. Balkendiagramm zurückgreifen. Zudem lässt sich auch der Zeitraum einschränken. Magento BI schlägt mir den Zeitraum 2015 bis heute vor, wobei dieser Zeitraum viel zu lang gewählt ist. Aus diesem Grund entscheide ich mich für eine Eingrenzung auf das Jahr 2017. Neben der Möglichkeit, eine Zeitspanne anzugeben, besteht zudem die der Perioden-Auswahl. Momentan ist die Staffelung monatlich, Sie könnten jedoch auch auf eine stündliche, tägliche, wöchentliche, quartalsweise oder jährliche Periode wechseln. Monatlich ist in dieser Form okay, weswegen ich die Einstellung beibehalte. Wenn Sie diese Änderungen durchführen, wird sich automatisch die Visualisierung des Berichts anpassen, wie Sie in Abbildung 15.14 sehen.

Abbildung 15.14    Durch die Einschränkung des Zeitraums ändert sich automatisch das Chart.

Ergänzend haben Sie übrigens an dieser Stelle noch die Möglichkeit, eine Gruppierung der Werte vorzunehmen. Dies können Sie mittels des Dropdown-Menüs Group By, das sich in der linken oberen Bildschirmhälfte befindet, tun. Direkt unter dem Chart liefert Magento BI zudem eine Tabelle mit allen Informationen und Werten aus. Sie sehen diese in Abbildung 15.15.

Abbildung 15.15    Neben der Visualisierung bzw. dem Chart steht zudem eine Tabelle mit allen Informationen zur Verfügung.

Aufgelistet werden nochmals alle Werte sowie Informationen wie die Zeitachse, die sich aus den von Ihnen hinzugefügten Metriken ergeben. Zur Validierung, speziell bei durch Formeln errechneten Werten, eignet sich die Tabelle meiner Meinung nach wesentlich besser als das Chart, da Sie die Werte viel schneller erfassen können.

Klicken Sie nun auf den Button Save, da Sie an dieser Stelle keine weiteren Einstellungen und Anpassungen vornehmen müssen. Nachdem Sie auf den Button geklickt haben, fragt Sie Magento BI, ob Sie den Chart bzw. die Tabelle oder die einzelnen Zahlen zum Dashboard hinzufügen möchten, und wenn Sie sich hierbei entschieden haben, zu welchem Dashboard Sie den Bericht hinzufügen möchten. Ich denke, der Unterschied zwischen Chart und Tabelle ist an dieser Stelle bekannt. Entweder Sie integrieren die grafisch visualisierten Werte oder die Werte in Tabellenform in das Dashboard. Alternativ hierzu könnten Sie sich aber auch die Kennzahl aus der Metrik picken und nur diese zum Dashboard hinzufügen. Denken Sie an dieser Stelle z. B. an die Anzahl der Bestellungen. Vermutlich brauchen Sie dafür kein Chart und keine Tabelle, Sie wollen einfach die nackte Zahl auf dem Dashboard sehen. Für diese Zwecke wäre diese Wahl also sinnvoll. Beim Dashboard können Sie an dieser Stelle einfach den Eintrag Executive Overview auswählen und daraufhin auf Save to Dashboard klicken.

Mit dieser letzten Tätigkeit haben Sie erfolgreich einen Bericht erstellt und einem im System vorhandenen Dashboard hinzugefügt!
