8.3    Verwaltung von Bestellstatus

Während der Erstellung von Rechnungen und Gutschriften ist Ihnen sicherlich der wechselnde Bestellstatus aufgefallen. Magento kennt von Haus aus verschiedene Zustände einer Bestellung, den Zuständen sind Bestellstatus zugewiesen. Das heißt, wenn eine neue Bestellung eingeht, kann diese Bestellung mehrere Bestellstatus haben, diese ändern aber nichts am Zustand der Bestellung, das bedeutet, dass es sich um eine neue Bestellung ohne Rechnung bzw. Lieferschein handelt.

Die Zustände an sich sind festgelegt, und Sie haben keinerlei Möglichkeit, diese innerhalb des Magento-Backends zu ändern. Vereinfacht ausgedrückt gibt es die folgenden Zustände:

  • Neue Bestellung
  • Bestellung mit einer Rechnung
  • Bestellung mit einem Lieferschein
  • Bestellung mit einer Gutschrift

Was Sie jedoch ändern und erweitern können, sind die Status. Klicken Sie hierfür im Backend auf den Punkt Shops • Bestellstatus. Daraufhin erhalten Sie, wie in Abbildung 8.21 zu sehen ist, eine Auflistung aller Zustände und Status samt deren Zuordnung.

Blenden Sie an dieser Stelle gedanklich die ganzen Tabelleneinträge aus, und klicken Sie zuerst auf den Button Neuer Status erstellen. In der anschließend dargestellten Eingabemaske können Sie einen Statuscode und ein Statuslabel hinterlegen. Aufgrund der Mehrsprachigkeit werden Sie an dieser Stelle auch die Möglichkeit haben, individuelle Werte je nach Store View zu hinterlegen. Diese Option ist aktuell aber weniger interessant. Angenommen, Sie möchten grundsätzlich bei einer Bestellung hinterlegen können, ob der Zahlungseingang, z. B. bei Bezahlung per Vorkasse, erfolgt ist, benötigen Sie einen weiteren Status. Diesem Status geben Sie den Statuscode »payment_received« und das Label »Geldeingang erfolgt«. Beim Statuscode müssen Sie letztendlich nur einen eindeutigen Wert hinterlegen, welchen Code Sie verwenden, bleibt Ihnen überlassen. Sowohl das Label als auch der Statuscode sind von mir an dieser Stelle frei gewählt, Sie können jeden beliebigen anderen Wert verwenden.

Speichern Sie anschließend den Status über den gleichnamigen Button.

Abbildung 8.21    Magento erlaubt die Anlage und Verwaltung von Bestellstatus.

Die reine Anlage des Status hilft Ihnen jetzt noch nicht weiter, denn Sie müssen dem System mitteilen, bei welchem Zustand einer Bestellung dieser Status zur Verfügung stehen soll. Klicken Sie daher in der Bestellstatusübersicht auf den Button Status dem Zustand zuweisen. Daraufhin öffnet sich die Maske, die Sie in Abbildung 8.22 sehen.

Abbildung 8.22    Nachdem Sie einen Status angelegt haben, müssen Sie ihm einen Zustand zuweisen.

Beim Bestellstatus können Sie jetzt den soeben angelegten Status auswählen, im nächsten Feld, beim Bestellzustand, in der Übersetzung fälschlicherweise auch mit Bestellstatus übersetzt, wählen Sie den Eintrag Ausstehend. Jede neue Bestellung bekommt nämlich den Zustand ausstehend zugewiesen. An dieser Stelle sehen Sie noch die weiteren Zustände, die aufgrund der Benennung recht selbsterklärend sind. Wenn Sie den Bestellstatus als Standard setzen, hierbei handelt es sich um das nächste Feld, würde jeder neuen Bestellung der von Ihnen ausgewählte Zustand zugewiesen werden. In diesem Fall wäre das kontraproduktiv, da ich die bezahlten Bestellungen markieren würde und nicht jede neue Bestellung per se bezahlt ist. Die letzte Option, sichtbar im Frontend, sollten Sie dann aktivieren, wenn Sie den angelegten Status auch innerhalb des Kundenkontos im Frontend anzeigen möchten. Speichern Sie bitte anschließend die Zuweisung, und wechseln Sie nun in eine unbearbeitete Bestellung innerhalb der Bestellübersicht.

Wenn Sie jetzt eine neue Bestellung innerhalb des Backends aufrufen und in der Detailansicht nach unten scrollen, werden Sie feststellen, dass Sie bei der Statusauswahl zusätzlich den soeben angelegten Status auswählen können, Sie sehen das in Abbildung 8.23.

Abbildung 8.23    Der neu hinzugefügte Status kann nun bei unbearbeiteten Bestellungen ausgewählt werden.

Erfolgt nun beispielsweise für diese Bestellung der Zahlungseingang, können Sie, wie in Abbildung 8.23 zu sehen ist, den neuen Status auswählen und den Kommentar übermitteln. Durch die Übermittlung des Kommentars – Sie müssen in den Freitextbereich auch keinen Text schreiben – wird automatisch der Status der Bestellung geändert.

Wie erwähnt, können Sie aber nicht nur für neue Bestellungen neue Status anlegen. Letztendlich haben Sie die Möglichkeit, bei jedem Zustand weitere Status zu erstellen und zuzuweisen und anschließend in der Bestellansicht den möglichen Status der Bestellung zuzuweisen. Was Sie jedoch nicht ändern können, das möchte ich an dieser Stelle nochmals betonen, sind die im System vorhandenen Zustände einer Bestellung.
