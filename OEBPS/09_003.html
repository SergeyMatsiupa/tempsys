9.3    Funktionen des Kundenkontos

Das Kundenkonto ist die persönliche Schaltzentrale eines jeden Nutzers Ihres Systems. Innerhalb des Kundenkontos können persönliche Daten wie Adressen, aber auch die Wunschliste verwaltet und Bestellungen eingesehen werden. Durch die angebotenen Self-Service-Funktionen müssen sich Ihre Kunden bei Fragen, zum Beispiel wegen einer fehlenden Rechnung, nicht mehr an Ihren Support wenden, sondern können über das Kundenkonto entsprechende Informationen einsehen. Lassen Sie uns daher auf den folgenden Seiten einen Blick auf die verschiedenen Funktionen und Möglichkeiten werfen.

Klicken Sie innerhalb der Header-Navigation auf Anmelden, und melden Sie sich mit Ihren persönlichen Daten an. Sollten Sie Ihr Passwort nicht mehr parat haben, wissen Sie nun auch, wie Sie ein neues Passwort setzen können. Nachdem Sie sich angemeldet haben, landen Sie direkt im Dashboard.

9.3.1    Dashboard

Das Dashboard ist sozusagen die persönliche Startseite innerhalb des Kundenkontos, das Ihnen relevante Informationen auf einen Blick anzeigt und Ihnen den Sprung in die restlichen Funktionen ermöglicht. Innerhalb des Dashboards sehen Sie auf einen Blick, wie Ihre Standardrechnungs- bzw. -versandadresse lautet, ob Sie sich für den Newsletter registriert haben und welche Daten Sie aktuell bei den Kontaktinformationen hinterlegt haben.

9.3.2    Kontoinformationen

Klicken Sie in der linken Navigation bitte auf den nächsten Punkt namens Kontoinformationen. Innerhalb dieser Maske können Sie Ihren Vornamen, Nachnamen, E‐Mail-Adresse sowie Passwort ändern. Beachten Sie, dass je nach Systemkonfiguration, nach einer Änderung der E‐Mail-Adresse diese unter Umständen erneut bestätigt werden muss. Achten Sie daher auf Tippfehler und Buchstabendreher.

9.3.3    Adressbuch

Grundsätzlich erlaubt Magento die Verwaltung von beliebig vielen Adressen pro Kunde. Aus diesem Grund existiert auch der nächste Menüpunkt namens Adressbuch. Wenn Sie diesen Link öffnen und noch keine hinterlegten Adressen haben, öffnet sich zuerst ein Dialog zur Anlage einer neuen Adresse, wie Sie in Abbildung 9.5 sehen können.

Abbildung 9.5    Innerhalb des Kundenkontos können Sie beliebig viele Adressen anlegen.

Legen Sie an dieser Stelle ruhig eine neue Adresse an, indem Sie die Eingabemaske ausfüllen und anschließend speichern. Haben Sie dies getan, wird sich im nächsten Schritt die Ansicht der Seite Adressbuch ein wenig ändern. Rufen Sie das Adressbuch erneut auf, öffnet sich nicht automatisch eine Eingabemaske zwecks Erstellung einer neuen Adresse, sondern eine Übersichtsseite, in der Sie alle im System hinterlegten Adressen einsehen können. Neben der Möglichkeit, die bestehenden Adressen zu ändern, können Sie selbstverständlich auch neue Adressen hinzufügen. Sofern Sie mehrere Adressen im System hinterlegt haben, können Sie zudem eine Standardrechnungs- bzw. Lieferadressen definieren.

9.3.4    Meine herunterladbaren Produkte

Der nächste Menüpunkt namens Meine herunterladbaren Produkte ist vor allem dann relevant, wenn Sie in Ihrem Online-Shop digitale Produkte, sprich Downloads, vertreiben. Kauft ein Kunde ein herunterladbares Produkt, hat er an dieser Stelle die Möglichkeit, die gekauften Dateien herunterzuladen. Der Download wird jedoch nur dann erlaubt, wenn bestimmte Bedingungen erfüllt sind, die Sie jedoch selbst definieren können. Zu den Bedingungen zählt beispielsweise der Status der Bestellung, wodurch Sie definieren können, dass nur Dateien aus bezahlten Bestellungen heruntergeladen werden können. Auch haben Sie die Möglichkeit, die maximale Anzahl an Downloads zu definieren. Aus diesem Regelwerk ergibt sich letztendlich die Antwort, ob der Kunde einen Download-Link innerhalb des Kundenkontos dargestellt bekommt, oder nicht.

9.3.5    Meine Bestellungen

In der Ansicht Meine Bestellungen haben Sie Zugriff auf alle von Ihnen getätigten Bestellungen. Sie sehen dabei auf den ersten Blick den Status, das Datum, die Bestellsumme, die Bestellnummer sowie die Versandadresse und können aus der Übersichtsansicht heraus eine Nachbestellung auslösen oder die Detailansicht aufrufen. Die Detailansicht liefert Ihnen weiterführende Informationen zur Bestellung, werfen Sie hierfür bitte einen Blick auf Abbildung 9.6. Neben einer Auflistung aller in der Bestellung enthaltenen Produkte, sehen Sie zudem die gewählte Versandadresse, Versandmethode, Rechnungsadresse und Zahlungsmethode.

In der oberen Hälfte dieser Ansicht stehen Ihnen zudem drei Links, Nachbestellen, Bestellstatus abonnieren und Bestellung drucken, zur Verfügung. Wenn Sie auf Nachbestellen klicken, werden alle Produkte dieser Bestellung in Ihren Warenkorb gelegt, und Sie können somit eine identische Bestellung erneut aufgeben. Selbstverständlich haben Sie an dieser Stelle jedoch auch die Möglichkeit, weitere Ergänzungen und Änderungen an Ihrem Warenkorb vorzunehmen. Der Link Bestellstatus abonnieren verweist auf einen RSS-Feed, den Sie mit einem entsprechenden Programm abonnieren können. Als Ergebnis erhalten Sie den aktuellen Status dieser Bestellung im XML-Format zurückgeliefert. Wenn Sie diesen Feed mittels eines RSS-Readers abonnieren, würden Sie, sobald sich der Bestellstatus ändert, eine entsprechende Benachrichtigung erhalten. Auch wenn dieses Feature, technologisch betrachtet, recht nett ist, so wird dies doch in der Praxis eher selten genutzt. Last, but not least können Sie die Bestellung auch ausdrucken.

Abbildung 9.6    In der Detailansicht erhalten Sie alle relevanten Informationen auf einen Blick.

Klicken Sie auf den Link Bestellung drucken, öffnet sich automatisch eine optimierte Druckansicht der Bestellung, und Sie haben anschließend die Möglichkeit, die Ansicht direkt zu drucken.

Je nach Status der Bestellung haben Sie an dieser Stelle übrigens noch weitere Möglichkeiten. Liegen eine oder mehrere Rechnungen vor, so können Sie die Rechnungen direkt über diese Ansicht herunterladen. Wurde die Lieferung als versendet markiert und ist im Besitz einer Tracking-Nummer, können Sie zudem an dieser Stelle die Tracking-Nummer einsehen bzw. direkt zum Versanddienstleistungsunternehmen springen. Der Status der Bestellung definiert also die vorhandenen Möglichkeiten und Funktionen. Da ich in diesem Beispiel eine neue, unbearbeitete Bestellung, geöffnet habe, sind diese erwähnten Funktionen nicht vorhanden, da die Bestellung selbst innerhalb des Backends noch nicht verarbeitet wurde.

9.3.6    Newsletter-Abonnements

Wie Sie im späteren Verlauf dieses Buches noch sehen werden, können Sie direkt über Magento Newsletter entwerfen und versenden. Im ersten Schritt kümmert sich Magento um die Anmeldung der Newsletter-Abonnenten und verfügt hierbei über eine entsprechende Verwaltungslogik. Die Anmeldung zum Newsletter ist grundsätzlich nicht nur registrierten Kunden vorbehalten, auch Gäste können sich per Eingabe der E‐Mail-Adresse für den Newsletter anmelden.

Im Menüpunkt Newsletter-Abonnement, den nächsten Eintrag in der Navigation innerhalb des Kundenkontos, können Sie sich für den Newsletter anmelden, aber auch wieder abmelden. Hierfür müssen Sie letztendlich nur die Checkbox bei der Option Allgemeines Abonnement aktivieren und auf speichern klicken. Je nach Systemkonfiguration kann es sein, dass Sie die Anmeldung zum Newsletter nochmals bestätigen müssen. Sollte dies der Fall sein, erhalten Sie eine entsprechende E‐Mail mit einem Bestätigungslink. Haben Sie das Double-Opt-in-Verfahren hingegen deaktiviert, erhalten Sie keine E‐Mail und sind direkt am Newsletter angemeldet.

9.3.7    Stored Payment Methods

Den nächsten Menüeintrag können Sie gedanklich ausblenden, da dieser in der Regel keine wichtige Rolle spielt. Magento erlaubt das Speichern von Zahlungsinformationen zu bestimmten Zahlungsmethoden, und genau diese Zahlungsinformationen können Sie hier einsehen. Da in der Regel ein Payment-Service-Provider für die Verarbeitung von Zahlungstransaktionen genutzt wird, ist daher auch dieser Menüeintrag in der Regel irrelevant.

9.3.8    Meine Produktbewertungen

Produktbewertungen sind eine gute Möglichkeit, um die Conversion Rate zu erhöhen. Denn je mehr Bewertungen zu einem Produkt vorliegen, vorausgesetzt die Bewertungen sind größtenteils positiv, desto höher ist die Wahrscheinlichkeit eines Kaufs durch einen Besucher bzw. Kunden. Aus diesem Grund ermöglicht Magento die Bewertung von Produkten. Haben Sie als Kunde Produktbewertungen abgegeben, erhalten Sie innerhalb des Kundenkontos eine Auflistung aller abgegebenen Bewertungen. Da eine Bewertung aus mehreren Kriterien und einem Freitext bestehen kann, gibt es zudem zu jeder Bewertung eine Detailansicht, die Sie innerhalb des Kundenkontos einsehen können.

Klicken Sie hierfür auf Meine Produktbewertungen, und wählen Sie aus der anschließend dargestellten Liste eine Bewertung aus, in meinem konkreten Beispiel ist nur eine Bewertung im System hinterlegt. Auf der anschließend dargestellten Detailansicht erhalten Sie nochmals Informationen zum bewerteten Artikel sowie die hinterlegten Informationen bei Ihrer Produktbewertung. Wie dies aussehen kann, sehen Sie in Abbildung 9.7. Haben Sie übrigens eine Bewertung abgegeben, haben Sie nachgelagert keine Möglichkeit mehr, diese zu ändern.

Abbildung 9.7    Abgegebene Bewertungen können innerhalb des Kundenkontos eingesehen werden.

Dieser Wunsch kommt in Projekten häufiger vor, ist jedoch leider im Standard nicht abbildbar. Sofern Sie eine abgegebene Produktbewertung ändern möchten, müssen Sie sich direkt an den Shop-Betreiber wenden, der direkt über das Backend existente Produktbewertungen editieren kann.

9.3.9    Abrechnungsvereinbarungen

Der PayPal-spezifische Menüpunkt namens Abrechnungsvereinbarungen spielt immer dann eine Rolle, wenn Sie wiederkehrende Zahlungen per PayPal akzeptieren und abbilden möchten. Angenommen, Sie bieten in Ihrem Magento-Shop Abonnements an, eine Funktion, die im Standard nicht existiert, aber sicherlich entwickelt werden kann, müssen Sie regelmäßig und automatisiert Zahlungen bei Ihren Kunden einziehen. PayPal bietet eine entsprechende Möglichkeit für wiederkehrende Zahlungen, sollten Sie diese Funktionalität nutzen, würde an dieser Stelle eine Liste dargestellt werden, mit allen wiederkehrenden Zahlungen, die Sie autorisiert haben. Es handelt sich daher um eine Liste der laufenden kostenpflichtigen »Abonnements«, die per PayPal bezahlt werden. In der Praxis spielt dieser Menüpunkt jedoch, ähnlich wie die Stored Payment Methods, eine untergeordnete Rolle, da speziell in Deutschland wiederkehrende Zahlungen tendenziell nicht über PayPal abgewickelt werden und Magento grundsätzlich keine Funktionalität zur Abbildung von Produkt-Abonnements im Standard bietet.

9.3.10    Mein Wunschzettel

Als letzten Menüpunkt finden Sie im Kundenkonto den Wunschzettel. Die Funktionsweise eines Wunschzettels haben Sie bestimmt schon bei Amazon bzw. anderen Online-Shops kennengelernt. Schauen Sie sich im Frontend Produkte an, können Sie diese nicht nur zum Warenkorb hinzufügen, sondern auch auf den Wunschzettel setzen.

Der Wunschzettel ist also eine Liste, auf die Sie beliebig viele Produkte setzen können. Innerhalb des Kundenkontos können Sie Ihren Wunschzettel administrieren, Produkte vom Wunschzettel löschen sowie den Wunschzettel teilen. Werfen Sie hierfür einen Blick auf Abbildung 9.8, die meinen exemplarischen Wunschzettel zeigt.

Abbildung 9.8    Das Kundenkonto erlaubt die Verwaltung eines Wunschzettels, der beliebig viele Produkte enthalten kann.

Mithilfe des Links RSS-Feed, den Sie in der oberen Bildschirmhälfte sehen, können Sie den RSS-Feed Ihres Wunschzettels abonnieren. Dadurch können Sie den Wunschzettel in externen Anwendungen, sogenannten RSS-Readern, einbinden und darüber abrufen. Diese Funktion kann dann ganz praktisch sein, wenn Sie sich das Kundenkonto mit einer anderen Person teilen und direkt informiert werden möchten, wenn Produkte zur Wunschliste hinzugefügt bzw. vom Wunschzettel gelöscht werden.

Darunter befindet sich nun die Auflistung aller Artikel, die Sie zur Wunschliste hinzugefügt haben. Wenn Sie mit der Maus über einen Artikel fahren, werden weitere Optionen sichtbar. Sie können pro Artikel einen Kommentar hinterlegen, den Artikel aus dem Wunschzettel entfernen, die Anzahl editieren und bei konfigurierbaren Produkten die Ausprägungen, d. h. Konfigurationsoptionen, anpassen. Diese genannten Optionen lassen sich allesamt auf Produktebene durchführen.

Ergänzend hierzu haben Sie weitere Optionen, die sich nicht auf einen bestimmten Artikel Ihres Wunschzettels, sondern auf den gesamten Wunschzettel beziehen. Der Button Wunschzettel aktualisieren übernimmt getätigte Änderungen und speichert den Wunschzettel erneut ab. Über den Button Wunschzettel teilen können Sie Ihren Wunschzettel per E‐Mail an Kollegen, Freunde und Bekannte versenden. Neben E‐Mail-Adressen haben Sie zudem die Möglichkeit, eine Nachricht zu hinterlegen, die ebenfalls Bestandteil der versendeten E‐Mail ist. Werfen Sie hierfür einen kurzen Blick auf Abbildung 9.9, die Ihnen die vorhandenen Möglichkeiten aufzeigt.

Abbildung 9.9    Sie können Ihren Wunschzettel teilen und dadurch an weitere Personen versenden.

Zu guter Letzt haben Sie zudem die Möglichkeit, alle Produkte aus dem Wunschzettel zu Ihrem Warenkorb hinzuzufügen. Das ist immer dann recht praktisch, wenn Sie den Wunschzettel als eine Art vorgelagerte Einkaufsliste verwenden und Sie die Produkte, nachdem Sie Ihre Einkaufsliste vervollständigt haben, zum Warenkorb hinzufügen müssen. Sie ersparen sich damit das manuelle Hinzufügen der Artikel zu Ihrem Warenkorb, da ein Klick innerhalb des Wunschzettels genügt, um die Produkte zu Ihrem Warenkorb hinzuzufügen. Alternativ, hierfür müssen Sie mit Ihrer Maus einfach über das jeweilige Produkt in Ihrem Wunschzettel fahren, können Sie die Produkte übrigens auch einzeln zur Einkaufsliste hinzufügen.
