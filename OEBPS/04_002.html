4.2    Das Magento-Backend im Überblick

Nachdem Sie an dieser Stelle genau wie ich über eine Magento-Instanz inklusive deutschem Sprachpaket verfügen, möchte ich Ihnen im Folgenden einen Ein- und Überblick über das Magento-Backend geben. Rufen Sie hierfür zuallererst das Magento-Backend auf. Sie erinnern sich sicherlich an den Installationsprozess und die dort vermerkte Admin-URL. Entweder haben Sie auf die von Magento generierte URL gesetzt oder eine eigene namens admin hinterlegt. Am Ende des Installationsprozesses wurde diese URL übrigens nochmals aufgeführt. Rufen Sie nun die hinterlegte Backend-URL auf. Da ich ab sofort zu dem im Buch thematisierten Demo-Shop wechsle, handelt es sich in meinem Fall um die URL http://www.foodbaer.de/admin. Durch den Zusatz /admin komme ich vom Frontend ins Backend und werde zuerst nach dem Benutzernamen und Passwort gefragt, wie Sie in Abbildung 4.2 sehen.

Abbildung 4.2    Um in das Magento-Backend zu gelangen, müssen Sie sich im ersten Schritt mit Ihrem Benutzernamen und Passwort anmelden.

Geben Sie die im Installationsprozess vermerkten Zugangsdaten bestehend aus einem Benutzernamen und Passwort ein, und klicken Sie auf Anmelden. Sollten Sie Ihre Zugangsdaten vergessen haben, was zu einem späteren Zeitpunkt sicherlich passieren kann, können Sie auf den Link Haben Sie Ihr Passwort vergessen? klicken. Anschließend können Sie Ihre E-Mail-Adresse hinterlegen, um ein neues Passwort anzufordern. Beachten Sie bitte, dass Sie für diese Funktion einen funktionierenden und lokal installierten Mail-Server benötigen. Sollten Sie aus irgendeinem Grund keine E-Mail erhalten, wenn Sie ein neues Passwort anfordern, ist der nicht existente bzw. fehlerhaft arbeitende Mail-Server in der Regel die Problemquelle Nummer eins.

Zugangsdaten für www.foodbaer.de

Sollten Sie keine lokale Installation von Magento aufsetzen können bzw. dürfen und falls VirtualBox samt MageVM für Sie ebenfalls keine Option darstellt, können Sie alle Änderungen ebenso in dem Demo-System www.foodbaer.de nachvollziehen. Es handelt sich um eine Magento-Installation, die alle zwei Stunden zurückgesetzt wird; innerhalb der zwei Stunden haben Sie aber die Möglichkeit, alles zu editieren und nachzuvollziehen.

  • Frontend: http://www.foodbaer.de
  • Backend: http://www.foodbaer.de/admin
  • Benutzername: magentobuch
  • Passwort: magento123!

Sobald Sie sich erfolgreich mit Ihrem Benutzernamen und Passwort angemeldet haben, landen Sie direkt im Magento-Backend. Standardmäßig ist als Startseite das Dashboard hinterlegt, in dem Sie sich nun befinden. Wenn Sie sich die Elemente des Backends nun im Detail ansehen, werden Sie relativ schnell feststellen, dass alle Begriffe weiterhin auf Englisch ausgegeben werden. Sie haben zwar, genau wie ich, bei der Installation die Sprache auf Deutsch gestellt, diese Einstellung bezieht sich aber nur auf das Frontend. Würden Sie an dieser Stelle in das Frontend springen, würden Sie eine vollständig auf Deutsch erscheinende Oberfläche vorfinden. Für das Backend hingegen müssen Sie, um die Sprache zu wechseln, zuerst in Ihr Benutzerkonto gehen.

Klicken Sie hierfür in der oberen rechten Ecke auf Ihren Benutzernamen, worauf sich ein neues Menü öffnet. Wählen Sie den ersten Menüpunkt namens Account Setting. Über diesen Link landen Sie in Ihren persönlichen Kontoeinstellungen. Innerhalb dieser Ansicht können Sie folgende Informationen bearbeiten:

  • User Name
  • First Name
  • Last Name
  • Email
  • Password
  • Interface Locale

Kurz gesagt, haben Sie in dieser Maske die Möglichkeit, Ihren Namen, Ihre E-Mail-Adresse, Ihren Benutzernamen und Ihr Kennwort abzuändern. Zudem können Sie auch die Sprache des Backends ändern, diese Einstellung bezieht sich exklusiv auf Ihr Benutzerkonto. Wählen Sie beim Punkt Interface Locale den Eintrag Deutsch (Deutschland) / German (Germany) aus, geben Sie zur Bestätigung der Änderung Ihr Kennwort im Feld Your Password ein, und klicken Sie auf Save Account. Zur besseren Orientierung können Sie einen Blick auf Abbildung 4.3 werfen, in der Sie das entsprechende Dropdown-Feld und auch den Button zum Speichern erkennen können.

Abbildung 4.3    In Ihrem Benutzerkonto können Sie die Sprache, aber auch persönliche Daten abändern.

Nachdem Sie auf Save Account geklickt haben, werden die Änderungen gespeichert, und das Backend ist anschließend in deutscher Sprache verfügbar. Bitte beachten Sie, dass Sie grundsätzlich für Änderungen in Ihrem Benutzerkonto immer Ihr Passwort als Bestätigung eingeben müssen. Sollten Sie das nicht tun, wird Sie Magento mit einem entsprechenden Hinweis darauf aufmerksam machen.

Klicken Sie nun auf den Link Dashboard, der sich in der linken Navigationsleiste ganz oben befindet. Da sich das Dashboard immer direkt nach einem erfolgreichen Login öffnet, möchte ich an dieser Stelle mit dieser Ansicht starten und Ihnen den Sinn und Zweck des Dashboards erklären. Das Magento, Ihre im Standard definierte Startseite, zeigt Ihnen alle wichtigen Kennzahlen und Informationen Ihres Online-Shops auf einen Blick an. Dashboard bedeutet, wörtlich übersetzt, Armaturenbrett, und genau als solches dient das Magento Dashboard. Aus diesem Grund ist das Dashboard zudem die ideale Startseite, da Sie nach jedem Login einen schnellen und übersichtlichen Überblick darüber erhalten, was in Ihrem Online-Shop passiert. Wie Sie in Abbildung 4.4 erkennen können, unterteilt sich das Dashboard, vereinfacht gesagt, in zwei Informationsbereiche.

Abbildung 4.4    Das Magento Dashboard, das zeitgleich als Startseite fungiert

Im linken Bereich des Dashboards erhalten Sie folgende Informationen bzw. Kennzahlen:

  • Gesamteinnahmen
    Gesamtumsatz, d. h. die Summe aller Bestellungen, die der Online-Shop seit Beginn generiert hat
  • Durchschnittlicher Bestellumsatz
    die durchschnittliche Höhe einer Bestellung
  • Letzte Bestellungen
    einen kurzen Überblick über die zuletzt getätigten Bestellungen
  • Letzte Suchbegriffe
    die zuletzt im Frontend verwendeten Suchbegriffe
  • Top-Suchbegriffe
    die beliebtesten Suchbegriffe Ihrer Kunden und Besucher

Diese Kennzahlen ermöglichen Ihnen in der Praxis nur einen groben Überblick. Der durchschnittliche Bestellumsatz ist in der Tat eine relativ wichtige Kennzahl, und im Dashboard können Sie diese sehr gut überwachen. Die restlichen Kennzahlen an dieser Stelle sind jedoch begrenzt interessant, da Sie daraus nicht wirklich Handlungen und Aktionen ableiten können, beispielsweise bei den letzten Suchbegriffen.

Der rechte Bereich des Magento Dashboards hat hingegen einen etwas stärkeren Detaillierungsgrad, denn Sie können folgende Informationen entnehmen:

  • Einnahmen
    Höhe der an diesem Tag generierten Umsätze
  • Steuer
    Höhe der an diesem Tag fakturierten Steuer
  • Versand
    Höhe der an diesem Tag fakturierten Versandkosten
  • Menge
    Anzahl der Artikel, die an diesem Tag verkauft wurden
  • Bestseller
    Auflistung der am häufigsten verkauften Produkte
  • Meistgesehene Produkte
    Auflistung der am häufigsten angesehenen Produkte
  • Neue Kunden
    Auflistung der neuen Kunden
  • Kunden
    Auflistung der Kunden

Der rechte Bereich innerhalb des Dashboards zielt auf eine etwas detailliertere Auswertung der Kennzahlen ab. So sehen Sie eine Auflistung der aktuellen Bestseller oder auch neuen Kunden. Zudem erhalten Sie gezielte Informationen zu den generierten Umsätzen des laufenden Tages. In der Praxis wird Sie speziell diese Information interessieren, nämlich wie viel Umsatz am jeweiligen Tag generiert wurde.

Neben der reinen Darstellung von Zahlen können Sie zusätzlich ein Diagramm aktivieren. Unter dem Button Daten neu laden, mit dessen Hilfe Sie durch einen Klick die Kennzahlen des Dashboards aktualisieren können, befindet sich ein Link mit der Bezeichnung Diagramm ist deaktiviert. Um das Diagramm zu aktivieren, klicken Sie hier. Klicken Sie an dieser Stelle auf das Wort hier, worauf Sie in eine Konfigurationsmaske geleitet werden. Innerhalb dieser Maske ist der Reiter Dashboard aufgeklappt, der die Option Tabellen aktivieren enthält. Aktivieren Sie diese Option, indem Sie bei der Checkbox Use system value den Haken entfernen, um dadurch bei dem Dropdown-Feld die Option Ja auswählen zu können. Speichern Sie bitte anschließend die Konfiguration, indem Sie auf den Button Konfiguration speichern klicken. Gehen Sie daraufhin wieder in das Dashboard, in dem der Satz Diagramm ist deaktiviert. Um das Diagramm zu aktivieren, klicken Sie hier nun nicht mehr sichtbar ist. An dieser Stelle sehen Sie jetzt zwei Reiter namens Bestellungen und Beträge, die Ihnen, sofern Daten vorliegen, entsprechende Diagramme darstellen. Werfen Sie hierfür einen Blick auf Abbildung 4.5, die Ihnen genau diese Reiter anzeigt.

Abbildung 4.5    Nach Aktivierung der Diagramme erscheinen neue Reiter sowie eine Einschränkung des Zeitraums.
