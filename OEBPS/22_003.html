22.3    Point-of-Sale-(PoS-)Lösungen

Neben dem Zugriff mit dem Smartphone oder Tablet können Sie Magento 2 auch für Point-of-Sale-Lösungen verwenden. Damit sind z. B. Kassensysteme gemeint. Somit können Sie auf eine Messe oder ein Event gehen, dort Barzahlungen akzeptieren, und im Hintergrund arbeitet Ihr Magento 2-System, legt Bestellungen und Kunden an und verwaltet entsprechend die Lagerbestände. Sofern Sie also nicht ein reiner Online-Händler sind, können die Point-of-Sale-Lösungen für Sie ebenfalls interessant sein. Auf den nächsten Seiten möchte ich Ihnen einen kurzen Einblick in die am Markt verfügbaren Lösungen geben.

22.3.1    POS Extension (Point Of Sales) for Magento 2

Boost my Shop stellt mit der Extension »POS Extension (Point Of Sales) for Magento 2« eine recht einfache und überschaubare Erweiterung im Bereich Point of Sale zur Verfügung. Sie können mit der Extension selbst keine Hardware wie eine Kasse oder einen Scanner steuern. Vielmehr klinkt sich die Erweiterung direkt in das Magento-Backend ein und erlaubt eine einfache Anlage von Bestellungen. Sobald Sie die Erweiterung installiert haben, wird das Magento-Backend durch weitere Navigationseinträge ergänzt. Wenn Sie anschließend unter Sales auf den Link Checkout klicken, öffnet sich, wie Sie in Abbildung 22.7 sehen können, eine komplett neue Eingabemaske, die vor allem auf die Nutzung von Tablets optimiert ist. So haben Sie am unteren Ende der Seite insgesamt vier große Buttons, die Sie problemlos mit den Fingern bedienen können. Mit dem Button Shortcuts erreichen Sie beispielsweise mit einem Klick definierte Produkte, die Sie direkt mit einem Klick in den Warenkorb legen können. Dadurch können Sie recht schnell und problemlos den Warenkorb befüllen und somit dem Kunden, angenommen, er steht gerade bei Ihnen am Messestand, die Bestellung vorbereiten. Wenn Sie Kundendaten hinterlegen möchten, können Sie auf den Button Guest Customer klicken. Daraufhin öffnet sich ein Overlay, in dem Sie entweder einen bestehenden Kunden auswählen oder einen neuen Kunden anlegen können. Der Button Pay ermöglicht die Bezahlung, wobei Ihnen an dieser Stelle die Zahlungsart »Check/Money Order« oder eben auch die Barzahlung zur Verfügung stehen. Beim Button Store Pickup wählen Sie zudem die Liefermethode, entweder das vorausgewählte Store Pickup oder alternativ die Flat- oder Table-Rates. Haben Sie so weit alle Einstellungen vorgenommen und Informationen hinterlegt, können Sie die Bestellung abschließen.

Bei der Lösung von Boost my Shop handelt es sich sicherlich um eine kleine und simple Point-of-Sale-Lösung. Kassensysteme bzw. Hardware können nicht angeschlossen werden, letztendlich fügt die Extension eine auf Tablets optimierte Backend-Ansicht hinzu, mit der Sie recht einfach Produkte zum Warenkorb hinzufügen, Kundendaten hinterlegen und eine Bestellung abschließen können. In einigen Fällen kann dies, bezogen auf den Funktionsumfang, auch schon reichen. Wenn Sie nur Barzahlungen akzeptieren, keine EC-Kartenzahlungen abbilden möchten und einfach eine schnelle und simple Lösung benötigen, sollten Sie definitiv einen Blick auf diese Erweiterung werfen. Weitere Informationen und eine Demo erhalten Sie unter https://www.boostmyshop.com/magento-2-extension/point-of-sales-magento2.html.

22.3.2    Magento 2 POS

Ähnlich wie Boost my Shop bietet Magestore ebenfalls eine Erweiterung an, die eine Point-of-Sale-Funktionalität direkt in Magento nachrüstet. Der Fokus liegt bei dieser Erweiterung ebenfalls auf einer optimierten Oberfläche innerhalb des Magento-Backends, mit deren Hilfe schnell und einfach Bestellungen mithilfe eines Tablets erfasst werden können. Nachdem Sie die Extension in Magento installiert haben, stehen Ihnen im Backend weitere Navigationspunkte zur Verfügung. Speziell in Sachen Konfiguration geht diese Erweiterung im Vergleich zu der ersten noch einen Schritt weiter. Sie können innerhalb des Magento-Backends verschiedenste Point of Sales anlegen. Das können verschiedene Filialen oder auch Marktplätze bzw. Messestände sein. Diese wiederum lassen sich auswerten, Sie können Mitarbeiter anlegen und zuweisen sowie die verschiedenen Locations verwalten. Der Backend-Part ist bei dieser Extension daher sehr umfangreich.

Die Durchführung der Bestellung erfolgt zudem im Frontend. Sie haben über einen speziellen Link Zugriff auf eine auf Tablets optimierte Oberfläche, die Sie in Abbildung 22.8 sehen.

Wie Sie sehen, werden die Produkte recht großflächig dargestellt und lassen sich mittels eines Klicks direkt zum Warenkorb hinzufügen. Wenn Sie mehrmals auf ein Produkt klicken, erhöhen Sie automatisch die Menge. Über das Icon in der linken oberen Ecke können Sie die weiteren Einstellungen und Menüpunkte öffnen. So können Sie beispielsweise Lagerbestände einsehen oder auch auf die Kundendaten zugreifen. Sobald Sie eine Bestellung auslösen möchten, müssen Sie nur noch auf den roten Button, der sich in der rechten unteren Ecke befindet und den Namen Checkout trägt, klicken. Daraufhin gelangen Sie zu einer neuen Ansicht, in der Sie die Versandmethode und Zahlungsart auswählen müssen. Bei der Zahlungsart steht an dieser Stelle beispielsweise die Barzahlung zur Verfügung, weitere Zahlungsarten können jedoch bei Bedarf hinzugefügt werden. Interessant ist meiner Meinung nach speziell die Discount-Funktion, die Sie in Abbildung 22.9 sehen. Sie können recht einfach einen prozentualen Rabatt gewähren, ohne zuerst Gutscheincodes oder Regeln anlegen zu müssen. Das ist äußerst praktisch, wenn Sie die Gesamtsumme schnell und einfach reduzieren möchten.

Haben Sie sowohl die Versandmethode als auch die Zahlungsart ausgewählt, können Sie die Bestellung aufgeben. Mehr müssen Sie an dieser Stelle gar nicht tun. Abschließend können Sie zudem die E-Mail-Adresse des Kunden hinterlegen, woraufhin ihm nochmals alle Bestellinformationen zugesendet werden. Auch der Druck der Bestellung ist im letzten Schritt möglich.

Zugegebenermaßen liegt bei dieser Erweiterung der Fokus nicht wirklich auf Kunden, d. h., Sie müssen keinen Kunden aus einer Liste auswählen oder anlegen. Die Extension ist auf den schnellen Abverkauf optimiert, das sehen Sie beim Kundenhandling wie bei der Rabattfunktion. Daher eignet sich diese Erweiterung speziell dann, wenn Sie auf Messen und Events unterwegs sind und schnell und einfach Bestellungen erfassen möchten.

Besonders positiv finde ich bei dieser Erweiterung das User Interface. Es wirkt äußerst clean und lässt sich mit einem Tablet sehr gut bedienen. Alle Schaltflächen haben eine vernünftige Größe, wodurch fehlerhafte Klicks vermieden werden können. Die Funktionen sind zudem logisch gruppiert, und auch wenn die Extension im Frontend wie auch im Backend über verschiedenste Möglichkeiten verfügt, wirkt sie nicht überladen. Daher ist diese Erweiterung, möchten Sie einen recht einfachen Point of Sale ermöglichen, meine Empfehlung an Sie. Mit 599 US$ gehört sie zwar zu den kostenintensiveren Erweiterungen, das Geld ist jedoch gut investiert. Weitere Informationen erhalten Sie unter https://www.magestore.com/magento-2-pos-extension.html.

22.3.3    ebizmarts POS

Im Gegensatz zu den beiden bereits vorgestellten Extensions bietet der Hersteller ebizmarts mit seiner Erweiterung POS eine recht umfangreiche Point-of-Sale-Lösung, die auch in der Lage ist, z. B. mit Kassen zusammenzuarbeiten. Magento fungiert weiterhin als treibende Komponente, wobei Bestellungen über eine eigens entwickelte App aufgegeben und verwaltet werden. Dadurch steht Ihnen eine für Tablets optimierte Oberfläche bereit, wodurch das Handling äußerst einfach ist. Interessant wird die Lösung jedoch gerade wegen der Hardware, d. h., Sie können eine Kasse, einen Drucker oder auch einen Scanner anschließen und diese Geräte verwenden. Unterstützt werden aktuell folgende Geräte:

  • iPad Air 1/2/3
  • iPad mini 1/2/3
  • iPad 4
  • iPad 3
  • iPad 2
  • Star Micronics TSP143Lan
  • Star Micronics TSP700 Series (nur Modelle mit Ethernet-Anschluss)
  • Star Micronics TSP650 II BTi
  • Star Micronics SM-T300i
  • Socket Mobile CX2870-1409
  • Socket Mobile CHS 7QI
  • Motorola LI4278
  • Koamtac KDC425IT
  • EC-410 DigiPos Cash Base Drawer

Dadurch können Sie für die Durchführung der Transaktion ein iPad verwenden, Belege können mit einem der aufgeführten Drucker ausgedruckt werden, zur einfacheren Bestellung können Sie zudem auf einen Barcode-Scanner zurückgreifen, und eine Kasse rundet das Gesamtpaket ab. Sprich, Sie können auf jede Art Hardware zurückgreifen, die in einem Point of Sale zum Einsatz kommt.

Magento 1 und Magento 2 Community sowie Enterprise Edition

Ebizmarts unterstützt mit der entwickelten POS-Lösung neben Magento 2 übrigens auch Magento 1. Zudem lässt sich die Lösung sowohl mit der Enterprise Edition als auch mit Magento Open Source (ehemals Community Edition) nutzen. Dadurch deckt ebizmarts die komplette Magento-Produktpalette vollständig ab.

Die in der App implementierte Backend-Oberfläche unterstützt zudem alle Funktionen, die Sie im Alltag benötigen. Angefangen von Bestellkommentaren über Gutscheine bis hin zu Rabatten. In diesen Bereichen dürften keine Wünsche übrigbleiben. Im Gegensatz zu den bereits vorgestellten Lösungen müssen Sie bei ebizmarts POS mit monatlichen Kosten zwischen 44 € und 84 € rechnen. Insgesamt stehen drei verschiedene Tarifstufen zur Verfügung, die sich anhand der angebotenen Funktionalitäten unterscheiden. Ein weiterer Unterschied, ganz unabhängig vom aufgerufenen Preis, besteht zudem in der Demo-Version. Bei den bereits behandelten PoS-Lösungen konnten Sie problemlos auf eine Demo-Version zurückgreifen, was bei ebizmarts leider nicht möglich ist. Das liegt primär an der benötigten App, die Sie sich zu Testzwecken leider nicht einfach herunterladen können. Auf der offiziellen Website, die Sie unter https://pos.ebizmarts.com erreichen, erhalten Sie jedoch eine Menge Informationen und können zudem direkten Kontakt zu ebizmarts aufnehmen.

22.3.4    Beurteilung der verschiedenen PoS-Lösungen

Welche Lösung in Ihrem konkreten Fall die sinnvollste ist, lässt sich von außen schwer beurteilen. Wenn Sie Hardware anbinden möchten, beispielsweise eine Kasse oder einen Barcode-Scanner, ist die Lösung von ebizmarts definitiv die ausgereifteste. Müssen Sie hingegen keine Hardware anbinden, so lohnt sich auch ein Blick auf die Erweiterung von Magestore. Hier sparen Sie sich monatliche Kosten und können gegebenenfalls auch selbst Hand anlegen und die Extension selbst erweitern.
