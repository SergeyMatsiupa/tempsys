15.4    Datenquellen anbinden und überwachen

Wie eingangs erwähnt, lebt Magento BI von den unterschiedlichsten Datenquellen. Das heißt, im Gegensatz zu Google Analytics verfügt Magento BI nicht über eine Datenquelle, sondern über einen ganzen Datentopf, der sich aus mehreren Quellen speist. Wenn Sie nun neue Datenquellen hinzufügen möchten, klicken Sie bitte auf Manage Data • Data Sources • Integrations. Daraufhin erhalten Sie eine Übersicht über alle aktiven Datenquellen samt Status. Sie werden an dieser Stelle nun die Datenquelle »Magento 2 System foodbaer.de« vorfinden, die erfolgreich angebunden ist. Auch hier setzt Magento BI auf ein visuelles Feedback. Solange das Icon vor der Datenquelle grün ist, ist alles im Lot. Erst wenn Sie ein rotes Icon sehen, sollten Sie sich Gedanken machen und die Integration überprüfen. In dieser Ansicht erhalten Sie zudem weitere Informationen wie den letzten Zeitpunkt der Datensynchronisation, und Sie sehen darüber hinaus, ob aktuell eine Datensynchronisation läuft.

Um eine neue Datenquelle hinzuzufügen, klicken Sie auf den Button Add Integration, den Sie in der rechten oberen Ecke vorfinden. Sie gelangen daraufhin zur Übersichtsseite der momentan vorhandenen Integrationsmöglichkeiten, die Sie zudem in Abbildung 15.6 sehen.

Abbildung 15.6    Aktuell unterstützt Magento BI eine Vielzahl von Anwendungen, die Sie mit wenigen Klicks integrieren können.

Bei den Integrationsmöglichkeiten können Sie zwischen Anbindungen an konkrete Softwarelösungen und Datenbanken bzw. Dateien differenzieren. Magento BI lässt sich z. B. mit wenigen Klicks an Google Analytics, Google AdWords, Zendesk oder Facebook Ads anbinden. Sie können jedoch auch direkt einen MySQL- oder MS-SQL-Server andocken. Auch der Import auf Basis von CSV-Dateien ist kein Problem, zudem stellt Magento BI eine API bereit. Sofern keine konkrete Anbindung an eine bestimmte Software vorhanden ist, ist das an dieser Stelle daher kein Ausschlusskriterium, da Sie im Zweifel direkt auf die Datenbank der Software gehen können. In der aufgeführten Liste werden Sie so auch kein Magento-Logo sehen, da es so gesehen keine direkte Magento-Integration gibt. Magento BI nutzt hierfür den Integrationstyp MySQL und verbindet sich direkt auf die MySQL-Datenbank von Magento, um an die benötigten Informationen zu kommen.

Als praxisnahes Beispiel möchte ich Ihnen an dieser Stelle die Anbindung an Google Analytics zeigen, da vermutlich Google Analytics immer angebunden werden wird. Klicken Sie hierzu einfach auf das Google-Analytics-Logo, das Sie ebenfalls in Abbildung 15.6 sehen. Anschließend werden Sie zu Google weitergeleitet, und Sie müssen sich mit Ihren Zugangsdaten anmelden.

Sofern die Anmeldung geklappt hat, fragt Google Analytics, ob Sie Magento BI den Zugriff auf die Daten gewähren möchten. Auch an dieser Stelle ist wieder von rjmetrics.com die Rede, gemeint ist jedoch Magento BI. Bestätigen Sie diese Frage, und klicken Sie auf zulassen.

Sie landen wiederum in der Magento-BI-Oberfläche und erhalten eine Auflistung aller Profile, die in Ihrem Google-Analytics-Konto vorhanden sind. Wählen Sie nun bitte eines bzw. mehrere Profile aus, die Sie mit Magento BI verbinden möchten. In meinem konkreten Fall wähle ich an dieser Stelle das foodbaer.de-Profil, da mir dieses die Informationen aus dem Magento-Shop bereitstellt. Theoretisch könnten Sie später jedoch auch mehrere Profile haben, die für das Tracking der unterschiedlichen Sprachen und Versionen Ihres Online-Shops verantwortlich sind, daher handelt es sich an dieser Stelle um eine Mehrfachauswahl. Nach der Auswahl der Profile bzw. des Profils ist die Anbindung von Google Analytics erfolgreich abgeschlossen, und Ihr Magento-BI-System wird nun auch mit den Daten von Google Analytics gespeist.

Wie Sie sehen, ist die Anbindung zusätzlicher Dienste und Lösungen recht einfach. Bei Facebook haben Sie eine ähnliche Vorgehensweise, d. h., Sie authentifizieren sich mit Ihren Facebook-Daten und können die Datenquelle anschließend recht problemlos anbinden. Bei der Anbindung auf SQL-Ebene sieht es ähnlich aus. Hier müssen Sie in der Regel nur die Zugangsdaten zum SQL-Server hinterlegen und die Datenbank auswählen. Anschließend ist die Verbindung hergestellt, und Magento BI kann auf die im SQL-Server vorhandenen Daten zugreifen.
