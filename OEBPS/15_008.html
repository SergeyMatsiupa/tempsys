15.8    Daten und Berichte exportieren

Als letzten interessanten Punkt möchte ich Ihnen noch zeigen, wie Sie die in Magento BI vorhandenen Daten exportieren können. Ich hatte bereits erwähnt, dass Sie jeden Bericht individuell mit einer API ansprechen und die Daten dadurch auslesen können. Es gibt jedoch noch weitere Möglichkeiten, um die in Magento BI vorhandenen Daten zu extrahieren. Klicken Sie hierfür auf den Link Manage Data, der sich in der Hauptnavigation befindet. Im linken Navigationsbereich sehen Sie daraufhin den Oberpunkt Export Data, der sich am Ende der Seite befindet. Dieser Punkt enthält weitere Unterpunkte, die Ihnen z. B. erlauben, den API-Key anzulegen. Klicken Sie hierzu auf Export API. Den API-Key benötigen Sie später wiederum, um die verschiedenen Berichte per API anzusprechen. Zusätzlich können Sie die in Magento BI vorhandenen Daten auch automatisiert per E‐Mail versenden. Hierfür steht Ihnen der Menüpunkt Email Summaries zur Verfügung. Mithilfe der Email Summaries können Sie beliebig viele Berichte auswählen und an einem bestimmten Wochentag und in einem bestimmten Rhythmus an Empfänger per E‐Mail versenden. Letztendlich handelt es sich hierbei um nichts anderes als E‐Mail-Reports, die Sie definieren können. Beachten Sie jedoch an dieser Stelle, dass Sie nicht die ganzen Dashboards per E‐Mail versenden, sondern die Berichte individuell zusammenstellen können und müssen. Im letzten Menüpunkt namens Raw Data Export können Sie alle im System vorhandenen Tabellen und Spalten direkt exportieren. Auf den Export können zudem Filter, die Sie selbst definieren, angewendet werden. Mit dem Raw Data Export haben Sie somit die Möglichkeit, alle in Magento BI vorhandenen Daten auch wieder aus dem System zu exportieren. Als Download erhalten Sie anschließend übrigens ein Zip-Archiv, das eine CSV-Datei beinhaltet. Das heißt, Sie können das Ergebnis wiederum in externen Anwendungen, die den Import von CSV-Dateien unterstützen, weiterverwenden.
