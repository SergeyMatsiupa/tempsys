3.4    MageVM auf Basis von VirtualBox

Alternativ zum Setup eines eigenen Web- und Datenbankservers auf dem heimischen Computer haben Sie zudem die Möglichkeit, Magento mithilfe einer virtuellen Maschine lokal zu betreiben. Der Vorteil dieser Lösung besteht primär in der Einfachheit. Sie müssen keinen eigenen Web- und Datenbankserver installieren und konfigurieren. Zudem müssen Sie sich auch nicht um die Installation von Magento kümmern. Dank der virtuellen Maschine benötigen Sie ausschließlich die Anwendung VirtualBox sowie die MageVM und können anschließend innerhalb weniger Minuten loslegen.

Der Vorteil der Einfachheit hat auf der anderen Seite, wie sollte es anders sein, aber auch einen Nachteil. Bei einer virtuellen Maschine wird auf Ihrem Computer ein komplettes Betriebssystem, im Fall der MageVM eine Linux-Distribution emuliert. Eine virtuelle Maschine ist also ein Betriebssystem in Ihrem Betriebssystem. Dieses Konzept geht in der Regel zu Lasten der Performance, da die Emulation eines kompletten Betriebssystems, wie Sie sich sicherlich vorstellen können, eine gewisse CPU-Power und auch Arbeitsspeicher voraussetzt. Aus diesem Grund sollten Sie diese Option nur ins Auge fassen, wenn Sie einen halbwegs aktuellen Computer haben, der über mindestens 4 GB Arbeitsspeicher verfügt. Ansonsten könnten Sie zwar die Installation von VirtualBox durchführen und die virtuelle Maschine betreiben. Es wäre aber voraussichtlich ein enorm langsames Arbeiten, das Ihnen sicherlich keine Freude bereiten würde.

3.4.1    Installation von VirtualBox

Für den Betrieb der MageVM benötigen Sie als Basis die Software VirtualBox. Bei VirtualBox handelt es sich um eine kostenfreie Anwendung, auf deren Basis Sie virtualisierte Systeme betreiben können. Ihnen ist gegebenenfalls die Anwendung VMware geläufig, die im Prinzip dieselbe Funktionsweise wie VirtualBox aufweist. Der große Vorteil von VirtualBox ist meiner Meinung nach die einfache Bedienung, aber auch die Tatsache, dass Sie die Software kostenlos nutzen können. Zudem steht VirtualBox für alle gängigen Betriebssysteme zur Verfügung. Es spielt also keine Rolle, ob Sie als Leser Windows, Linux oder macOS nutzen. Die Software steht für alle diese Plattformen bereit und besitzt ebenso übergreifend eine identische Benutzeroberfläche. Auch wenn ich im Folgenden Windows verwende, so ist doch die Vorgehensweise unter Linux bzw. macOS komplett identisch.

Um nun zu starten, müssen Sie im ersten Schritt die Anwendung VirtualBox herunterladen. Gehen Sie hierfür im Browser Ihrer Wahl auf http://www.virtualbox.org, und klicken Sie im linken Navigationsbereich auf »Downloads«. Anschließend müssen Sie die Plattform wählen, sprich unter welchem Betriebssystem Sie VirtualBox installieren möchten. Ich wähle in meinem Fall Windows, da mein verwendetes Betriebssystem Windows ist. Wie erwähnt, kann VirtualBox neben Windows auch unter Linux, macOS und sogar Solaris betrieben werden. Wählen Sie Ihre Plattform, und klicken Sie anschließend auf den verlinkten Bereich, den Sie auch in Abbildung 3.27 sehen, hinter dem gewählten Betriebssystem, um den Download zu starten.

Installation der VirtualBox unter Windows

Aus Gründen der Einfachheit beschreibe ich Ihnen im Folgenden die Installation der VirtualBox unter Microsoft Windows 10. Der Installationsprozess unterscheidet sich speziell in Bezug auf Linux bzw. macOS an einigen Stellen. Wenn Sie eine ausführliche Installationsanleitung für Ihr Betriebssystem benötigen, kann ich Ihnen folgenden Link ans Herz legen: https://www.virtualbox.org/manual/ch02.html.

Unter dieser URL finden Sie eine ausführliche Dokumentation und Beschreibung des Installationsprozesses für Linux, Windows und macOS, die Ihnen bei Problemen sicherlich weiterhelfen wird.

Anschließend startet der knapp 100 MB große Download und ist bei Ihnen je nach Internetverbindung innerhalb weniger Sekunden oder Minuten abgeschlossen. Nachdem Sie die Installationsdatei erfolgreich heruntergeladen haben, starten Sie diese durch einen Doppelklick.

Abbildung 3.27    Die VirtualBox steht für verschiedenste Betriebssysteme zum Download zur Verfügung.

Daraufhin öffnet sich der Installationsprozess. Klicken Sie, nachdem sich der Installationsprozess geöffnet hat, in der ersten Maske auf Next, um die Installation zu beginnen. Daraufhin werden Sie zu einer Maske geführt, in der Sie verschiedene Installationskomponenten auswählen können. Innerhalb dieser Ansicht müssen Sie jedoch keine Anpassungen vornehmen, sondern können durch einen Klick auf Next fortfahren. Abschließend werden Sie noch gefragt, ob Sie einen Eintrag im Startmenü bzw. eine Desktopverknüpfung wünschen. Diese Auswahl überlasse ich Ihnen, im Prinzip können Sie aber auch hier direkt ohne weitere Änderung auf Next klicken. Daraufhin sollten Sie eine Warnung erhalten, die Sie in Abbildung 3.28 sehen. VirtualBox warnt Sie im Vorfeld, dass Ihre Netzwerkverbindung kurzzeitig deaktiviert wird. Dies müssen Sie bestätigen, was Sie aber letztendlich bedenkenlos machen können, da diese Entscheidung keine negativen Auswirkungen hat.

Klicken Sie anschließend auf Yes, um mit der Installation fortzufahren, und in der darauffolgenden Maske auf Install. Nun ist der Zeitpunkt gekommen, zu dem der eigentliche Installationsprozess startet und VirtualBox auf Ihrem Computer installiert wird.

Abbildung 3.28    VirtualBox warnt innerhalb des Installationsprozesses vor einer kurzfristigen Deaktivierung der Netzwerkverbindung.

Sollte während der Installation nochmals ein Dialogfenster erscheinen, was unter anderem von Ihrer verwendeten Windows-Version abhängig ist, können Sie dieses bedenkenlos bestätigen. Andernfalls würde der Installationsprozess nicht fortgeführt werden. Nach einigen Minuten ist der Installationsprozess abgeschlossen, und Sie haben VirtualBox erfolgreich installiert!

Auch wenn Sie VirtualBox nun erfolgreich installiert haben, empfehle ich Ihnen zusätzlich die Installation des VirtualBox Extension Packs. Es handelt sich hierbei um ein Add-on zu VirtualBox, das die Performance der virtuellen Maschine, aber auch deren Funktionsumfang erweitert. Auch hierbei fallen für Sie keinerlei Kosten an, weswegen es auch keinen Grund gibt, die Erweiterung nicht zu installieren. Rufen Sie in Ihrem Browser erneut die Download-Seite von VirtualBox auf, die Sie direkt unter https://www.virtualbox.org/wiki/Downloads erreichen. Scrollen Sie nun herunter bis zum Eintrag VirtualBox 5.1.2 Oracle VM VirtualBox Extension Pack. Bitte beachten Sie, dass sich die Version während der Arbeit an diesem Buch geändert haben kann, gegebenenfalls steht daher eine neue Version zum Download bereit. Ungeachtet dessen, klicken Sie nun auf den Link All supported platforms, um den Download des Extension Packs zu starten. Haben Sie die Datei erfolgreich heruntergeladen, öffnen Sie diese durch einen Doppelklick. VirtualBox fragt Sie anschließend, ob Sie das Extension Pack installieren möchten, was Sie bestätigen.

Nach der Installation des Extension Packs sind Sie mit dem Setup von VirtualBox fertig, und dem Betrieb der MageVM steht nichts mehr im Weg.

3.4.2    Installation von MageVM

Bei der MageVM handelt es sich um eine auf Linux basierende virtuelle Maschine, die über einen vorkonfigurierten Web- und Datenbankserver verfügt und darüber hinaus alle Magento 2-Versionen beinhaltet. Damit stellt die MageVM den mit Abstand einfachsten Weg dar, um ohne technisches Wissen an eine lokale Magento-Installation zu kommen. Zudem fallen für die Nutzung von MageVM keinerlei Kosten an, weswegen die MageVM von jedermann, selbst für kommerzielle Zwecke, eingesetzt werden kann.

Damit Sie die MageVM betreiben können, müssen Sie diese zuerst herunterladen. Rufen Sie hierfür die URL http://www.alexander-steireif.com/portfolio/magevm-magento-2-virtuelle-maschine/ auf. Auf dieser Seite finden Sie alle für das System benötigten Zugangsdaten, den Download sowie eine kurze Installationsanleitung. Scrollen Sie etwas nach unten, und klicken Sie auf den Button Jetzt kostenlos herunterladen, um den Download zu beginnen. Da es sich um eine knapp 6 GB große Datei handelt, wird der Download bei Ihnen voraussichtlich ein paar Minuten bis hin zu einer Stunde dauern. Sie haben also jetzt die Möglichkeit, sich einen Kaffee zu holen und eine kurze Verschnaufpause einzulegen. ;)

MageVM enthält alle Magento 2-Versionen

Ein großer Vorteil der MageVM besteht unter anderem darin, dass Sie Zugriff auf alle Versionen von Magento 2 haben. Diese sind sowohl mit den Dummy-Daten als auch jeweils ohne Dummy-Daten bereits vorinstalliert. In der aktuellen Version der MageVM können Sie dadurch auf alle Magento-Versionen von 2.0.0 bis 2.1.7 zugreifen.

Nachdem Sie die MageVM heruntergeladen haben, müssen Sie diese entpacken. Die MageVM wird, um die Download-Größe zu minimieren, als gepacktes Zip-Archiv ausgeliefert. Dementsprechend benötigen Sie ein Programm, um dieses Zip-Archiv zu entpacken. Unabhängig von Ihrem gewählten Betriebssystem sollte ein solches Programm von Haus aus in Ihrem Betriebssystem enthalten sein. Sollte dies nicht der Fall sein, kann ich Ihnen zumindest unter Windows die kostenfreie Anwendung 7-Zip empfehlen, die Sie unter http://www.7-zip.de/ herunterladen können. Sobald Sie die MageVM entpackt haben, öffnen Sie bitte die VirtualBox, und klicken Sie auf Datei • Appliance importieren, wie in Abbildung 3.29 zu sehen.

Abbildung 3.29    Zuerst müssen Sie die MageVM in Ihre VirtualBox importieren.

Daraufhin öffnet sich ein Dialogfenster, in dem Sie nach einer Datei gefragt werden. Wählen Sie anschließend die Datei MageVM-2-1-0.ova aus, die durch das Entpacken der MageVM zur Verfügung steht. Klicken Sie anschließend auf Weiter. Im nächsten Dialogfeld haben Sie die Möglichkeit, Appliance-Einstellungen zu ändern. Diesen Dialog können Sie getrost ignorieren, Sie müssen keine Anpassungen bei den Einstellungen vornehmen. Um den Importprozess zu starten, klicken Sie bitte auf Importieren. VirtualBox importiert jetzt die MageVM, Sie sehen das in Abbildung 3.30. Dieser Vorgang kann je nach Hardware Ihres Computers bis zu 30 Minuten dauern.
