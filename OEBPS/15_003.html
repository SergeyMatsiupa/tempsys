15.3    Magento-BI-Backend im Überblick

Nachdem Sie Ihren Magento-BI-Account erfolgreich eingerichtet haben, können Sie im nächsten Schritt das Magento-BI-Backend aufrufen. Sollten Sie das Browser-Fenster während des mehrminütigen Setup-Prozesses geschlossen haben, rufen Sie bitte die URL https://dashboard.rjmetrics.com auf, um in das Magento-BI-Backend zu gelangen. Ich möchte Ihnen zunächst eine kurze Einführung in die Oberfläche geben, sodass Sie sich im Verlauf der nächsten Seiten gut orientieren können und die Punkte finden, die ich im Text erwähne.

Magento BI verfügt über eine primäre Navigationsleiste, die Sie im oberen Bereich der Seite vorfinden (siehe Abbildung 15.4). Es ist die einzige Navigationsleiste, die im System besteht, und Sie erreichen alle Menüpunkte über diese eine Navigationsleiste.

Abbildung 15.4    Die einzig vorhandene Navigationsleiste befindet sich im oberen Bereich der Seite.

Im Menüpunkt Dashboards, den Sie aktuell bereits aufgerufen haben, erhalten Sie einen Einblick in die vorhandenen Reports und Analysen. Magento BI bildet alle Berichte innerhalb des Dashboards ab, wobei Sie beliebig viele Dashboards anlegen können. Im Menüpunkt Report Builder, der Name ist an dieser Stelle recht aussagekräftig gewählt, können Sie neue Berichte erstellen und dem Dashboard zuweisen. Im dritten und letzten Bereich namens Manage Data können Sie sowohl Datenquellen pflegen als auch Filter und Metriken erstellen. Im Prinzip ist dieser Punkt die Systemkonfiguration, da er viele Verwaltungsfunktionen gruppiert.

Auf der rechten Seite der Navigationsleiste finden Sie darüber hinaus weitere Links und Menüs, die jedoch nichts mit der Software an sich zu tun haben. Wenn Sie auf das Lupen-Symbol klicken, können Sie das System durchsuchen. Geben Sie beispielsweise »Customer« ein, finden Sie Reports wie auch Metriken. Das Rettungsring-Icon verweist auf Support-Funktionen wie die Erstellung eines Tickets und enthält zudem ein Link zum offiziellen Hilfecenter unter https://rjmetrics.zendesk.com. Speziell als Magento-BI-Neuling hilft ein Blick in das Hilfecenter definitiv weiter, da dort viele Sachverhalte recht einfach und ohne ausschweifende Worte erklärt werden.

Neben dem Rettungsring-Icon finden Sie zudem ein Glocken-Symbol. Immer wenn es eine Meldung bzw. Notification innerhalb des Systems gibt, wird dieses Symbol entsprechend gekennzeichnet. Dadurch wissen Sie, dass irgendetwas passiert ist. Solange das Symbol jedoch grün ist, ist alles im grünen Bereich. Erst wenn Sie eine rote Kennzeichnung vorfinden, gibt es vermutlich mit einer Datenquelle ein Problem, und Sie sollten tiefer in die Details einsteigen.

Abbildung 15.5    Sie können sowohl das eigene Benutzerkonto verwalten als auch neue Konten anlegen.

Zu guter Letzt gibt es am rechten Bildschirmrand noch die Benutzerkontenverwaltung, die Sie in Abbildung 15.5 ausgeklappt sehen. An dieser Stelle können Sie die allgemeinen Informationen Ihres Unternehmens editieren, Zahlungsdaten einsehen, neue Benutzer anlegen und bestehende Benutzer sowie Ihr Profil verwalten. Alles, was mit Benutzern und dem Thema Zahlungen zu tun hat, ist daher in diesem Menüpunkt gruppiert.

Magento BI bietet momentan nur eine englische Oberfläche

Aktuell können Sie leider die Sprache der Oberfläche nicht umstellen, d. h., Magento BI ist derzeit nur in englischer Sprache verfügbar. Ob sich das mittel- bis langfristig ändern wird, ist aktuell noch nicht absehbar. Dementsprechend werde ich im Verlauf des Kapitels an den jeweiligen Stellen immer auf die englischen Begrifflichkeiten verweisen. Sofern gewisse Stellen jedoch etwas tricky und schwer zu verstehen sind, werde ich diese selbstverständlich übersetzen bzw. erklären.

Weitere Navigationspunkte gibt es an dieser Stelle nicht, daher ist der grundlegende Aufbau von Magento BI recht einfach und simpel, und auch als Neuling werden Sie sich recht schnell im System zurechtfinden.
