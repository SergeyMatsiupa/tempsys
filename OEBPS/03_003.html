3.3    Installation von Magento

Unabhängig davon, welches Betriebssystem Sie verwenden, sollten Sie an diesem Punkt eine lauffähige und vorkonfigurierte Webserver-Umgebung haben, um Magento installieren zu können. Da sich Magento auf unterschiedlichste Arten installieren lässt, möchte ich Ihnen die populärsten Varianten an dieser Stelle im Detail vorstellen. Welche Sie letztendlich bei sich lokal verwenden, bleibt Ihnen überlassen, und Sie können die Installationsroutine nehmen, die für Sie am einfachsten bzw. am schnellsten ist.

3.3.1    Grundvoraussetzung Datenbank

Bevor ich mit Ihnen an dieser Stelle die jeweiligen Installationsmöglichkeiten von Magento durchgehe, möchte ich das Thema Installation von Magento kurz verlassen und mich der Verwaltung der Datenbanken samt dem Tool phpMyAdmin widmen. Für die Installation von Magento benötigen Sie eine Datenbank. Wenn Sie mit den verschiedenen Installationsmöglichkeiten etwas experimentieren, sind mehrere Datenbanken notwendig. Da Magento innerhalb des Installationsprozesses keine Datenbank automatisch anlegt, müssen Sie dies im Vorfeld machen. Damit Sie bei der Anlage der Datenbanken nicht in die Tiefen von MySQL auf Basis der Kommandozeile abtauchen oder eine weitere Software installieren müssen, steht Ihnen das Werkzeug phpMyAdmin zur Verfügung. Dieses wird Ihnen, wie Sie auf den vorherigen Seiten bereits erfahren haben, mit XAMPP von Haus aus ausgeliefert.

Um phpMyAdmin zu starten, öffnen Sie den Webbrowser Ihrer Wahl und rufen die URL http://127.0.0.1/phpmyadmin auf. Sie erhalten anschließend eine Ansicht wie in Abbildung 3.15.

Auf der linken Seite sehen Sie alle bereits angelegten Datenbanken. Hier können Sie per Klick auf die jeweilige Datenbank eine auswählen und erhalten anschließend eine Auflistung aller Tabellen. Bei den jeweiligen Tabellen können Sie die Einträge einsehen, die Struktur editieren oder grundsätzlich SQL Queries ausführen.

Abbildung 3.15    phpMyAdmin ist das Tool schlechthin, wenn es um die Verwaltung von Datenbanken geht.

Um eine weitere Datenbank anzulegen, klicken Sie in der linken Navigationsleiste, in der Sie alle bereits angelegten Datenbanken sehen, auf Neu. Sie werden zu einer neuen Maske weitergeleitet, in der Sie einen Datenbanknamen eingeben können. Zudem können Sie die Kollation auswählen, wobei Sie an dieser Stelle keine Änderung vornehmen möchten. Legen Sie jetzt eine neue Datenbank namens magento an, indem Sie den Datenbanknamen eingeben und auf Anlegen klicken. Daraufhin erhalten Sie von phpMyAdmin eine Erfolgsmeldung, und Sie haben die neue Datenbank problemlos angelegt.

Bitte haben Sie an dieser Stelle Verständnis, dass eine ausführliche Erklärung dieses umfangreichen Datenbankadministrationswerkzeugs zu weit ginge. Die wichtigste Funktion, um den Anleitungen dieses Buches folgen zu können, ist die Anlage neuer Datenbanken. Wenn Sie Probleme beim Umgang mit phpMyAdmin haben oder sich die verschiedenen Möglichkeiten der Software anschauen möchten, empfehle ich Ihnen die offizielle Dokumentation, die Sie unter https://www.phpmyadmin.net/docs/ einsehen können. Dank dieser Dokumentation dürften bei Ihnen keine Fragen offenbleiben.

3.3.2    Klassische Installation per Weboberfläche

Die einfachste Installationsvariante taufe ich spontan die klassische Installation. Hierbei laden Sie sich das komplette Magento-Installationsarchiv herunter und installieren die Software. Rufen Sie, um Magento herunterzuladen, zuerst die Website http://www.magento.com auf. In einer ruhigen Minute sollten Sie sich grundsätzlich ein wenig mit der offiziellen Magento-Website beschäftigen, denn neben dem Download der Software finden Sie hier die Magento-Dokumentation und auch das offizielle Forum. Die Magento-Website sollte daher Ihre erste Anlaufstelle bei Fragen oder Problemen sein.

Klicken Sie in der Hauptnavigation auf Products & Solutions und dann auf Open Source. Alternativ können Sie diese Seite ebenso direkt unter https://magento.com/products/open-source aufrufen. Im oberen Bereich der Seite finden Sie anschließend einen Button mit der Beschriftung Download now vor, auf den Sie klicken. Sie gelangen zur Download-Seite von Magento, die Ihnen die verschiedenen Versionen und Updates zu Magento anbietet.

Magento mit und ohne Dummy-Daten

Unabhängig von der jeweiligen Magento-Version steht jede Version in zwei Varianten zur Verfügung. Sie können Magento mit, aber auch ohne Dummy-Daten, auch Sample Data genannt, herunterladen. Die Variante ohne Dummy-Daten entspricht einer »nackten« Magento-Installation. Laden Sie die Variante mit Dummy-Daten herunter, werden Sie bereits Produkte, Kategorien und Kundendaten vorfinden.

Wählen Sie jetzt bei der aktuellsten Version von Magento (zum Zeitpunkt der Manuskripterstellung ist das die Version 2.1.7) den Full Release ohne Dummy-Daten (Sample Data) aus. Es stehen Ihnen drei Download-Varianten zur Verfügung, unterschieden nach der Art der Kompression. Ich wähle in meinem Fall das Zip-Archiv und klicke anschließend auf Download.

Der Download von Magento ist nur möglich, wenn Sie über ein Benutzerkonto verfügen und angemeldet sind, Sie sehen den entsprechenden Dialog in Abbildung 3.16.

Abbildung 3.16    Ein Download von Magento ist nur im angemeldeten Zustand möglich.

Sollten Sie noch kein Benutzerkonto auf magento.com angelegt haben, können Sie dies nun erledigen, indem Sie auf Create an Account now klicken. Die Erstellung ist innerhalb weniger Minuten erledigt und für Sie mit keinerlei Kosten verbunden. Sie können daher das Benutzerkonto bedenkenlos registrieren. Damit haben Sie übrigens später auch die Möglichkeit, im Magento-Diskussionsforum aktiv zu werden und Fragen zu stellen sowie anderen Nutzern bei deren Problemen zu helfen. Für den Fall, dass Sie bereits über ein Benutzerkonto verfügen, können Sie sich an dieser Stelle mit Ihren Benutzerkontodaten anmelden, um den Download zu starten. Nachdem Sie das Installationsarchiv heruntergeladen haben, müssen Sie dies anschließend in Ihren htdocs-Ordner in einem Ordner, den Sie frei benennen können, extrahieren. Der htdocs-Ordner befindet sich bei Ihnen je nach gewähltem Betriebssystem und Installationsoption an unterschiedlichen Stellen. Sollten Sie sich an diesem Punkt nicht sicher sein, werfen Sie bitte nochmals einen Blick in die beschriebene Installationsanleitung von XAMPP für Ihr Betriebssystem, denn aus der Anleitung geht der htdocs-Ordner hervor. Innerhalb des htdocs-Ordners empfehle ich Ihnen die Anlage eines Verzeichnisses namens magento, in das Sie alle Dateien extrahieren. Ihr Verzeichnis und dessen Inhalte sollten anschließend aussehen wie in Abbildung 3.17.

Rufen Sie anschließend über Ihren Browser die Magento- Installationsroutine auf, indem Sie die URL http://127.0.0.1/magento verwenden. Haben Sie den Ordner mit dem Magento-Archiv anders benannt, müssen Sie die URL entsprechend anpassen. Haben Sie die richtige URL aufgerufen, werden Sie den Magento-Installationsprozess vorfinden. Um diesen zu starten, müssen Sie als Nächstes auf Agree and Setup Magento klicken. Im ersten Schritt des Installationsprozesses prüft Magento die technischen Voraussetzungen. Diese sollten Sie unabhängig vom verwendeten Betriebssystem erfüllen, wenn Sie XAMPP gemäß Anleitung installiert haben. Klicken Sie auf Start Readiness Check, um die technischen Voraussetzungen für die Installation von Magento zu prüfen. Im Idealfall sollten Sie eine Ansicht wie in Abbildung 3.18 erhalten.

Abbildung 3.18    Die Magento-Installationsroutine prüft die technischen Voraussetzungen.

Da in meinen Fall alle Haken grün eingefärbt sind, kann ich mit der Installation fortfahren. Sie sollten exakt dieselbe Darstellung vorfinden. Sollte es, aus welchen Gründen auch immer, bei Ihnen zu Problemen kommen, zeigt Ihnen Magento exakt das Problem an. Ein häufig auftretendes Problem ist eine zu alte PHP-Version, aber auch fehlende PHP-Erweiterungen können Probleme verursachen. Sollte dies bei Ihnen auch der Fall sein, beispielsweise, wenn Sie nicht XAMPP, sondern ein anderes Setup verwenden, müssen Sie an dieser Stelle eingreifen.

Magento zeigt Ihnen jedenfalls eine so detaillierte Fehlermeldung wie möglich an. Klicken Sie auf Next, um mit der Installation fortzufahren. In der darauffolgenden Ansicht müssen Sie im zweiten Schritt die Zugangsdaten zur Datenbank hinterlegen. Hierfür können Sie folgende Einstellungen verwenden:

  • Database Server Host: localhost bzw. 127.0.01
  • Database Server Username: root
  • Database Server Password: leer lassen, da XAMPP im Standard kein Passwort für den MySQL-root-Benutzer hinterlegt
  • Database Name: der von Ihnen definierte Datenbankname, z. B. magento
  • Table prefix: leer lassen

Im Prinzip müssen Sie nur den Datenbanknamen abändern, je nachdem welchen Namen Sie bei der Anlage der Datenbank in phpMyAdmin hinterlegt haben. Nachdem Sie das Formular ausgefüllt haben, klicken Sie auf Next.

Im dritten Konfigurationsschritt können Sie die URL Ihres Magento-Shops sowie des Magento-Backends definieren. Das Backend ist der Administrationsbereich, mit dessen Hilfe Sie später Magento verwalten können. Die vorausgefüllten Einstellungen können Sie an dieser Stelle belassen, wie sie sind.

Merken Sie sich die Magento-Admin-Adresse

In Version 1 war das Magento-Backend immer unter /admin aufrufbar. Aus Sicherheitsgründen erzeugt Magento 2 bei der Installation eine individuelle Backend-URL, z. B. /admin_4abg1s. Diese können Sie bei der Installation selbst editieren, der Grundgedanke einer komplett individuellen URL für das Backend ist jedoch richtig. Notieren Sie sich daher bei der Installation die definierte Backend-URL, bzw. legen Sie ein entsprechendes Bookmark an.

Neben den URLs können Sie zudem weitere Einstellungen vornehmen. Diese befinden sich im Punkt Advanced Options, den Sie durch einen Klick öffnen können, wie Sie in Abbildung 3.19 sehen.

Abbildung 3.19    Erweiterte Einstellungen lassen sich im Konfigurationsschritt drei durch Aufklappen der »Advanced Options« hinterlegen.

Bei den HTTPS Options können Sie durch einen Haken bei der Storefront (Frontend) bzw. Admin (Backend) definieren, ob Sie SSL verwenden möchten. Haben Sie beispielsweise bei Ihrem Webhoster ein SSL-Zertifikat, das gesicherte Verbindungen ermöglicht, muss bei den URLs anstelle von http das Protokoll https verwendet werden. Sollte Ihnen bei der Installation ein solches SSL-Zertifikat bereits zur Verfügung stehen, was im Fall von XAMPP jedoch nicht zutrifft, können Sie dies an dieser Stelle entsprechend vermerken. Bei den Apache Rewrites handelt es sich um suchmaschinenfreundliche URLs. Magento hat zwei Methoden, um URLs zu erzeugen; diejenige, die über die Apache Rewrites läuft, ist die bessere. Aus diesem Grund ist diese Option bereits vorausgewählt. Eine Abwahl der Option würde nur sinnvoll sein, wenn Sie nicht auf die Apache Rewrites zurückgreifen können, z. B. wenn Sie einen anderen Webserver als den IIS unter Windows verwenden würden. Der Encryption Key dient zur Verschlüsselung der Passwörter. Magento kann einen Encryption Key erzeugen; wenn Sie bereits einen haben, könnten Sie diesen an dieser Stelle hinterlegen, indem Sie die Option I want to use my own encryption key auswählen. Auch diese Option soll Sie an dieser Stelle nicht stören; belassen Sie die Auswahl bitte bei I want to use a Magento generated key. Bei der letzten Option können Sie den Speicherort der Session-Dateien definieren. Zur Auswahl stehen das Dateisystem und die Datenbank. Welche Option besser ist, kann pauschal nicht beantwortet werden. Es hängt immer vom Hosting-Setup, der Performance der Server aber auch von der gesamten Infrastruktur ab. Belassen Sie bei der lokalen Installation ruhig die Option bei Files, beim lokalen Setup würden Sie keine Unterschiede zwischen beiden Optionen feststellen. Klicken Sie auf Next, um den nächsten Installationsschritt zu initialisieren.

Der vierte Schritt dreht sich primär um Lokalisierungsoptionen. Treffen Sie hierfür folgende Einstellungen:

  • Store Default Time Zone: Central European Standard Time (Europe/Berlin)
  • Store Default Currency: Euro (EUR)
  • Store Default Language: German (Germany)

Neben den Lokalisierungsoptionen können Sie innerhalb dieses Schrittes beim Punkt Advanced Modules Configurations definieren, welche Magento-Module Sie installieren möchten. Mit Version 2 hat Magento einen noch modulareren Aufbau erhalten. Dieser modulare Aufbau ermöglicht die gezielte Installation von einzelnen Komponenten und bietet zudem die Möglichkeit, einzelne Komponenten auszutauschen, ohne gleich die gesamte Software modifizieren zu müssen. Belassen Sie hier die Vorauswahl, die alle Magento-Komponenten installiert, und klicken Sie auf Next.

Die Installation neigt sich mit dem fünften Schritt dem Ende zu; hier müssen Sie einen Administrations-Account anlegen (siehe Abbildung 3.20).

Abbildung 3.20    Die Anlage eines Administrations-Accounts

Dazu sind ein Benutzername, eine E-Mail sowie ein Passwort notwendig. Füllen Sie die dargestellten Formularfelder aus, und klicken Sie auf Next. Sie gelangen zum sechsten Schritt, der aus dem Button Install now besteht, den Sie bestätigen, um schließlich die Installation von Magento zu starten. Magento beginnt nun mit der Installation des Systems, was einige Zeit in Anspruch nehmen kann. Sie sehen zu jedem Zeitpunkt, mit welchen Tätigkeiten die Installationsroutine beschäftigt ist (siehe Abbildung 3.21).

Abbildung 3.21    Der Installationsfortschritt von Magento wird unter anderem in einem Log ausgegeben.

Sobald Magento mit dem Installationsprozess fertig ist, sehen Sie eine neue Seite samt Erfolgsmeldung. Auf dieser Seite erhalten Sie nochmals eine Zusammenfassung wichtiger Daten. Neben Ihrem Benutzernamen zeigt Magento die Frontend- und Backend-URL an, zudem erhalten Sie den Encryption Key. Es kann durchaus sinnvoll sein, diese Seite in Form einer PDF-Datei zu speichern bzw. sich die wichtigsten Informationen zu notieren. Besonders wichtig ist an dieser Stelle, wie eingangs erwähnt, die Backend-URL, da diese bei jeder Magento-Installation individuell erzeugt wird.

Bevor ich Ihnen nun zur Installation von Magento 2 gratulieren kann, müssen Sie abschließend noch eine weitere Anpassung vornehmen. Da Magento während der Nutzung relativ viele dynamische Dateien erzeugt, benötigt es entsprechende Schreibrechte. Sie müssen daher dem Hauptverzeichnis von Magento erweiterte Rechte zuweisen. Öffnen Sie hierfür das htdocs-Verzeichnis, klicken Sie mit der rechten Maustaste auf das Verzeichnis Magento, und wählen Sie den Menüpunkt Eigenschaften. Entfernen Sie bei Attribute den Haken Schreibgeschützt (betrifft nur Dateien im Ordner), und bestätigen Sie mit ok.

Berechtigungen unter macOS und Linux

Für den Fall, dass Sie macOS bzw. Linux einsetzen, müssen Sie die Berechtigungen des Verzeichnisses ebenfalls anpassen. Der einfachste Weg bei beiden Systemen führt über das Terminal. Rufen Sie dieses auf, und führen Sie den folgenden Befehl aus, bei dem Sie aber noch den Verzeichnispfad Ihrer Magento-Installation entsprechend anpassen müssen:

chmod -R 777 /pfad/zu/htdocs/magento

Nachdem Sie die Schreibrechte angepasst haben, müssen Sie anschließend noch die statischen Dateien erzeugen.

Starten Sie hierfür unter Windows die Eingabeaufforderung, und navigieren Sie in das Hauptverzeichnis Ihrer Magento-Installation. In meinem Fall befindet sich dieses unter C:/xampp/htdocs/magento, weswegen ich mit dem Befehl cd C:/xampp/htdocs/magento direkt in dieses Verzeichnis wechseln kann. Innerhalb dieses Verzeichnisses müssen Sie den Befehl php bin/magento setup:static-content:deploy de_DE ausführen.[ 8 ] Mit diesem Befehl starten Sie eine in Magento enthaltene Konsolenanwendung, die Sie im späteren Verlauf dieses Buches noch genauer kennenlernen werden. Diese Konsolenanwendung benötigen Sie in diesem Schritt für die Erzeugung der statischen Dateien. Für den Fall, dass Sie nicht Windows, sondern Linux oder macOS verwenden, ist die Vorgehensweise übrigens identisch. Einzig die Verzeichnisstruktur wird sich bei Ihnen geringfügig unterscheiden. Durch den Aufruf des oben aufgeführten Befehls erzeugt Magento nun die für den Betrieb benötigten statischen Dateien. Dabei handelt es sich primär um Grafiken, aber speziell die JavaScript- und CSS-Dateien sind elementar für den Betrieb von Magento. Würden Sie diesen Befehl nicht ausführen, würden Sie beim Aufruf des Frontends bzw. Backends eine recht zerstörte Darstellung erhalten, da Magento ohne Stylesheets und JavaScript-Funktionen geladen wird. Dieser Schritt ist also zwingend notwendig für die Installation von Magento.

Nachdem Sie diesen Schritt durchgeführt haben, haben Sie erfolgreich Magento installiert, und einer Nutzung des Systems steht nichts mehr im Weg. Gratulation, den ersten wichtigen Schritt für den Aufbau Ihres Online-Shops haben Sie somit gelegt!

3.3.3    Klassische Installation per Kommandozeile

Im vorherigen Abschnitt habe ich Ihnen gezeigt, wie Sie das heruntergeladene Installationspaket von Magento mittels der Weboberfläche, also mithilfe Ihres Browsers, installieren können. Alternativ hierzu gibt es jedoch noch eine weitere Möglichkeit zur Installation. Denn Sie können Magento auch mittels Terminal, sprich über die Konsole, installieren.

Legen Sie mithilfe von phpMyAdmin eine weitere Datenbank an, und laden Sie sich, sofern Sie das Zip-Archiv gelöscht haben, die aktuellste Version von Magento herunter. Die Vorgehensweise für diese beiden Aufgaben finden Sie in Abschnitt 3.3.1, »Grundvoraussetzung Datenbank«, und Abschnitt 3.3.2, »Klassische Installation per Weboberfläche«, weshalb ich an dieser Stelle auf eine Doppelung des Inhalts verzichte. Sobald Sie das Magento-Installationsarchiv heruntergeladen haben, entpacken Sie den gesamten Inhalt in ein beliebiges Verzeichnis in Ihrem htdocs-Ordner. Ich habe für dieses Beispiel ein weiteres Verzeichnis namens magento_terminal angelegt, das sich in meinem htdocs-Ordner befindet, d. h., die Verzeichnisstruktur auf meinem Computer lautet htdocs/magento_terminal. Sie können Ihre Verzeichnisstruktur mit der in Abbildung 3.22 ersichtlichen Struktur abgleichen, Ihre sollte, abgesehen vom Verzeichnisnamen, den Sie frei wählen können, identisch aussehen.

Abbildung 3.22    Verzeichnisstruktur von Magento

Öffnen Sie nach dem Extrahieren das Terminal. Unter Windows handelt es sich um die Eingabeaufforderung, unter macOS um das Terminal und unter Linux um die Shell. Navigieren Sie zu dem Verzeichnis, in das Sie Magento extrahiert haben. In meinem Fall erreiche ich den Verzeichniswechsel mit dem Befehl cd C:\xampp\htdocs\magento_terminal. Im Magento-Verzeichnis angekommen, können Sie mit dem Befehl php bin/magento die Magento-Konsolenanwendung aufrufen.

Auf die Konsolenanwendung und die Vielzahl von Möglichkeiten werde ich im späteren Verlauf des Buches gesondert eingehen, da der Umfang dieser Anwendung wirklich sehr groß ist. An dieser Stelle möchte ich mich auf eine Funktion beschränken, nämlich auf die Installation.

Innerhalb der Magento-Konsolenanwendung können Sie mit dem Parameter setup:install Magento installieren. Der reine Befehl reicht an dieser Stelle jedoch nicht aus, da Sie weitere Parameter benötigen, um die Installation zu konkretisieren. Dazu zählen unter anderem Datenbankverbindungsdaten, aber auch der Magento-Backend-Benutzer. Mit folgendem Befehl, der die Magento-Konsolenanwendung aufruft und darin den Installationsprozess anstößt, können Sie Magento gänzlich ohne Weboberfläche installieren:

php bin/magento setup:install --base-url=http://127.0.0.1/magento_terminal/ --db-host=localhost --db-name=magento_terminal --db-user=root --db-password= --admin-firstname=Alexander --admin-lastname=Steireif --admin-email= info@alexander-steireif.com --admin-user=asteireif --admin-password=admin12345 --language=de_DE --currency=EUR --timezone=Europe/Berlin --use-rewrites=1

Aller Voraussicht nach müssen Sie die Parameter auf Ihre Bedürfnisse anpassen, aus diesem Grund möchte ich Ihnen diese im Folgenden im Detail erklären:

  • base-url: die URL, unter der Sie Ihre Magento-Instanz aufrufen. Beachten Sie hierfür den htdocs-Unterordner, den Sie gewählt haben.
  • db-host: Domain bzw. IP Ihres Datenbankservers. In unserem Fall ist localhost korrekt.
  • db-name: der Name der Datenbank, die Sie für diese neue Magento-Instanz angelegt haben
  • db-user: im Fall vom XAMPP root
  • db-password: kann im Fall von XAMPP freigelassen werden
  • admin-firstname: Ihr Vorname
  • admin-lastname: Ihr Nachname
  • admin-user: Benutzername Ihres Benutzers
  • admin-password: Ihr gewünschtes Passwort
  • language: die für Ihre Magento-Installation gewünschte Sprache
  • currency: die Währung für Ihren Online-Shop
  • timezone: die Zeitzone, die Sie verwenden möchten
  • use-rewrites: ob Sie suchmaschinenfreundliche URLs verwenden möchten, was ich Ihnen empfehle
Überblick über alle Installationsparameter

Einen detaillierten und übersichtlichen Überblick über alle vorhandenen Installationsparameter erhalten Sie unter http://devdocs.magento.com/guides/v2.0/install-gde/install/cli/install-cli-install.html. Diese Seite empfehle ich Ihnen zusätzlich als Nachschlagewerk, auch wenn Sie bei den möglichen Werten für die Parameter unsicher sind. Magento hat sich speziell auf dieser Seite viel Mühe gegeben, alle möglichen offenen Fragen zu klären und Ihnen als Benutzer einen einfachen Einstieg zu ermöglichen.

Sobald Sie den Befehl in der Eingabeaufforderung, im Terminal bzw. der Shell ausgeführt haben, werden Sie eine Erfolgsmeldung erhalten, wie in Abbildung 3.23 zu sehen ist. An dieser Stelle ist speziell die Admin-URL sehr wichtig. Wie Sie vielleicht erkennen können, ist diese nicht in den Installationsparametern enthalten. Da Magento bei jeder Installation eine neue und individuelle Admin-URL erzeugt, wird diese zum Ende der Installation angezeigt. Notieren Sie sich diese, damit Sie später keine Probleme beim Zugriff auf das Backend haben.

Nachdem die Installation erfolgreich abgeschlossen wurde, müssen Sie auch in diesem Fall die nachgelagerten Aufgaben erledigen, damit Sie ohne Probleme und Einschränkungen Magento benutzen können. Werfen Sie hierfür bitte einen Blick in Abschnitt 3.2.1, »XAMPP für Windows«, und beachten Sie die Anmerkungen, die nach dem Installationsprozess aufgeführt werden. An dieser Stelle müssen noch die Verzeichnisberechtigungen vergeben und die statischen Dateien erzeugt werden.

Abbildung 3.23    Erfolgsmeldung bei der Magento-Installation via Terminal

Sobald Sie sich um diese beiden Aufgaben gekümmert haben, können Sie die soeben installierte Magento-Instanz problemlos nutzen.

Glückwunsch, Sie haben neben der Installation per Weboberfläche Magento nun auch über das Terminal installiert. Falls Sie beide Installationsprozesse durchlaufen haben, wird Ihnen aufgefallen sein, dass die Installation per Terminal wesentlich schneller und einfacher ist. Sie müssen zwar etwas Vorarbeit leisten, indem Sie sich mit den verschiedenen Installationsparametern vertraut machen, wenn Sie diese aber kennen, können Sie Magento wesentlich schneller und einfacher installieren. Die Installation per Terminal lohnt sich vor allem dann, wenn Sie täglich mehrere Magento-Instanzen aufsetzen und Zeit sparen möchten. Daher werden speziell Entwickler, die doch ab und an Test- und Entwicklungssysteme aufsetzen müssen, mit dieser Art der Installation sehr glücklich sein.

3.3.4    Composer

Mit der Installation mittels Composer steht Ihnen eine weitere und alternative Installationsmöglichkeit zur Verfügung. Bei Composer handelt es sich um einen sogenannten Dependency Manager, d. h. um eine Applikation, die in der Lage ist, Abhängigkeiten innerhalb einer Software aufzulösen und entsprechend benötigte Komponenten herunterzuladen bzw. zu installieren. Da Webanwendungen wie auch in diesem Fall Magento 2 immer größer und komplexer werden, hat man sich in den letzten Jahren Gedanken über die Verteilung bzw. Auslieferung solcher komplexen und großen Webanwendungen gemacht. Um nicht immer Hunderte Megabyte große Zip-Archive durch die Gegend schicken zu müssen, haben sich Lösungen wie Composer ergeben. Mittels einer Datei kann man Abhängigkeiten und Relationen zu Komponenten definieren, und basierend auf dieser Datei löst Composer diese auf. Zugegebenermaßen handelt es sich hierbei um eine Lösung, die primär im Bereich der Entwicklung eingesetzt wird und Akzeptanz findet. Aus diesem Grund können Sie, wie in Abschnitt 3.2.1, »XAMPP für Windows«, beschrieben, Magento auch weiterhin als großes Zip-Archiv herunterladen und installieren. Aus Gründen der Vollständigkeit möchte ich Ihnen an dieser Stelle jedoch auch einen Einblick geben, wie die Installation mittels Composer abläuft.

Grundvoraussetzung für die Nutzung ist die Installation von Composer. Das Installationspaket können Sie sich vollkommen kostenlos und ohne jegliche Einschränkung direkt auf der offiziellen Website unter https://getcomposer.org/ herunterladen. Das Betriebssystem spielt auch bei Composer eine untergeordnete Rolle, denn Composer ist für Windows, Linux sowie macOS verfügbar. Sobald Sie Composer installiert haben, steht Ihnen das Tool über die Kommandozeile zur Verfügung, und Sie haben jetzt die Möglichkeit, Magento mittels Composer zu installieren.

Weitere Informationen zu Composer

Verzeihen Sie mir an dieser Stelle die schnelle Abhandlung von Composer. Da diese Installationsvariante für voraussichtlich die Minderheit der Leser dieses Buches relevant ist, möchte ich diesen Teil so kurz wie möglich, aber so ausführlich wie nötig halten. Wenn Sie sich für Composer interessieren, Probleme mit der Installation oder sonstige Fragen haben, kann ich Ihnen die offizielle Website unter https://getcomposer.org empfehlen. Zusätzlich finden Sie in Google eine Menge nützlicher Infos zu Composer, da aufgrund der sehr hohen Verbreitung von Composer mittlerweile sehr viele Blogeinträge, Artikel und Informationsquellen verfügbar sind.

Wechseln Sie nun in die Eingabeaufforderung, das Terminal bzw. die Shell, und navigieren Sie zu Ihrem htdocs-Verzeichnis. Sobald Sie in diesem Verzeichnis angekommen sind, führen Sie folgenden Befehl aus:

composer create-project magento/community-edition magento_composer -s dev  
--prefer-dist

Daraufhin fängt Composer an, die aktuellste Version der Magento Community Edition bzw. Magento Open Source herunterzuladen und vorhandene Abhängigkeiten aufzulösen, sprich Ihnen den gesamten Umfang der für die Installation benötigten Dateien bereitzustellen. Sie müssen an dieser Stelle nichts weiter tun, als zu warten, bis der Download abgeschlossen ist. Die Nutzung von Composer hat grundsätzlich viele Vorteile, die auch komplett unabhängig von Magento zu betrachten sind. Letztendlich hilft Ihnen Composer auch dabei, Teilkomponenten einfach zu aktualisieren und Ihr System bzw. die darin verwendeten Komponenten aktuell zu halten. In diesem konkreten Beispiel sehen Sie jedoch auch, dass Composer für die initiale Installation von Magento praktisch ist, da Sie Zeit sparen. Sie müssen sich nicht durch die Magento-Website klicken, das Zip-Archiv mit knapp 100 MB herunterladen und lokal entpacken. Letztendlich können Sie mithilfe eines Konsolenbefehls den Download der benötigten Dateien starten und damit die Installation von Magento vorbereiten (siehe Abbildung 3.24).

Nachdem Composer seine Aufgabe erledigt hat, steht Ihnen im Verzeichnis magento_composer, sollten Sie meiner Namensgebung gefolgt sein, ein aktuelles Magento-Installationsarchiv zur Verfügung. Da Composer sich ausschließlich um den Download und die Aktualisierung von Komponenten kümmert, müssen Sie im nächsten Schritt noch die Magento-Installation durchführen. Diese können Sie mittels Weboberfläche, aber auch via Terminal starten und durchführen. Werfen Sie hierfür bitte einen Blick in Abschnitt 3.2.1, »XAMPP für Windows«, und Abschnitt 3.2.2, »XAMPP für Linux-Systeme«. In diesen Abschnitten ist der Installationsprozess, also die Tätigkeit, die nach der Bereitstellung des Magento-Installationsarchivs folgt, im Detail beschrieben. Änderungen und Besonderheiten aufgrund der Nutzung von Composer existieren nicht, für den Magento-Installationsprozess ist es letztendlich irrelevant, ob die benötigten Dateien als Zip-Archiv heruntergeladen oder mittels Composer bereitgestellt wurden.

3.3.5    Magerun

Die mit Abstand schnellste, unkomplizierteste, aber auch »nerdigste« Art der Magento-Installation erzielen Sie mit Magerun. Bei Magerun handelt es sich um ein Community-Projekt meines geschätzten Kollegen Christian Münch, der bereits zu Zeiten von Magento 1 begonnen hat, mit Magerun eine Konsolenanwendung für Magento bereitzustellen, die Anwender und speziell Entwickler im Alltag unterstützt. Diese Konsolenanwendung hat das Ziel, möglichst schnell und einfach Konfigurationseinstellungen von Magento zu ändern, aber auch Aktionen durchzuführen. Dadurch sparen Sie sich die oftmals zeitintensive und umständliche Nutzung der Benutzeroberfläche. Über die Konsole können Sie innerhalb weniger Sekunden eine Vielzahl von Befehlen abfeuern und kommen somit schneller ans Ziel. Wohlgemerkt handelt es sich bei der Zielgruppe, die auf Magerun schwört, vorwiegend um Entwickler und Profinutzer. Da es sich bei Magerun definitiv um ein interessantes und empfehlenswertes Werkzeug handelt (Magerun selbst bezeichnet sich als Swiss Army Knife), möchte ich in Kapitel 19 im Detail auf Magerun eingehen. An dieser Stelle beschränke ich mich ausschließlich auf die Installation von Magento mittels Magerun. Wenn es Sie aber jetzt schon in den Fingern juckt, können Sie selbstverständlich schon einen Abstecher auf die Magerun-Seite machen und sich das Tool im Detail anschauen. Die offizielle Magerun-Website finden Sie unter http://magerun.net samt vieler interessanter Informationen, Videos und eines Wikis.

Probleme von Magerun unter Windows

Speziell bei der Installation von Magerun hatte ich unter Windows einige Probleme, weswegen ich an dieser Stelle bei der Erklärung von Magerun zu Linux wechsle. Möglicherweise sind die Probleme während der Arbeit an diesem Buch behoben, weswegen Sie Magerun auch unter Windows einsetzen können. Da mir das zum jetzigen Zeitpunkt jedoch nicht möglich ist, sehen Sie mir nach, dass ich an dieser Stelle temporär aus der Windows-Welt ausbreche.

Bevor ich mit der Installation von Magento starte, installiere ich auf meinem Linux-Betriebssystem zuallererst Composer. Sofern Sie die Möglichkeit haben, mittels apt-get Software zu installieren, wie das beispielsweise unter Debian und Ubuntu der Fall ist, können Sie Composer relativ einfach mit folgendem Befehl über die Shell installieren: sudo apt-get install composer. Sollten Sie auf Ihrem System nicht die Möglichkeit haben, Composer über den beschriebenen Weg zu installieren, erhalten Sie unter https://getcomposer.org/ weiterführende Informationen, wie Sie Composer auf Ihrem System einrichten können.

Nachdem Composer auf dem System bereitsteht, gilt es im nächsten Schritt, Magerun herunterzuladen. Hierfür stehen zwei Varianten zur Verfügung. Sie haben die Wahl zwischen wget und curl, je nach Möglichkeit und persönlicher Präferenz.

Installation mithilfe von wget:

wget https://files.magerun.net/n98-magerun2.phar 
chmod +x ./n98-magerun2.phar

Installation mithilfe von curl:

curl -sS -O https://files.magerun.net/n98-magerun2.phar 
chmod +x ./n98-magerun2.phar

Nachdem Sie Magerun heruntergeladen haben, erstellen Sie ein neues Unterverzeichnis innerhalb Ihres htdocs-Ordners, dessen Namen Sie frei wählen können. Ich wähle in diesem konkreten Beispiel den Namen magento_magerun. Verschieben Sie in dieses Verzeichnis die soeben heruntergeladene Datei n98-magerun2.phar. Sobald Sie diesen Schritt erledigt haben, sind alle Installationsvoraussetzungen erfüllt, und Sie können mit der Installation von Magento 2 mithilfe von Magerun beginnen.

Starten Sie jetzt die Shell bzw. das Terminal, und navigieren Sie zu Ihrem soeben angelegten Verzeichnisses innerhalb des Ordners htdocs. Innerhalb dieses Verzeichnisses können Sie nun den Konsolenbefehl ./n98-magerun2.phar eingeben. Dadurch starten Sie Magerun und erhalten daraufhin eine Auflistung der Möglichkeiten und Funktionen, wie Sie in Abbildung 3.25 sehen können.

Abbildung 3.25    Magerun bietet einen Strauß an Funktionen, um noch besser mit Magento arbeiten zu können.

Nun können Sie mit der Installation von Magento beginnen. Hierzu müssen Sie im ersten Schritt etwas Vorarbeit leisten, denn Sie benötigen den Private und den Public Key Ihres Benutzerkontos von magento.com. Öffnen Sie den Browser Ihrer Wahl, und gehen Sie auf die offizielle Website von Magento, indem Sie die URL http://www.magento.com aufrufen. Klicken Sie im oberen Bereich der Seite auf My Account, und melden Sie sich mit Ihren Zugangsdaten an. Sollten Sie zu diesem Zeitpunkt noch nicht über ein Benutzerkonto verfügen, legen Sie sich ein neues Benutzerkonto an. Dieses werden Sie, unabhängig von der Nutzung von Magerun, zukünftig definitiv benötigen, um auf die gesamten Angebote der Magento-Plattform zugreifen zu können. Im Benutzerkonto angekommen, klicken Sie auf den Reiter Connect und innerhalb dieser Ansicht auf den Menüpunkt Secure Keys, den Sie auf der linken Seite finden. Alternativ hierzu können Sie direkt die URL https://www.magentocommerce.com/magento-connect/customerdata/accessKeys/list/ aufrufen. Geben Sie innerhalb dieser Ansicht einen beliebigen Namen ein, z. B. Magento, und klicken Sie auf Generate New. Daraufhin werden ein Public und ein Private Key für Sie generiert. Erstellen Sie nun eine neue Datei namens auth.json, und speichern Sie diese in dem Composer-Verzeichnis ab. In meinem konkreten Fall befindet sich dieses unter /home/benutzername/.composer, je nach Betriebssystem bzw. Linux-Distribution kann sich der Pfad jedoch unterscheiden. Die Datei auth.json muss dabei wie folgt aufgebaut sein und folgenden Inhalt haben:

{
    "http-basic": {
        "repo.magento.com": {
            "username": "publickey",
            "password": "privatekey"
        }
    }
}

Tragen Sie beim Username bitte Ihren Public Key ein, beim Passwort hinterlegen Sie Ihren Private Key. Speichern Sie nun die Datei unter dem besagten Namen auth.json ab. Durch diese Datei erhält Magerun letztendlich die Möglichkeit, die jeweiligen Magento-Installationspakete herunterzuladen, was für die Installation von Magento unerlässlich ist.

Wechseln Sie nun wieder in die Shell bzw. das Terminal, und rufen Sie in dem von Ihnen in den vorherigen Schritten angelegten Verzeichnis folgenden Konsolenbefehl auf, um den Installationsprozess von Magento mittels Magerun zu starten:

./n98-magerun2.phar install

Nachdem Sie diesen Befehl eingegeben haben, startet Magerun die Installationsroutine. Sie werden zuerst gefragt, welche Version von Magento Sie installieren möchten. Das ist ein ziemlich geniales Feature, da Sie mit Magerun nicht zwangsläufig die neuste und aktuellste Version von Magento installieren müssen, sondern die Auswahl zwischen allen Magento 2-Versionen haben. Ich gehe an dieser Stelle davon aus, dass Sie genau wie ich die aktuellste Version installieren möchten. Geben Sie daher die 1 ein, und drücken Sie (¢). Magerun fragt Sie anschließend, in welchem Verzeichnis Sie Magento installieren möchten. Den Verzeichnisnamen können Sie frei wählen, ich verwende in diesem Beispiel den Namen magento21, da ich die aktuellste Version von Magento installieren möchte und das aus diesem Grund eine für mich logische Benennung ist. Wie Sie das Verzeichnis jedoch nennen, bleibt Ihnen überlassen. Nachdem Sie das Verzeichnis angegeben haben, werden Sie nach dem Host der Datenbank gefragt. Geben Sie localhost ein, und bestätigen Sie die Eingabe mittels (¢). Beim Port der Datenbank, das ist die nächste Abfrage, können Sie den Standardwert 3306 eingeben bzw. einfach (¢) drücken. Wenn Sie keine Eingabe tätigen, wird immer der dargestellte Standardwert verwendet. Daraufhin werden Sie nach den Datenbankverbindungsdaten gefragt, wofür Sie den Benutzernamen des MySQL-Benutzers und dessen Passwort sowie eine Datenbank hinterlegen müssen. Beim Benutzernamen verwenden Sie root. Wenn Sie auf XAMPP setzen, können Sie das Passwort freilassen, verwenden Sie MAMP, geben Sie beim Passwort root ein. Was die Datenbank betrifft, so müssen Sie diese im Vorfeld über phpMyAdmin anlegen und den entsprechend gewählten Datenbanknamen an dieser Stelle eingeben.

Abschließend müssen Sie noch die Base-URL, also die Adresse, unter der die Magento-Installation erreichbar ist, eingeben. Wenn Sie, wie von mir erwähnt, ein Unterverzeichnis magento_magerun angelegt haben und die Magento-Installation im Verzeichnis magento21 ausführen möchten, dann lautet die korrekte Base-URL http://127.0.0.1/magento_magerun/magento21. Passen Sie die Base-URL daher basierend auf Ihren Eingaben in Magerun und der Verzeichnisstruktur Ihres htdocs-Ordner entsprechend an.

Zu guter Letzt können Sie in Magerun noch entscheiden, ob Sie Demo-Daten installieren möchten, die Auswahl überlasse ich Ihnen. Nachdem Sie sich für bzw. gegen die Demo-Daten entschieden haben, stößt Magerun den Aufbau der Indizes an und Magento ist erfolgreich installiert. Sie erhalten eine Meldung, wie Sie sie auch in Abbildung 3.26 sehen können.

Abbildung 3.26    Magerun meldet die erfolgreiche Installation der Magento-Instanz.

Wie eingangs erwähnt, bietet Magerun wesentlich mehr Möglichleiten als die reine Installation von Magento, weswegen ich Ihnen dieses Tool in Kapitel 19 noch im Detail vorstellen werde. Wie Sie auf den vorherigen Seiten gesehen haben, können Sie auch mit den Magento-Hausmitteln eine Installation über die Eingabeaufforderung bzw. die Shell oder das Terminal durchführen. Magerun ergänzt den Funktionsumfang aber ein Stück weit, da auch der komplette Download der frei wählbaren Magento-Version über Magerun abgedeckt wird. Sie müssen sich also nicht einmal Magento herunterladen, Magerun kümmert sich auch um diesen Part. Auch Magerun eignet sich vor allem für Entwickler, die schnell und häufig Magento-Installationen aufsetzen und hierbei Zeit sparen möchten. Lassen Sie sich aber noch von den weiteren Funktionen und Möglichkeiten dieses Tools überraschen!
