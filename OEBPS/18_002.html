18.2    Magento-Update durchführen

Auf Basis der vorgestellten Quellen haben Sie sich über ein veröffentlichtes Magento-Update informiert und möchten dieses im nächsten Schritt einspielen. Bitte melden Sie sich hierfür erneut am Magento-Backend an, vorausgesetzt, Sie befinden sich nicht bereits im Administrationsbereich. Klicken Sie in der linken Navigationsleiste auf System und anschließend auf Web Setup Wizard. Daraufhin gelangen Sie zu einer Applikation, die ähnlich wie das klassische Magento-Backend aussieht, sich jedoch von den Menüpunkten stark unterscheidet. Der Web Setup Wizard ist in etwa der Nachfolger des aus Magento 1 bekannten Connect Managers. Auch in Magento 1 gab es eine »eigenständige« Applikation, die ausschließlich die Funktion hatte, Updates einzuspielen und Extensions zu installieren. Ähnlich verhält es sich mit dem Web Setup Wizard, den Sie übrigens direkt unter /setup/, in meinem Fall http://www.foodbaer.de/setup/, aufrufen können.

Innerhalb des Web Setup Wizards klicken Sie bitte in der linken Navigationsleiste, wie in Abbildung 18.3 zu sehen, auf den Eintrag System Upgrade.

Abbildung 18.3    Mithilfe des Web Setup Wizards können Sie Komponenten installieren sowie das System aktualisieren.

Anschließend werden Sie nach Ihren Magento Marketplace Public Key und Private Key gefragt. Diese Informationen setzen einen Account im Magento Marketplace voraus, den Sie kostenfrei unter https://account.magento.com/applications/customer/create/ anlegen können. Sollten Sie an dieser Stelle noch nicht über einen Account verfügen, legen Sie im ersten Schritt einen solchen Account für sich an. Letztendlich müssen Sie nur ein paar wenige Informationen hinterlegen und erhalten anschließend Zugang zum Magento Marketplace bzw. den Magento-Services.

Wenn Sie bereits über einen Account verfügen, öffnen Sie die URL https://account.magento.com/applications/customer/login, und melden Sie sich mit Ihren Zugangsdaten am System an. Nach dem erfolgreichen Login gelangen Sie zur Übersichtsseite (siehe Abbildung 18.4). Klicken Sie auf dieser Übersichtsseite bitte auf den Link My Access Keys.

Abbildung 18.4    Mithilfe eines kostenfreien Magento-Accounts können Sie auf die unterschiedlichsten Services zugreifen.

Innerhalb der jetzt geöffneten Ansicht haben Sie die Möglichkeit, zwischen zwei Tabs zu springen. Es gibt einen Magento 1 Tab sowie einen Magento 2 Tab. Klicken Sie auf den Magento 2 Tab, wodurch sich der Inhaltsbereich etwas weiter unten ändert. Sollten Sie bereits über Access Keys verfügen, erhalten Sie an dieser Stelle die Auflistung dieser Keys. Wenn Sie hingegen noch keine Access Keys besitzen, klicken Sie auf Create A New Access Key. Notieren Sie sich den Public Key sowie den Private Key, und wechseln Sie zurück in den Web Setup Wizard. Dort angelangt, hinterlegen Sie bitte beide Werte, und klicken Sie auf Submit.

Vorausgesetzt, die beiden Werte wurden korrekt hinterlegt, werden Sie anschließend zur ersten Maske innerhalb des Update-Prozesses geleitet. Bei dem ersten Dropdown-Menü mit dem Titel Magento Core Components können Sie die Magento-Version wählen, auf die Sie aktualisieren möchten. Grundsätzlich müssen Sie nicht auf die aktuellste Magento-Version updaten, sondern können das Update auch in kleineren Schritten durchspielen. In diesem Szenario verfüge ich beispielsweise über eine installierte Version 2.1.0 von Magento Open Source (ehemals Community Edition) und kann auf die Version 2.1.3 aktualisieren, weswegen ich an dieser Stelle die Version 2.1.3 auswähle.

Mit der Option Other Components zielt Magento auf weitere installierte Komponenten ab, die ebenfalls aktualisiert werden können. Hierzu zählen beispielsweise Module und Erweiterungen. Ich belasse die Auswahl bei No, da ich aktuell nur mein Magento-Basissystem aktualisieren möchte, und klicke auf Next.

Wie auch bei der Installation steht jetzt der Readiness-Check an, das heißt, Magento prüft, ob der Server und die Konfiguration die Mindestvoraussetzungen für Magento erfüllen. An dieser Stelle müssen Sie zwangsläufig auf Start Readiness Check klicken, wodurch Sie ein Ergebnis wie in Abbildung 18.5 erhalten sollten.

Abbildung 18.5    Aktuell erfüllt das System nicht die Mindestvoraussetzungen von Magento.

Wie Sie sehen, erhalte ich relativ viele Fehlermeldungen, weshalb ich das Update nicht durchführen kann. Ebenso wie ich sollten auch Sie Fehlermeldungen erhalten, und vermutlich wundern Sie sich an dieser Stelle, da die Installation von Magento kein Problem war und während der Installation ebenfalls die Mindestanforderungen geprüft wurden. Der Unterschied liegt darin, dass Magento vor einem Update zudem prüft, ob der CronJob korrekt eingerichtet ist. Bei mir war dies nicht der Fall, bislang ist dies nicht aufgefallen, da ein System bedingt auch ohne eingerichteten CronJob funktioniert.

An dieser Stelle, es hängt nun ganz stark von Ihrem Webhoster und den bereitgestellten Oberflächen und Zugriffen ab, müssen Sie das Setup des Magento-CronJobs prüfen bzw. diesen initial anlegen. Detaillierte Informationen hierzu finden Sie direkt bei Magento unter http://devdocs.magento.com/guides/v2.0/config-guide/cli/config-cli-subcommands-cron.html, im Zweifelsfall ist sicherlich auch der Support Ihres Webhosters immer bereit, weiterzuhelfen und für Sie die Anlage des CronJobs zu übernehmen. Beachten Sie an dieser Stelle, dass auf jeden Fall die folgenden drei CronJobs im System angelegt werden müssen:

*/1 * * * * /path/to/php /pfad/zu/magento/bin/magento cron:run [>> /log/file &]
*/1 * * * * /path/to/php /pfad/zu/magento/update/cron.php [>> /log/file &]
*/1 * * * * /path/to/php /pfad/zu/magento/bin/magento setup:cron:run [>> /log/file &

Magento 2 CronJob bei Hosteurope einrichten

Sollten Sie, genau wie ich, bei Hosteurope ein virtualisiertes System betreiben, kann ich Ihnen den folgenden Beitrag aus meinem Blog ans Herz legen: http://www.alexander-steireif.com/magento-2-cronjob-bei-hosteurope-einrichten/. In diesem Blogbeitrag beschreibe ich, wie Sie bei Hosteurope den CronJob für Magento 2 einrichten und welche Einstellungen Sie noch berücksichtigen müssen.

Sobald Sie diese Hürde genommen haben, können Sie eine erneute Prüfung des Systems anstoßen. Im nächsten Schritt werden Sie gefragt, ob vor dem Update eine Sicherung (Backup) erstellt werden soll und wenn ja, von welchen Bereichen im System. Magento untergliedert dabei nach Code, Media und Database. In der Datenbank stecken alle Informationen wie Kunden, Bestellungen und Produkte. Bei Media handelt es sich um die hochgeladenen Produktbilder und CMS-Grafiken, und der Code ist letztendlich die Basis des Magento-Systems, sprich die PHP-Dateien. Lassen Sie an dieser Stelle ruhig alle drei Checkboxen angehakt, und klicken Sie auf Create Backup.

Nachdem Sie das Backup erstellt haben, wobei dies natürlich keine Pflicht ist, können Sie im nächsten Schritt auf Weiter klicken und somit den Update-Vorgang einleiten. Daraufhin werden Sie zu einer Update-Ansicht, die in Abbildung 18.6 zu sehen ist, geführt, und es kann mit dem Update begonnen werden.

Abbildung 18.6    Während des Updates werden Sie auf dem aktuellen Stand gehalten.

Damit Benutzer, die gegebenenfalls auf Ihrem System aktiv sind, den Update-Prozess nicht beeinträchtigen, aktiviert Magento zuallererst den Wartungsmodus. Dadurch können Nutzer das Frontend nicht mehr bedienen, wodurch Komplikationen während des Updates vermieden werden. Nachdem das Update erfolgreich eingespielt wurde, bei Ihnen sollte das binnen weniger Minuten passieren, erhalten Sie zudem abschließend eine Erfolgsmeldung, und Magento ist erfolgreich aktualisiert. Weitere Schritte müssen Sie nicht unternehmen, auch der Cache wird beispielsweise von Magento automatisiert gelöscht. Sie haben somit erfolgreich die neuste Version von Magento eingespielt und das Update erfolgreich durchgeführt!
