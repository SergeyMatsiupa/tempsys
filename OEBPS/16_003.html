16.3    Erweitern Sie die Standardfunktionalitäten

Sofern es sich um sinnvolle Ergänzungen handelt, die von der Magento-Community bzw. Unternehmen bereitgestellt werden, bin ich der Letzte, der Ihnen diese Möglichkeiten vorenthalten möchte. Speziell bei den Import- und Export-Funktionen ist sicherlich Luft nach oben, was den Funktionsumfang betrifft. Denn auch wenn der Standard schon ganz passabel ist, ist Ihnen sicherlich aufgefallen, dass Sie alle Exporte und Importe manuell starten müssen. Das ist natürlich für einmalige Aktionen vollkommen in Ordnung, auf Dauer und bei wiederkehrenden Importen bzw. Exporten ist der fehlende Automatismus aber definitiv ein wenig störend. Aus diesem Grund möchte ich Ihnen an dieser Stelle eine, wie ich finde, sehr sinnvolle und nützliche Erweiterung vorstellen, die den Import- sowie Export-Funktionsumfang sinnvoll ergänzt.

Das Unternehmen Firebear Studio hat für Magento 2 eine sehr umfangreiche Import- bzw. Export-Extension entwickelt, die Sie unter https://firebearstudio.com/the-improved-import.html kaufen und herunterladen können. Zudem steht eine abgespeckte Variante dieser Extension zur Verfügung, die Sie kostenlos über GitHub beziehen können. Letztere Extension, sprich die kostenfreie, möchte ich Ihnen auf den folgenden Seiten näher vorstellen. Da die kostenpflichtige Erweiterung mit knapp 350 US$ nicht ganz günstig ist, ergibt es sicherlich Sinn, zuerst die frei verfügbare Version zu testen und anschließend, wenn Sie merken, dass der Funktionsumfang nicht ausreicht, auf die kostenpflichtige Variante zu wechseln.

16.3.1    Die Erweiterung »importexportfree« installieren

Um die Erweiterung zu installieren, rufen Sie bitte die URL https://github.com/firebearstudio/importexportfree auf, und klicken Sie anschließend in der oberen rechten Ecke auf den grünen Button Clone or Download. Es erscheint daraufhin ein kleines Fenster, in dem Sie auf den Link Download Zip klicken, woraufhin der Download startet. Nachdem der Download abgeschlossen ist, extrahieren Sie das Zip-Archiv, beispielsweise mithilfe von 7-Zip, wobei Sie an dieser Stelle jedes beliebige Zip-Programm verwenden können, um das Archiv zu extrahieren. Im nächsten Schritt müssen Sie innerhalb Ihrer Magento-Installation ein neues Verzeichnis anlegen. Erstellen Sie innerhalb des Ordners /app/code das Verzeichnis Firebear. Innerhalb des Verzeichnisses Firebear legen Sie das Verzeichnis ImportExport an, in das Sie den Inhalt des extrahierten Zip-Archivs kopieren. Haben Sie die Verzeichnisse erstellt und die Dateien kopiert, öffnen Sie bitte das Terminal bzw. die Shell, und navigieren Sie in das Magento-Hauptverzeichnis. Dort angekommen, führen Sie den folgenden Befehl aus:

php -f bin/magento module:enable Firebear_ImportExport

Nachdem Sie die Extension installiert haben, müssen Sie noch die folgenden Befehle in der Shell bzw. im Terminal ausführen:

php -f bin/magento setup:upgrade
php -f bin/magento setup:static-content:deploy
php -f bin/magento cache:clean

Haben Sie diese Schritte durchgeführt, ist die Extension erfolgreich installiert und kann genutzt werden. Melden Sie sich daher bitte nun mit Ihren persönlichen Zugangsdaten im Magento-Backend an.

16.3.2    Neue Funktionen durch importexportfree

Nachdem Sie sich im Magento-Backend angemeldet haben, klicken Sie auf System • Datentransfer • Importoptionen. Sie gelangen zum Dropdown-Menü, das Sie bereits kennen und das Ihnen die Auswahl des Datensatztyps erlaubt. Wenn Sie in diesem Dropdown-Menü den Eintrag Produkte auswählen, werden Sie eine Erweiterung der Eingabemaske feststellen. Wenn Sie nach unten scrollen, gelangen Sie zu einem neuen Menüpunkt namens Import Source. Hier können Sie nun auswählen, auf welche Art und Weise Sie den Produktimport bereitstellen möchten. Im Standard müssen Sie immer die CSV-Datei hochladen, um diese zu importieren. Dank der Extension haben Sie jedoch die Möglichkeit, die Importdatei per FTP, URL oder auch via Dropbox bereitzustellen. Je nachdem welche der Optionen Sie auswählen, die Sie in Abbildung 16.10 sehen, müssen Sie unterschiedlichste Informationen angeben.

Wählen Sie beispielsweise den Eintrag FTP, so müssen Sie einen File Path, also den Pfad zur Datei, angeben. Wenn Sie sich an dieser Stelle fragen, wo Sie die eigentlichen FTP-Zugangsdaten hinterlegen können, so muss ich Sie an dieser Stelle auf die Systemkonfiguration verweisen. Der Import der Datei aus einer externen Quelle ist fürs Erste schon ein recht interessantes Feature. Wenn Sie weitere Möglichkeiten beim Import bzw. Export benötigen, sollten Sie sich zudem die kostenpflichtige Version dieser Extension anschauen. Denn diese enthält nochmals wesentlich mehr Funktionen, die meiner Meinung nach äußerst nützlich sind.

16.3.3    Funktionen der kostenpflichtigen Version

Die kostenpflichtige Version ermöglicht, und das finde ich persönlich besonders interessant, den Import von Kategorien. Wie bereits einige Seiten zuvor kurz erwähnt, haben Sie im Standard keine Möglichkeit, Kategorien per Import ins System zu laden. Dieser Datensatztyp steht weder beim Export noch beim Import bereit, wodurch Sie bei Massenbearbeitungen von Kategorien die Änderungen und Anpassungen tatsächlich mithilfe des Magento-Backends vornehmen müssen. Das geht zwar ohne Einschränkung, ist aber in der Praxis recht mühevoll. Aus diesem Grund wünschen sich viele Shop-Betreiber und Magento-Nutzer ein Export- bzw. Importmöglichkeit für Kategorien. In der kostenpflichtigen Variante ist diese Möglichkeit enthalten und ergänzt letztendlich die vorhandenen Datensatztypen, wie Sie in Abbildung 16.11 sehen.

Abbildung 16.11    Die Extension ergänzt einen neuen Datensatztyp namens »Categories«, der den Import von Kategorien ermöglicht.

Abgesehen von dem Kategorie-Import, steht zudem eine Erweiterung des Produktdatenimports zur Verfügung. Wenn Sie im Magento-Standard Produkte importieren, die Attributwerte besitzen, die im System nicht vorhanden sind, so müssen Sie diese Werte zuerst über das Magento-Backend anlegen. Mithilfe dieser Extension ersparen Sie sich aber diesen Schritt. Würden Sie also ein Produkt importieren, das beispielsweise bei der Farbe den Wert »schwarz« enthält, die Farbe Schwarz wäre im System jedoch noch gar nicht angelegt, würde der Import dies on the fly während des Importvorgangs tun. Gleiches beherrscht die Extension übrigens grundsätzlich bei allen nicht im System existenten Attributen. Wenn Sie eine Importdatei übermitteln, die nicht vorhandene Attribute beinhaltet, so würden diese Attribute on the fly während des Importvorgangs erstellt werden. Auch dies ist im Magento-Standard nicht möglich. Im Standard würde Magento diese Attribute einfach ignorieren, und Sie müssten diese manuell über das Backend anlegen.

Neben dem erweiterten Umgang mit Attributen und Attributwerten können Sie zudem herunterladbare Produkte samt allen relevanten Informationen importieren, was im Standard ebenfalls nicht möglich ist. Einen Import können Sie übrigens, wenn Sie auf diese Erweiterung setzen, auch direkt mittels Konsole bzw. Terminal starten. Hierfür steht die CLI-Komponente zur Verfügung, welche die Steuerung der Jobs erlaubt.

php -f bin/magento import:job:COMMAND JOB_ID
import:job:disable                        Disable Firebear Import Jobs
import:job:enable                         Enable Firebear Import Jobs
import:job:run                            Generate Firebear Import Jobs

Listing 16.5    Sie können den Import auch direkt über die Kommandozeile starten.

Die Nutzung der Kommandozeile beim Import hat verschiedene Vorteile. Zum einen können Sie wesentlich schneller agieren, da Sie sich nicht durch das Backend klicken müssen. Zum anderen umgehen Sie in der Regel, dies gilt speziell bei größeren Importen bzw. Exporten, mögliche Timeouts und Limitierungen. Diese sind oftmals deaktiviert, wenn Sie PHP direkt via Kommandozeile nutzen, wobei dies durch die Konfiguration des Servers und die durch den Webhoster bereitgestellte Konfiguration bestimmt wird.

Wie Sie anhand der Kommandos gegebenenfalls erkennen können, arbeitet die Extension mit sogenannten Jobs. Das heißt, Sie haben die Möglichkeit, zeitlich definierte Importe anzulegen, die anschließend automatisiert ausgeführt werden. Dies ist besonders praktisch, wenn Sie immer zu einem bestimmten Zeitpunkt vollkommen automatisch Produktdaten importieren möchten. Mit den Hausmitteln, das haben Sie ja bereits kennengelernt, können Sie keine automatischen Importe abbilden. Diese Extension hingegen erlaubt Ihnen den zeitlich terminierten Import und sorgt für eine höchstmöglichste Automatisierung.

Zum Schluss haben Sie zudem noch die Möglichkeit ein Field-Mapping durchzuführen. Das heißt, Sie können definieren, welches Attribut mit welchem Namen exportiert bzw. importiert wird. Dies ist immer dann praktisch, wenn eine andere Anwendung Produktdaten bereitstellt und Sie keinen Einfluss auf die Benennung der Spalten haben. In diesem Fall würde Magento im Standard natürlich ein Zuordnungsproblem haben, wenn z. B. die SKU mit Artikelnummer bezeichnet wird. Aus diesem Grund müssen Sie ein Mapping durchführen und Magento mitteilen, welches Feld die SKU enthält. Wie Sie in Abbildung 16.12 sehen, ist exakt diese Funktionalität in der Extension enthalten. Somit können Sie so gut wie jede bereitgestellte Datei beim Import verwenden und haben an dieser Stelle eine enorme Flexibilität.

Zusammengefasst lässt sich getrost sagen, dass die erwähnte Extension den Magento-Funktionsumfang nochmals signifikant erweitert und Ihnen speziell bei der Verarbeitung von Kategorien und Produkten stark unter die Arme greift.
