15.7    Dashboards anlegen, einsehen und verwalten

Nachdem Sie nun gesehen haben, wie Sie in Magento BI Metriken und Filter erstellen sowie Datenquellen anbinden, möchte ich Ihnen natürlich auch den Umgang mit den Berichten bzw. Dashboards im Detail zeigen. Grundsätzlich müssen Sie, um einen Bericht einzusehen, ein Dashboard anlegen und diesen Bericht einem Dashboard zuweisen. Die reine Anlage eines Berichts reicht also nicht aus, um diesen einzusehen. Sie benötigen in jedem Fall immer ein Dashboard, das diesen Bericht einbindet. Klicken Sie nun in der Hauptnavigation auf den Link Dashboard, um zu den Dashboards zu gelangen.

Sobald die Seite geladen ist, werden Sie eine Vielzahl von Charts, Tabellen und Kennzahlen sehen. Das sogenannte Executive Overview Dashboard, in dem Sie sich aktuell befinden, hat von Haus aus bereits Berichte zugewiesen bekommen, weswegen Sie, ähnlich wie in Abbildung 15.16, die verschiedensten Elemente sehen sollten. Da es sich um eine Vielzahl von dem Dashboard zugewiesenen Berichten handelt, sehen diese zum Teil sehr unterschiedlich aus. Der Bericht, der Ihnen auf den ersten Blick auffallen sollte, befindet sich direkt in der oberen linken Ecke und trägt den Namen »Test«. Hierbei handelt es sich exakt um den Bericht, den Sie einige Seiten zuvor erstellt und dem Executive Overview Dashboard zugewiesen haben.

Abbildung 15.16    Ein Dashboard gruppiert immer eine beliebige Anzahl von Berichten.

Sie sehen an dieser Stelle, wenn auch etwas gestaucht, exakt die Visualisierung, die Sie bereits bei der Erstellung des Berichts als Vorschau gesehen haben. Dazu gehören z. B. auch die Umsatzzahlen der letzten 30 Tage, die Bestellungen pro Monat sowie der Umsatzverlauf pro Tag. Scrollen Sie an dieser Stelle gern ein wenig nach unten, denn Sie werden auf dieser Seite noch weitaus mehr Berichte vorfinden. Am unteren Ende der Seite haben Sie zudem ein paar Beispiele für die Einbindung von Tabellen sowie nackten Kennzahlen.

Bei der Anordnung der Berichte haben Sie eine größtmögliche Flexibilität. Möchten Sie beispielsweise den Bericht »Test« verschieben, können Sie einfach per Drag & Drop, d. h. durch Ziehen mit dem Mauszeiger, den Bericht an eine andere Stelle verschieben. Auch können Sie die Größe eines jeden Berichts durch simples Ziehen verändern. Sie können nun gern ein wenig mit der Platzierung der Berichte spielen und das Dashboard an Ihre Bedürfnisse anpassen. Bei Magento BI gilt wie im gesamten Magento-Kosmos: Probieren geht über Studieren!

Sobald Sie mit dem Mauszeiger über einen Bericht fahren, erscheint ein unscheinbares Zahnrad-Icon, auf das Sie bitte klicken. Welchen Bericht Sie auswählen, spielt dabei keine Rolle, Sie können aber gern auf den von Ihnen erstellten Bericht »Test« zurückgreifen. Sobald Sie auf das Zahnrad-Icon geklickt haben, öffnet sich ein weiteres Menü mit verschiedensten Optionen. Klicken Sie auf den ersten Link namens Edit, springen Sie direkt in die Bearbeitungsmaske des Berichts, die Sie bereits kennen. Sie erlaubt Ihnen die Anpassung des Berichts, beispielsweise durch das Hinzufügen von Metriken, Formeln oder durch Eingrenzung der Ergebnismenge auf Basis von Filtern. Klicken Sie auf Enlarge, wird der Bericht bildschirmfüllend dargestellt. Speziell für etwas komplexere und umfangreichere Berichte kann diese Option recht nützlich sein. Bei einem vergrößerten Bericht befindet sich in der oberen rechten Ecke zudem ein Icon, mit dem Sie den Bericht wieder auf die Normalgröße zurückbringen können. Möchten Sie einen Bericht in ein anderes Dashboard verfrachten, so können Sie dies an dieser Stelle mittels des Links save as tun. Es öffnet sich daraufhin ein Overlay, in dem Sie einen Namen und ein Ziel-Dashboard hinterlegen können. Ebenfalls können Sie einen Bericht, der im Dashboard inkludiert ist, exportieren. Magento BI bietet hierfür die Dateiformate CSV und XLSX, sprich Microsoft Excel, an. Wenn Sie beispielsweise den Test-Bericht als Excel-Datei exportieren und in Microsoft Excel öffnen, erhalten Sie die im Bericht enthaltenen Zahlen, jedoch nicht die Visualisierung. Diese könnten Sie dann aber direkt in Microsoft Excel nachbauen. Je nach Bericht können Sie zudem einen Rohdaten-Export durchführen. Ebenso erhalten Sie bei jedem Bericht die API Figure ID. Mit Hilfe dieser ID können Sie aus anderen Anwendungen den Magento-BI-Bericht ansprechen und die Daten abfragen. Dadurch lassen sich die Magento-BI-Berichte auch z. B. in Intranet-Anwendungen implementieren bzw. in jeder Anwendung, die per API Daten aus Magento BI abfragen kann.

Das ist, auch wenn es auf den ersten Blick gar nicht so klingt, ein enorm spannendes Feature. Sie können dadurch Magento BI als reines Reporting-Tool nutzen und die dort erstellten Berichte und aufbereiteten Daten problemlos in weiteren Anwendungen nutzen. Dadurch kann Magento BI das zentrale Tool für Datenaggregation und ‐auswertung in Ihrem Unternehmen werden! Last, but not least können Sie zudem den Bericht wieder aus dem Dashboard entfernen. Klicken Sie hierzu einfach auf den Link Remove from Dashboard, den Sie auch in Abbildung 15.17 sehen, die zudem alle bereits angesprochenen Links und Möglichkeiten zeigt.

Abbildung 15.17    Pro Bericht haben Sie verschiedene Optionen und Möglichkeiten, die aber abgesehen vom Rohdatenexport immer identisch sind.

Unabhängig von den jeweiligen Berichten, haben Sie weitere Konfigurationsmöglichkeiten bzw. Optionen, die sich auf das gesamte Dashboard beziehen. Hierfür steht Ihnen eine weitere Navigationsleiste, die sich am oberen linken Bildschirmrand befindet, zur Verfügung. Werfen Sie hierzu bitte einen Blick auf Abbildung 15.18.

Abbildung 15.18    Das Dashboard selbst verfügt ebenfalls über verschiedenste Optionen.

Wenn Sie auf das Wort Executive Overview klicken, können Sie zwischen den verschiedenen Dashboards hin und her wechseln. Wie ich bereits erwähnte, besteht die Möglichkeit, in Magento BI unendlich viele Dashboards anzulegen. Ein Dashboard ist letztendlich nur eine Ansammlung bzw. Darstellung von Berichten. In der Praxis legen Sie für verschiedene Abteilungen, zum Teil auch Personen, unterschiedliche Dashboards an. Ein Geschäftsführer benötigt komplett andere Zahlen und Visualisierungen als z. B. ein Außendienstmitarbeiter. Dadurch können Sie ein Geschäftsführer-Dashboard sowie ein Außendienstmitarbeiter-Dashboard anlegen und beiden Dashboards unterschiedliche Berichte zuweisen. Der Geschäftsführer würde anschließend nur in sein Dashboard schauen und hätte auch nur die Berichte zur Verfügung, die für ihn relevant sind. Ob Sie die Dashboards dabei anhand der Abteilungen bzw. Funktionen oder direkt nach Personen gliedern, bleibt natürlich Ihnen überlassen. Sofern Sie einem Nutzer verschiedene Dashboards freigeben, hat er an dieser Stelle die Möglichkeit, zwischen den verschiedenen Dashboards zu wechseln, d. h., ein Nutzer kann immer mehr als ein Dashboard besitzen bzw. darauf zugreifen. Testen Sie dies gern an dieser Stelle, da Magento BI von Haus aus verschiedene Dashboards anlegt. Wenn Sie auf das Zahnrad-Icon klicken, können Sie zudem den Namen des Dashboards anpassen und das geöffnete Dashboard als Standard-Dashboard definieren. Auch können Sie das Dashboard unter einem neuen Namen abspeichern, damit kopieren und eine Massenbearbeitung durchführen. Mithilfe der Massenbearbeitung können Sie alle im Dashboard enthaltenen Berichte anhand eines Musters abändern bzw. anpassen. Dadurch ersparen Sie sich die einzelne Bearbeitung der Berichte, wodurch Sie eine Menge Zeit sparen können. Eine Massenbearbeitungsoption wäre z. B. die Suche nach einem bestimmten Namen und das automatisierte Ersetzen des Namens mit einem anderen Begriff. Ebenso können Sie direkt ein neues Dashboard erstellen, Dashboards durchsuchen und das Dashboard löschen.

Klicken Sie als Nächstes bitte auf den Link namens Sharing. Daraufhin öffnet sich ein weiteres Menü, das Sie auch in Abbildung 15.19 sehen.

Mithilfe dieses Links können Sie das Dashboard, das Sie sich gerade ansehen, mit anderen Nutzern teilen. Das heißt, andere Nutzer haben dadurch Zugriff auf das Dashboard und die dort enthaltenen Berichte. Ob die Nutzer das Dashboard editieren oder nur anschauen dürfen, lässt sich mittels des Buttons Set Permissions steuern. Über den Button Add Report, den Sie ebenfalls in Abbildung 15.19 sehen und der zudem recht prominent in der Farbe Grün abgebildet ist, können Sie darüber hinaus Berichte zu dem geöffneten Dashboard hinzufügen. Dadurch ergeben sich zwei Wege: Entweder Sie erstellen einen Bericht und fügen diesen direkt einem Dashboard hinzu, oder Sie öffnen ein Dashboard und fügen diesem einen auszuwählenden Bericht hinzu. Beide Wege sind möglich, in der Praxis bevorzuge ich jedoch den Weg über die Dashboards. Schlussendlich werden Sie sehr häufig Dashboards erstellen und diesen anschließend die Berichte hinzufügen.

Abbildung 15.19    Sie können ein vorhandenes Dashboard direkt mit anderen Nutzern teilen.

Zuletzt haben Sie zudem noch die Möglichkeit, die dargestellten Berichte zu filtern bzw. einzugrenzen. Magento BI erlaubt die Filterung auf Basis von Store Views sowie anhand einer zu definierenden Zeitspanne. Wählen Sie eine Zeitspanne aus, wird diese daraufhin automatisch auf alle Berichte, die im Dashboard enthalten sind, angewendet. Somit können Sie recht schnell zwischen der Ansicht des aktuellen Tages und der Betrachtung des aktuellen Monats wechseln. Auch wenn diese Funktion recht praktisch ist, müssen Sie an dieser Stelle etwas vorsichtig sein. Sie können ja bei den Berichten an sich schon verschiedene Zeitspannen hinterlegen. Wenn Sie z. B. die Abverkaufszahlen des gesamten Jahres, aber den durchschnittlichen Warenkorbwert des aktuellen Monats betrachten, kann bei einer globalen Anpassung des Zeitraums ein gewisses Datenchaos entstehen, da Sie ab diesem Zeitpunkt sowohl die Verkaufszahlen als auch den Warenkorbwert für die neu hinterlegte Zeitspanne betrachten. Seien Sie daher bei der Änderung der Zeiträume innerhalb eines Dashboards ein wenig vorsichtig!

Nutzen Sie die Möglichkeit der Testversion, und spielen Sie mit den Dashboards und den Berichten. Magento BI hat eine recht intuitive Oberfläche, und viele Aktionen lassen sich mittels Drag & Drop ausführen. Sie werden schnell die Logik und die Abläufe des Systems verinnerlichen und können anschließend äußerst effizient Berichte anlegen und Auswertungen fahren. Meiner Meinung nach hat Magento BI eine einfache und schnell zu erlernende Oberfläche, die sich auf das Wesentliche konzentriert.
